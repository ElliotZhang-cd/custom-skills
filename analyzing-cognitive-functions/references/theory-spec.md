## 0. 本文档的地位与用法

**读者**：执行 `analyzing-cognitive-functions` skill 的模型（LLM）。

**地位**：本 skill 的**理论基石 spec**。`SKILL.md` 规定"做什么、按什么顺序做、产物长什么样"；本文档规定"为什么可以这么做、每一步的判定依据是什么、边界在哪里、什么结论不许下"。两份文档冲突时的仲裁规则：

- 涉及**理论判定**（某个读法合不合法、某句话能不能说）→ 以本文档为准。
- 涉及**操作契约**（命名、文件结构、固定文本块、lint 检查项、语气禁用词）→ 以 `SKILL.md` 与 `references/` 其余文件为准。

本文档不重复 `SKILL.md` 的流程步骤，只做它的规范来源；也不重复 `references/writing-style.md` 的措辞规则，只说明那些规则背后的心理学理由。

### 0.1 核心立场：双层并置

本 skill 同时使用两套理论，它们不是二选一，是**同一张图的两种读法**：

| | 结构层（Structural） | 动力层（Dynamic） |
|---|---|---|
| 理论来源 | 荣格的功能态度概念 + Myers 的栈序 + Beebe 的八格原型 | 荣格的对立与补偿、阴影、投射、阿尼玛/阿尼姆斯、个体化、退行 |
| 回答什么 | 谁站在哪个位置（类型、主导/辅助、位次、分化程度） | 位置在动什么（压力、关系、成长、防御） |
| 与分数的关系 | 可追溯到分数（排序 → 梯队 → 配对 → 锁定） | 不可直接从分数读出，须经结构层定位后再解读 |
| 产物落点 | 01 章（类型与八维栈、形状与分化）、04 章（四条轴） | 02 章（位置动力学）、03 章（能量）、05 章（投射）、06 章（个体化） |

**两层的接口规则（本文档最重要的一条）**：

> **结构层是动力层的定位系统，动力层是结构层的意义系统。**

- 没有结构层，动力层说不清话：不知道"第 4 位是 Se"，就说不出"他在用 Se 逃避 Ni 的重压"。
- 没有动力层，结构层只剩贴标签：同一个第 8 位功能，在不同人身上意义完全不同，取决于它**是否已被"拥有"**——被意识到、被承认，还是被压抑、被投射到别人身上。

**推论**：报告里的任何一句动力层结论（压力下的退行、人际摩擦、成长路径），都必须先能指出它挂在结构层的哪一格上。指不出格位的动力层结论 = 凭空发挥，禁止输出。

### 0.2 三处必须记住的取舍（两层冲突时怎么办）

两套理论在三个地方直接打架。本文档的选择如下，执行时不得含糊：

1. **"第三功能"是后世构造。** 荣格本人只讲三个位次：优势、辅助、劣势。第三功能（永恒少年位）由 Myers、Beebe、Grant 一系补出。**凡输出涉及第 3 位的结论，须知道它是后世构造**，不得说成"荣格认为你的第三功能……"。使用上仍然采用——因为 skill 的八格结构与分数校验都依赖它——但归属要说对。

2. **"辅助必须与主导态度相反"是 Myers 的规范化，不是荣格原话。** 荣格只要求辅助功能与优势功能**不同类**（一个判断、一个知觉）。要求"态度也必须相反"，是 Myers 为了凑出 16 型并让四个功能态度构成封闭对立结构而追加的约定。本文档**采用 Myers/Beebe 的严格版**（因为配对法则表依赖它），但要说清它的来源（详见 §2.2）。

3. **量化语言是测量层的工程约定，不是荣格的心理学主张。** 荣格不用"高 Fe / 低 Fe"这种说法，他讲的是"分化/未分化""优势/劣势"。本 skill 的量化读法（噪声带、梯队、分差）是为了让一个连续分数剖面可操作而加的工程约定。**凡量化结论，都必须在动力层找到对应的定性读法**（"更常用 / 更费力 / 主场 / 不常用 / 未分化"），不能停在数字上。

### 0.3 明确不覆盖（边界声明）

- **Socionics（社会人格学）**：另一支独立的荣格学派延伸，含 Model A 八位排序、PoLR（痛点功能）/暗示功能、16 种关系类型（对偶、镜像、冲突、超我等）。它是"双人关系"最系统的规则化理论，但**它的位次定义与 Beebe 的八格不是同一套**（Model A 的第 3/4 位与 Beebe 的第 3/4 位指的不是同一种东西）。本 skill 不采用，故本文档不展开。**红线**：不得把 Model A 的位次、PoLR、关系类型名塞进 Beebe 的八格表或双人报告。若将来要引入双人关系分类，须单独立项并重写 `couple-report.md`。
- **实证与测量细节**：信效度、常模、重测稳定性、type-vs-trait 之争等，本文档只保留"分数怎么用才不越界"的最小必要（§5.1），不展开。
- **与大五/BFI-2 的交叉映射**：归 `analyzing-bigfive`，本文档不处理，也不在报告里做跨框架印证。
- **临床诊断、精神病理、依恋类型、创伤**：不在适用范围。本文档的框架分不开人格结构与状态起伏（这也是 07 章边界声明第 2 条的理论出处）。

## 1. 第一层：荣格原典

### 1.1 心理能量：为什么"分数 = 能量分布"是合法的荣格式读法

荣格把心理能量（力比多）看作一种**可在人格内部各系统之间分配的量**，在功能、情结、意象之间流动。三条支撑命题（观点归属：荣格，《论心理能量》一系著作）：

- **等值原则**：能量不会凭空产生或消失，只会转移——某处撤出，必在别处出现。
- **熵原则**：能量分布趋向均衡，极端的一边会引发另一边的补偿。
- **间接度量**：能量本身不可直接测，只能通过它的**效果**（某个内容对这个人有多大的"价值色"、有多大的吸引力或强制力）来推断。

**由此得到本 skill 的核心合法性论证**：

> 八维分数不是能量本身，而是能量在八个方向上留下的**效果痕迹**。

三条推论，直接决定报告怎么写：

1. 分数可以读作"能量放在哪里"——这是 03 章能量管理、04 章四条轴的理论许可。
2. **低分不必然是"没有能力"**，更可能是能量被撤走（压抑、未开发）——这是等值原则的读法，也是"低分 ≠ 弱"的理论依据（对应 07 章第 2 条、禁用词表禁止用"劣势/短板"）。
3. **分数的绝对值不可跨人比较**（没有共同零点、没有常模，见 §5.1）。

**明确禁止**：把分数读成能力、绩效、智力、健康度或任何可测量的表现。

### 1.2 两种态度：内倾 / 外倾

**不是"内向/外向性格"**——那是通俗化的误读。荣格讲的是**力比多的朝向**：

- **外倾（e）**：朝向客体——外部世界、他人、事物、客观事实。判断与感知以外部标准为准。
- **内倾（i）**：朝向主体——内部世界、自己的意象、自己的标准。判断与感知以内部标准为准。

**关键推论（全篇结构性结论之一）**：**态度与功能是两条独立的轴。** 一个人完全可能"思维分化得很好，但态度没分化"——表现为 Ti 和 Te 分数都高。**这不是数据错误，是荣格明确承认的"未分化型/中间型"。**

在报告里的落点：03 章首行"偏内倾 / 偏外倾"按**主导功能的态度**定（主导是 i 功能 → 偏内倾，以此类推）。

### 1.3 四种功能：判断与知觉

荣格按"心理在做什么"把功能分成两类，每类两个：

| 类别 | 功能 | 在做什么 | 判断标准 |
|---|---|---|---|
| **判断功能**（理性） | **思维 T** | 下判断、做决定 | 真 / 假、对不对、讲不讲得通 |
| | **情感 F** | 下判断、做决定 | 值 / 不值、好恶、该不该 |
| **知觉功能**（非理性） | **感觉 S** | 接收信息 | 具体的、当下的、实存的东西 |
| | **直觉 N** | 接收信息 | 关系、意义、可能性、走向 |

两个最容易被误读的点，必须在心里钉死：

1. **情感是理性（判断）功能。** 荣格把 F 和 T 并列，都叫"理性功能"。**情感不是"情绪"**——情绪是情感功能失控时的副产物；情感本身是一种**评价性判断**（"这对我值不值""这该不该"）。把 F 读成"感性、爱哭、情绪化"是最常见的错误。
2. **"非理性"不是"不讲理"。** 感觉和直觉被称为非理性，只因为它们**不下判断、只负责接收**。S/N 不评价，只提供材料。

**领域映射（决定投射的内容，见 §4.5）**：

| 功能对 | 领域 | 一句话 |
|---|---|---|
| 思考 Ti / Te | **真** | 可信、懂我、能办成 |
| 情感 Fi / Fe | **值** | 对、属于 |
| 感觉 Si / Se | **实** | 真的存在、真的在场 |
| 直觉 Ni / Ne | **义** | 意味着什么、可能成为什么 |

同一对里的两个功能是**同一领域的两副面孔**，所以它们最容易互相冒充（Ni 的"宿命"与 Ne 的"无限可能"是同一件事的收敛版与发散版；Fi 的"这才是对的"与 Fe 的"我才属于这里"是同一价值领域的内部版与外部版）。

### 1.4 八种功能态度（全篇词汇表底座）

2 种态度 × 4 种功能 = 8。这八个是全篇的最小单位，正文一律用中文名（见 `writing-style.md` §2 命名表）：

| 代码 | 正文名 | 一句话定义 |
|---|---|---|
| Se | 外倾感觉 | 朝向客体的当下实感：具体、直接、在场的感官与行动 |
| Si | 内倾感觉 | 朝向主体的感觉印象：被过往经验沉淀下来的印象、身体感、习惯（"跟过去比较"） |
| Ne | 外倾直觉 | 朝向客体的可能性：外部事物还有什么别的可能、别的联系 |
| Ni | 内倾直觉 | 朝向主体的意象：内在的图景、走向、意义（"这一切的去向"） |
| Te | 外倾思考 | 按外部标准组织事实与资源：效率、秩序、把事情办成 |
| Ti | 内倾思考 | 按内部标准建立逻辑一致：对不对、讲不讲得通、是不是真的懂了 |
| Fe | 外倾情感 | 按外部标准评价与协调：氛围、归属、他人的感受有没有被照顾到 |
| Fi | 内倾情感 | 按内部标准评价：值不值、真不真、是不是"我的" |

**归属提醒**：荣格用**主导功能**单独定义类型，因此严格说他只有八种"心理类型"（外倾思维型、内倾直觉型……）。十六型是 Myers 之后的构造（§2.1）。

### 1.5 对立与补偿（理论最核心的机制）

**每两个功能构成一对"对立"（opposite）**，规则是：

> **换到同一条轴上的另一个功能，同时翻转态度。**

| 功能 | 它的对立功能 |
|---|---|
| Ni | Se |
| Ne | Si |
| Ti | Fe |
| Te | Fi |

**补偿原则**：意识态度越极端地偏向一端，无意识就越强烈地往另一端补偿。所以这四对**不是"你强我就弱"的简单反比**，而是**同一枚硬币的两面**——一面的高度，决定了另一面被压入无意识的深度与张力。

**物极必反（enantiodromia）**：任何极端都会向它的反面翻转。这是两个高频现象的出处：**退行**（压力下退回劣势位）与**第 4 位膨胀**（被劣势功能"附身"，见 §5.6 偏离 B）。

在报告里的落点：**04 章的四条轴就是这四对对立方**（轴序固定为 Ni-Se / Ne-Si / Ti-Fe / Te-Fi），"分高端在下"的天平图是这个机制的视觉化。**必须提醒读者**：天平两端不是"好/坏"，是"意识 / 无意识"。

### 1.6 优势、辅助、劣势（荣格本人的三分）

| 位次 | 荣格的术语 | 特征 |
|---|---|---|
| 1 | **优势功能**（superior） | 发展最充分、最认同、用起来最省力，是自我认同的核心 |
| 2 | **辅助功能**（auxiliary） | 与优势功能**不同类**（一判断、一知觉）；是向外部世界适应的**桥梁**，但**无法替代优势功能的深层认同** |
| 3 | **劣势功能**（inferior） | 最不发达、最深地留在无意识里，是优势功能的**对立功能** |

**劣势功能的自主性（本 skill 伴侣分析的理论基础）**。荣格在论述劣势功能时的大意是：它"是独立的，它会攻击，它令人着迷，使我们旋转失控，无法再正确区分自己与他人"。

> 这正是"被伴侣某种特质强烈吸引、或被强烈激怒"的心理学基础：劣势功能不受自我控制，所以它以**投射**的形式出现在别人身上（§4.2、§4.3）。

**荣格的"垂直轴"**：优势与劣势构成心理生活中张力最大的维度，两者相互对抗；一方的过度发展，常以另一方的被压抑为代价。这解释了 06 章"支撑还是打架"的读法。

> **护栏（术语分层）**：「优势功能 / 辅助功能 / 劣势功能」是**荣格的术语，只在本文档（理解用）里出现**。**报告正文一律不得使用"优势/劣势/优点/缺点/强项/短板"字样**，必须换成"更常用 / 更费力 / 主场 / 不常用"（`writing-style.md` §3 R4、§5 禁用词表；lint 机械校验）。本文档里出现荣格术语，不构成在报告里使用它们的许可。

### 1.7 背景概念：集体无意识、原型、情结

这三个概念是动力层的地基，只需知道它们的角色，不需要展开：

- **集体无意识**：比个人无意识更深的一层，承载全人类共有的心理模式。
- **原型（archetype）**：集体无意识中的**普遍模式/意象**（大母神、智慧老人、阴影、阿尼玛……）。**注意区分**：Beebe 的八格用"原型"命名（英雄、恶作剧者……），指的是**原型性的角色/位置**——它们确实取材于跨文化的原型意象，但和荣格体系里的经典原型**不是同一层级的东西**。Beebe 的原型是"心理功能在人格结构里所处的位置所对应的角色意象"。
- **情结（complex）**：被压抑的情感—记忆团簇，具有自主性，可以短暂接管人格。情结是投射的常见载体：某个话题一被触碰就反应过度，往往是情结被激活。

### 1.8 类型的地位（认识论声明）

这一节是 skill 全部"边界声明"（07 章五条）的理论出处，必须原样理解：

- 类型是**描述性**的，用于组织理解，**不是人本身**。
- 荣格晚年反复警告：类型学的目的是让人**意识到自己的片面性**，从而有动力整合被压抑的部分——**不是给片面性发一张证书**。
- 人的目标是成为**完整的自己**（个体化，§4.4），不是成为一个类型。
- 因此：**"这个人属于哪一类"不是本 skill 要回答的问题**；"这个人目前把能量放在哪里、哪里还没被点亮"才是。

## 2. 第二层：延伸一 —— MBTI 系

### 2.1 Myers 的改造（与荣格的分歧点清单）

Myers 与 Briggs 在荣格八型的基础上建立了四字母、十六型、以及功能栈顺序（观点归属：Myers，《天资差异》一系著作）。**她改动了三处，每一处都要记清楚**：

| 维度 | 荣格 | Myers / MBTI |
|---|---|---|
| 类型数量 | **8 种**（只由主导功能态度定义） | **16 种** |
| 功能位次 | 优势 / 辅助 / 劣势（**3 个**） | 主导 / 辅助 / 第三 / 劣势（**4 个**） |
| 态度相反规则 | 只要求辅助与优势**不同类**，未明确要求态度相反 | **硬性要求**态度相反（J/P 由此定义） |
| 第三功能 | **无此概念** | 有（永恒少年位） |
| 用法 | 描述性、理解自己 | 分类、配对、职业咨询 |

**J/P 是 Myers 的发明**，荣格没有这个维度。它标记的是**哪个功能朝外**：

- 外倾的**判断**功能做主导 → **J**（如 Te 主导的 ESTJ、Fe 主导的 ENFJ）
- 外倾的**知觉**功能做主导 → **P**（如 Se 主导的 ESTP、Ne 主导的 ENTP）

**本文档采用 Myers 的严格栈序**（因为配对法则与镜像规则依赖它），但 §0.2 取舍规则 1 始终生效：**凡涉及第 3 位的结论，都要知道它是后世构造。**

### 2.2 为什么辅助必须"不同轴且态度相反"

这是 skill 里最硬的约束，它由两条理由叠加而成：

1. **荣格的理由（不同类）**：辅助必须与优势**不同类**（判断配知觉）。否则两个判断功能互相干扰，没有人负责接收信息，人格无法适应现实。
2. **Myers 的理由（态度相反）**：要凑出 16 型，并让每个类型的四个功能在态度上构成封闭的对立结构，辅助必须取**相反态度**。

两条合起来，就是 §5.4 的**配对法则表**。**它是硬约束，不是排序建议**——这是本 skill 最容易翻车的一步。

### 2.3 Keirsey 四种气质（另一个切法）

Keirsey 把十六型归为四种气质（观点归属：Keirsey，《请理解我》）：**SJ 护卫者 / SP 艺匠 / NF 理想主义者 / NT 理性者**。切分轴是 S/N（具体 vs 抽象）与行为目的（合作 vs 工具）。

- **与功能栈不冲突，粒度不同**：气质讲"这个人要什么"，栈讲"这个人怎么运作"。
- **使用规则**：报告里**不引入气质标签**（与"不贴标签"的总口径冲突）。只在需要解释"为什么这四组类型看起来像四类人"时，作为背景说明可用，不进结论。

### 2.4 Grant / Brownsword 的发展阶段论（两个高频解读的出处）

Grant 与 Brownsword 提出：四个功能按主导 → 辅助 → 第三 → 劣势的顺序在生命历程中依次发展（童年 → 青少年 → 成年早期 → 中年）（观点归属：Grant & Brownsword，《从形象到相似》）。

**地位声明（必须记住）**：这是**流行说法**，不是荣格的主张，也缺乏实证支持。

**但它必须写进 spec**，因为它是 skill 里两个偏离读法的理论出处：

| 流行说法 | skill 里的对应 | 规则 |
|---|---|---|
| "第三功能在二三十岁觉醒，常被当成主要出口" | **偏离 A**（第 3 位高于第 2 位 = 责任回避） | 可以说"这常见于刚成年、职业未定型、主业让人窒息的人" |
| "劣势功能在中年觉醒、膨胀" | **偏离 B**（第 4 位分数不低 = 膨胀） | 见 §5.6 |

**使用红线**：**不可**把发展阶段论当因果规律用。禁止说"你到了中年，所以 Se 会膨胀"、"你这个年纪第三功能该醒了"。只能说"这种分数形态常见于……"，把因果留给当事人自己核对。

## 3. 第三层：延伸二 —— Beebe 八原型

### 3.1 从 4 到 8 的扩展逻辑

荣格讲了意识三层级（优势/辅助/劣势）+ 无意识的补偿，但没有把无意识那半边结构化。**Beebe 的贡献是把八格补全**（观点归属：John Beebe，《心理类型中的能量与模式》）：

- **阳面四位（1–4）**= Myers 的主栈：主导 / 辅助 / 第三 / 劣势。
- **阴影四位（5–8）**= 主栈四位的**同功能反态度**。

**阴影不是"坏的一半"，是"未被拥有的一半"**——这与荣格的阴影概念完全一致：阴影既包含被压抑的负面内容，也包含**未被活出的潜能**。

### 3.2 八格表

| 位次 | 原型 | 其他中文译名 | 白话 | 分数预期 | 功能来源 |
|---|---|---|---|---|---|
| 1 | 英雄 Hero | 女英雄 | 你最自然、最拿手、最认同自己的部分 | 最高 | 主导 |
| 2 | 好父母 Good Parent | 父母 | 你照顾、支撑别人的那双手 | 次高 | 辅助 |
| 3 | 永恒少年 Puer/Puella | 永恒少女 | 放松时才玩得起来、孩子气、也容易在这里受伤的部分 | 中段 | 第三 |
| 4 | 阿尼玛/阿尼姆斯 Anima/Animus | — | 最费力、最想回避，也是最可能带你长大的门 | 偏低，常最低 | 劣势 |
| 5 | 对立人格 Opposing | 反派 | 被人反对时冒出来的防御姿态 | 中低 | 1 的同功能反态度 |
| 6 | 批判父母 Critical Parent | 女巫 / 老翁 Senex/Witch | 内心那个挑剔的声音 | 中低 | 2 的同功能反态度 |
| 7 | 欺骗者 Trickster | 小丑 | 压力下自以为聪明、容易把你带沟里的把戏 | 低 | 3 的同功能反态度 |
| 8 | 恶魔 Demon | — | 压力最大时才出现、破坏性最强的出口 | 通常最低 | 4 的同功能反态度 |

（译名差异说明：不同来源把第 6 位叫"批判父母/女巫/老翁"、第 7 位叫"欺骗者/小丑"。**本 skill 统一用"批判父母"与"欺骗者"**，见 `writing-style.md` §2。）

### 3.3 锁定规则与 16 种合法剖面

给定第 1 位，第 2 到第 8 位**全部被锁死**，没有自由裁量：

- **第 1 与第 4 位互为对立功能**（如 Ni ↔ Se）
- **第 2 与第 3 位互为对立功能**（如 Fe ↔ Ti）
- **第 5 位 = 第 1 位的同功能反态度**（Ni → Ne）
- **第 6 位 = 第 2 位的同功能反态度**（Fe → Fi）
- **第 7 位 = 第 3 位的同功能反态度**（Ti → Te）
- **第 8 位 = 第 4 位的同功能反态度**（Se → Si）

> **整个剖面只有 16 种合法形态**，每种对应一个类型。这就是全部结构分析的骨架。完整十六型栈表见**附录 B**。

### 3.4 镜像自检

把认定的主栈四个功能**态度全部翻转**，得到的序列应该刚好是**另一个类型的主栈**：

- INFJ 的 Ni-Fe-Ti-Se 翻转为 Ne-Fi-Te-Si = **ENFP** 的栈
- INTJ 的 Ni-Te-Fi-Se 翻转为 Ne-Ti-Fe-Si = **ENTP** 的栈

**为什么这个自检有效**：因为 5–8 位本来就是主栈的反态度，所以"实测的第 5–8 位"必须大致落在低分区，且顺序与镜像序列一致。**若 5–8 位不符合镜像序列 → 类型判定可能错了**，回 §5.3/§5.4 重定。

（完整的镜像配对：INTJ↔ENTP、INFJ↔ENFP、ISTJ↔ESTP、ISFJ↔ESFP、INTP↔ENTJ、INFP↔ENFJ、ISTP↔ESTJ、ISFP↔ESFJ。见附录 C。）

### 3.5 逐格读法（操作核心）

每一格统一回答四问：**这一格是什么 / 高分读什么 / 低分读什么 / 压力下怎么表现**。以下八节是 01–06 章所有结论的规则来源。

**第 1 位 · 英雄（主导）**
- 是什么：主场、自我认同。
- 高分：分化清晰、自我认同稳固。健康，但可能窄。
- 低分（相对其余）：几乎不会出现；若出现，先怀疑作答质量（§5.1），而不是"这个人没有主场"。
- 过高且其余塌陷：认知工具箱单一，适应面不够宽。
- 压力下：英雄位通常最稳定，是压力中唯一还转得动的部分。

**第 2 位 · 好父母（辅助）**
- 是什么：照顾、支撑别人的手，也是对外适应的桥梁。
- 关键判断（06 章）：它在**支撑**主导，还是在**和主导打架**？Ni 极高 + Fe 极低 = 直觉飞得很高却无法落地与人沟通，会显得"有洞见但不可理喻"。
- 高分：能对外协调、能支撑别人。
- 低分：对外适应吃力，容易退回只用自己的主场。

**第 3 位 · 永恒少年（第三）**
- 是什么：放松时才玩得起来、孩子气、也容易在这里受伤的部分。
- 高分（尤其**超过第 2 位**）：把"玩乐/兴趣"当成了主要出口 → 见 §5.6 偏离 A（责任回避）。
- 低分：不太会放松，兴趣稀薄，缺少"玩"的出口。
- 压力下：容易在这里任性、退行到"只想做自己玩得转的事"。

**第 4 位 · 阿尼玛/阿尼姆斯（劣势）**
- 是什么：软肋，也是门。最费力、最想回避。
- 低分：**这是正常形态**，符合"劣势"的定义。
- **不低**：必须走两解读法（§5.6 偏离 B）——膨胀 vs 误判，不得硬选一种。
- 它连着无意识，是**通往自性的门**（§4.4）：最低的那一格，成长空间最大。
- 压力下：这是最经典的退行出口之一（"被劣势功能附身"）。

**第 5 位 · 对立人格（阴影·防御）**
- 是什么：被人反对时冒出来的防御姿态。
- 偏高：在冲突里容易摆出防御架势，把讨论变成攻防。
- 低分：被反对时不容易立刻进入防御。

**第 6 位 · 批判父母（阴影·内在批判者）**
- 是什么：内心那个挑剔的声音。
- **这一格的高低 = 内在批判者的音量**（06 章固定读法）。
- 偏高：对自己极其苛刻，也容易苛责别人。

**第 7 位 · 欺骗者（阴影·把戏）**
- 是什么：压力下自以为聪明、容易把你带沟里的方式。
- 偏高：压力下会用一套"看起来很聪明"的办法把事情办砸，而且当时觉得自己很有道理。
- 低分：不太会在这一格上自作聪明。

**第 8 位 · 恶魔（阴影·退行出口）**
- 是什么：压力最大时的破坏性出口。
- **它不是弱点，是预警指标**（02 章固定读法）：**开始高频使用第 8 位功能 = 已进入退行**。
- 压力下：这是最深、最具破坏性的出口。它的价值在于**提前识别**——一旦出现高频使用的迹象，就该上外部护栏，而不是等它爆发。

**补充（可选证据层）**：有的自陈工具会让答题者给每个位次标一种"位置态度"（如 1 位"应然/零内耗/心流"、2 位"熟练/有意识/轻耗"……）。这类自陈可作为补充证据，但**本 skill 不采集**，只在用户主动提供时作为访谈线索，不写进分数分析。

### 3.6 与荣格的接口

- **1–4 位 = 荣格的意识层级**：英雄 + 好父母 ≈ 优势 + 辅助；永恒少年 = 第三；阿尼玛 = 劣势。
- **5–8 位 = 荣格意义上的阴影 / 无意识内容**，Beebe 给了它们名字和位置。
- 因此：**结构层（八格）与动力层（意识/无意识）是同一张图的两套读法**——这是双层并置的核心接口（§0.1）。八格是"格位地图"，荣格的心理能量论是"这张地图上为什么会有张力"的解释。

## 4. 第四层：延伸三 —— 荣格学派分析师

### 4.1 von Franz：劣势功能与投射的收回

（观点归属：Marie-Louise von Franz，《荣格类型学讲义》一系著作）

- **劣势功能是"通往无意识之桥"**，是"难以获得的珍宝"所在；个体化要求把它带入意识。
- **投射的收回**：投射被收回时，投入在投射意象里的心理能量**回流到个体自身，供其发展使用**。von Franz 把它称为"使心理能量回流到个体自身、供其发展使用的唯一途径"。
- **推论**：投射的收回是关系发展的关键转折，也是"关系成熟"的定义——不是"找到完美匹配的人"，而是双方逐渐收回投射、看见彼此的真实面目（§5.8 层次 4）。

### 4.2 阴影

- 荣格把阴影称为人格的"**第三维度**"：那些被自我压抑、与自我形象不相容的心理内容。
- **阴影不只包含"负面"特质，也包括未被活出的潜能。**
- **运作方式是投射**：我们无法在自己身上看见的内容，会在他人身上被强烈地感知到——**无论被吸引，还是被激怒**。

在报告里的落点：05 章那句"最容易点燃你情绪的，是对方身上带着你未被拥有的部分"就是这一节的白话版。

### 4.3 阿尼玛 / 阿尼姆斯

- **阿尼玛**：男性无意识中的女性原型意象；**阿尼姆斯**：女性无意识中的男性原型意象。
- 荣格的大意是：一个男人在爱情的选择上，受"与他本身无意识中的女性原始意象最吻合的女性"强烈诱惑。
- **推论**：**爱情初期的高强度吸引，本质上是阿尼玛/阿尼姆斯原型的投射**。伴侣被体验为"灵魂的载体"，而不是一个完整、独立、有局限的人。这是"命中注定"感的来源。
- **使用规则**：这是异性恋框架下的经典表述。本 skill **只保留机制（投射发生在灵魂意象层），不预设伴侣的性别与性取向**。写作时用"灵魂意象 / 阿尼玛/阿尼姆斯"表述机制，不假定读者与伴侣的性别。

### 4.4 个体化（individuation）

- **定义**：整合意识与无意识内容，成为更完整的人。**自性（Self）**是整全的原型，也是人格的目标与中心。
- **机制**：**超越功能（transcendent function）**——持有对立面的张力，直到"第三物"从张力中产生（这与 §1.5 的对立与补偿是同一套动力学）。
- **关键推论（06 章的理论出处）**：**劣势功能不是缺陷，是"未开垦的入口"**，它连着无意识，是通往自性的门。**分数最低的那一格，成长空间最大。**

**但必须同时说清一个务实的取舍（否则 06 章会自相矛盾）**：

> **"用得更省力"优先于"死磕不常用"。** 对成年人，巩固常用功能的回报远高于强行发展不常用功能。（06 章不用"守常用 / 点亮不常用"这类不直观的说法：对常用功能写「**用得更省力**」，对不常用功能写「**借力补位**」。）

这与荣格"最终要整合劣势功能"**不矛盾**：整合是**长期方向**，不是**短期任务**。06 章的固定引言"对成年人来说，守住你最常用的功能，回报远高于死磕最不常用的那一格"就是这条取舍的白话版。

### 4.5 投射的语法（功能 × 态度 → 投射形态）

这是 05 章与双人报告"翻译"话术的技术依据。核心命题：

> **功能决定投什么（领域），态度决定投射以什么形态出现。**

- **内倾功能被投射时** → 产出**无人称的绝对判决**："这才是……"。因为它的标准在内部、不可协商。
- **外倾功能被投射时** → 产出**对象作为必要条件**："有你在，我才能／就能……"。因为它把重量放在对象身上。

**所以：听语法就能分辨投射的方向。** 判决句 = 内倾功能在投；条件句 = 外倾功能在投。完整 8 条清单见**附录 E**（含每条的"失效方式"，那是这套清单最实用的部分）。

**层级说明（不可省略）**：这份清单是**灵魂意象（阿尼玛/阿尼姆斯）层**的——每个功能投的是**未活出的一个部分**。**自性投射是另一个层级**，投的是**整全本身**（意义本身、完整性本身），落到关系或事业上。

> **Ni 与 Fi 之所以特别危险，不是因为它们投的东西更重，而是因为它们的内容（意义、价值）最容易从一个"部分"升级成"整全"**——"这是去向"很容易变成"这是我生命的意义"，"这才是对的"很容易变成"这才是真实的我"。其他六个功能要完成这个升级，得先借道这两个。

## 5. 分析操作规范（拿到分数之后）

> 本节是 `SKILL.md`「分析方法论」的规范来源。SKILL.md 给步骤，本节给每一步的**判定规则、允许的结论形态、禁止的越界**。

### 5.1 分数的性质与三条使用限制

**分数是能量分布的代理指标，不是测量值本身**（§1.1）：没有常模、没有共同零点、不跨人可比。

**三条限制（违反其一即越界）**：

1. **不跨人比较绝对值。** A 的 Ni = 65 与 B 的 Ni = 54 **不构成**“谁的直觉更强”的结论。凡关于“更常用／更费力”的结论，只能用**各自内部的对比**（“A 的重心压在 Ni，B 的重心压在 Se”）——**这是双人报告的方法学底线**（`couple-report.md` §4 要求“读数用描述性语言，不出现数字倍数、也不用分差绝对值”，理由在此）。
   - **唯一的例外：位置参照。** 同一量表、同一次测评下，允许把两人的分数放进**同一坐标系**作位置参照（双人 01 章的四象限矩阵、附录对照表），用途仅限于看“两人的重心各落在哪里”。**但不得读成强弱**：禁止“谁更高／谁带谁／谁的 X 更强”式的命名与结论；象限名与列名一律中性化（“A 更靠这一头／B 更靠那一头”），并配边界句说明“中线是几何中点，不是及格线，也不代表谁更强”。**凡进入“更常用／更费力”层面的结论，仍然只能用各自内部比值。**
2. **单一阈值 ≤3 分（分差只回答"有没有先后"，不回答"差多少"）。** 同一剖面内，分差 **≤3** 的两个功能**不构成可靠先后**（视为"分不出先后"）；**>3 才构成先后**。这是**唯一**的阈值——**不再分 4–11 / ≥12 档**。三条理由：① 荣格关心的核心是**分化**——功能有没有分出先后，这是**二分的**；差值大小是连续量，荣格并不用它描述人格；② 这个量表的精度不足以支撑 1–2 分的区分，把 1 分差写成故事是编造；③ 奥卡姆剃刀——三阈值 → 一阈值。读**梯队**（分数接近、链式归组的一片），不读名次；**梯队内先后不解读**。轴两端强弱的**幅度**一律用**描述性语言**表达（接近时说“几乎并肩／基本是平的”，拉开时说“一头站在明处、另一头要专门使劲”），**不出现数字倍数、也不用分差绝对值**——原始分无共同零点，倍数接近 1 时会把“几乎一样”说成“有差别”；与双人报告口径统一（`couple-report.md` §4）。
3. **不读能力。** 分数高低 ≠ 能力强弱。低分可能是压抑、未开发，也可能是健康的谦逊（07 章第 2 条）。

**作答质量前置检查**（`SKILL.md` Phase 0，规则见 `input-parsing.md` §2）：

| 模式 | 判定 | 动作 |
|---|---|---|
| 8 项全部 ≤10 | 十分制疑点 | **停下反问**，不静默处理 |
| 全距 <10（扁平剖面） | 作答防御 / 敷衍 / 耗竭 | 建议重测，**全部推断降权** |
| 极端应答、敷衍模式 | 作答质量异常 | 在【咨询师备注】中警告 |

### 5.2 第 1 步：排序与形状（判定树）

**先归梯队（≤3 分链式归组），再按下面的判定树定形态——自上而下，命中一条即停，不再往下判。** 用判定树而不是并列的五个标签，是为了消除"双峰 + 反常同时成立、却没有优先级"的空洞：形态**恰有一个**，判定的顺序本身就是优先级。

| 顺序 | 形态 | 判定条件（命中即停） | 读法 |
|---|---|---|---|
| 1 | **塌陷型** | 作答质量异常：八项普遍低（如全部 ≤30），**或**全距 <10（全部挤在一起，含全部 ≥85 的情况） | 优先怀疑**答题防御**或**抑郁/耗竭状态**，**不是"空白人格"**。建议重测，所有推断降权 |
| 2 | **高原型** | ≥4 个功能落在同一梯队 | 两解，**必须结合访谈/自查区分**：① 未分化（还没找到主场，容易随环境变形）；② 社会化良好但自我认同稀薄（什么场合都能应付，但问"你是谁"答不上来）。就地给两解 + 自查问题 |
| 3 | **双峰型** | 最高两项分差 **≤阈值（≤3）**，**且二者构成合法主辅对**（一判断一知觉、态度相反，即 §5.4 配对法则的合法组合） | **主辅齐飞**，理想形态：两股力量互为支撑 |
| 4 | **反常型** | 最高两项分差 **≤阈值（≤3）**，**但不构成合法主辅对**；**或**镜像自检不过（§3.4）；**或**对位出现 ✗（有格位明显错位） | 剖面与任何单一合法类型不符；走 §5.6 偏离 B 读法 + §5.6.2 奥卡姆单线选型 |
| 5 | **尖塔型** | 其余情形（一个明确最高，其余平滑递减） | 主导分化清晰、自我认同稳固。健康但可能窄——工具箱单一，适应面可能不够宽 |

**两条硬规则**：

- **双峰型与反常型互斥。** 二者的分界线就是"最高两项是否构成合法主辅对"：构成 → 双峰型（理想）；不构成 → 反常型。同一个剖面不可能同时命中（判定树里第 3 步先于第 4 步）。
- **"第 4 位分数不低"不触发反常型。** 它是一条**软观察**（§5.6 偏离 B），写在 02 章的偏离块里；只有当它导致**对位 ✗**（该格实测分明显越出该位次应有的段位）时，才升级为反常型。判定树第 4 步只认"对位 ✗"，**不认"分数不低"这种字面条件**——否则任何第 4 位分数不低的剖面都会被误判为反常，尖塔型将无处安放。
- **第 4 步为什么成立（第一性原理）**：若最高两项分差 ≤阈值、却**不构成**合法主辅对，那么"第二高"必然落在**它不该在的位次**上——它若在第 3 位，就是"偏离 A"（第 3 位只该是辅助之后的发展位）；它若在第 4–8 位，就是**阴影位**，阴影位不该高。两种情况都意味着剖面与任何单一合法类型不符，所以**必然反常**——不存在"两个高分不合法却仍算正常类型"的中间情况。

**输出形态**：01 章尾「你的分布形状：」小节，结构固定两行——「1. 形态：」只写判定树命中的那一个形态名；「2. 结论：」两句式（肯定句 + "可能…"保留句），按命中的形态取句（模板见 `html-templates.md` 01 章）。

### 5.3 第 2 步：定主导

取**最高分**。**但要警惕"崇拜的功能"污染**：

> 如果最高分是 Fi，而这个人做的是销售、或在强调集体和谐的家庭长大，要考虑他填的是"**我想成为的样子**"而不是"**我实际的样子**"。

**交叉验证的办法**：问行为证据——**他空闲时自发干什么？能量在什么时候回升？**（`writing-style.md` §5 禁用"以你的经历为准"这类敷衍话术，但行为核对是必须的，要以**自查问题**的形式给出。）

**理论依据**：问卷测的是**自我概念（自我认同）**，不完全等于**实际的功能使用**。荣格本人强调类型要看实际的心理活动，不是自陈。

### 5.4 第 3 步：配对法则定辅助（硬约束，最容易翻车的一步）

**不要简单取第二高分。** 辅助功能必须满足：

> **辅助功能必须与主导功能不在同一条轴上（一个判断、一个知觉），且态度相反。**

| 主导 | 合法辅助 | 对应类型 |
|---|---|---|
| Ni | Te / Fe | INTJ / INFJ |
| Si | Te / Fe | ISTJ / ISFJ |
| Ne | Ti / Fi | ENTP / ENFP |
| Se | Ti / Fi | ESTP / ESFP |
| Ti | Se / Ne | ISTP / INTP |
| Fi | Se / Ne | ISFP / INFP |
| Te | Si / Ni | ESTJ / ENTJ |
| Fe | Si / Ni | ESFJ / ENFJ |

**操作**：第二高分不满足这个条件 → **跳过它**，看第三、第四高，从合法候选里挑最高的那个。

**教学点（本流程最重要的一个）**：假设主导是 Ni（36），第二高是 Ti（33）。Ti 是**内倾判断**，不合法。跳过，从合法候选里挑：Te = 11、Fe = 30 → **辅助 = Fe**。类型锁定为 **INFJ**。

> **如果按分数排序硬套，你会得出"Ni + Ti"这种根本不存在的组合**，从而误判成一个不存在的类型。

**理论依据**：§2.2（荣格的"不同类" + Myers 的"态度相反"）。

### 5.5 第 4 步：镜像补全八格

一旦主导 + 辅助确定，剩下六位**全部锁定，不再有自由裁量**（§3.3 六条锁定规则）。把**理论栈**与**实际分数**并排写出来，逐格对位。

### 5.6 第 5 步：校验

**正常趋势**：`1 > 2 > 3 > 4 ≳ 5 ≈ 6 > 7 > 8`。真实数据常有两类**合法偏离**，需要解释而不是忽略：

**偏离 A：第 3 位（永恒少年）异常高，甚至超过第 2 位。**
- 含义：这个人把"玩乐/兴趣"功能当成了主要出口。
- 常见于：刚成年、职业未定型、或主业让他窒息的人。
- **关键读法**：第三功能高本身不坏，**但高于辅助功能，往往意味着责任回避**——他更愿意待在自己玩得转的地方，而不是去扛辅助功能该扛的事。
- 措辞：**分差 ≤阈值（≤3）时只说"接近、不算构成先后"**；构成先后后，强弱一律用**描述性语言**（"Ti 一头站在明处、Fe 要专门使劲"），**不出现数字倍数，也不用"差 8 分 / 差 10 分"这类数字**（§5.1 限制 2 的单一阈值口径）。
- 理论出处：§2.4（发展阶段论，须标注为流行说法）。

**偏离 B：第 4 位（劣势/阿尼玛）分数不低。**
- 两种截然不同的解释，**必须给两解 + 自查问题，不硬选一种写成定论**：
  - **膨胀**（荣格所说的 inflation，被劣势功能"附身"）：比如一个 INFJ 突然狂热投入健身、感官刺激、物质消费，那是他在用 Se 逃避 Ni 的沉重。**临床上更常见，也更值得关注。**
  - **误判**：他把某个自己崇拜的功能填高了。
- 理论出处：§1.6（劣势功能的自主性）+ §1.5（物极必反）+ §4.1（von Franz 的劣势功能论）。

**镜像自检**（§3.4）：5–8 位不符合镜像序列 → 回 §5.3/§5.4 重定。

**输出形态（单线）**：**只输出一个类型**作为正文主线——`<h3>最接近的类型：X（仅供参考）</h3>` + 栈序一行 + **对位摘要**（**八格全 ✓ 可写"判定高度可信"**；出现 ≈ 或 ✗ 就逐格说明，不写"高度可信"）。选型见 §5.6.2 的**奥卡姆单线选型**：候选 = **最高梯队的每个功能**分别当主导；判据分两层——意识四位（1–4）对位和 → 阴影四位（5–8）对位和 → 主导分更高者。其余候选在 01 章用**一句话**带过。**"主导未定 / 两套合法栈并列"这一分支已整体删除**，不再作为输出形态存在。

#### 5.6.1 "双核心"的正式定义（必读）

用户口语里会说"**双核心**"，例如"INFJ，Ni + Fi 双核心"。**注意：Ni + Fi 是非法栈**——Ni 主导（内倾知觉）必须配 Te/Fe，Fi 是内倾判断，不合法。所以"双核心"这个说法在结构层必须被翻译，不能照抄。

**规范读法**：

1. "双核心"指的是**实测最高的两个功能**，**不保证构成合法栈**。
2. 所谓"双核心"在结构层**只能翻译成两种东西，不留第三种**：
   - ① **主辅齐飞**：两个最高分不同轴、态度相反（构成合法主辅对）→ 它就是主导 + 辅助，理想形态（对应"双峰型"）。
   - ② **错位**：两个最高分不构成合法主辅对（同轴、同态度，或落在阴影位）→ 最高分坐在**非主栈位次**上，走**反常型**读法（§5.2 判定树第 4 步）+ **奥卡姆单线选型**（§5.6.2）。
3. **红线**：**不得写成"X + Y 双主导"**。合法栈永远只有一个主导；候选类型可以有多个，主导只有一个。
4. 报告里出现"双核心"字样时，**必须紧跟一句它在八格里的位置**（如"Ni 坐在第 1 位、Fi 坐在第 6 位"），否则不得使用这个词。

#### 5.6.2 奥卡姆单线选型（取代"主导未定 + 两套栈并列"）

**形式化准则（最终措辞，执行时按此逐步计算）**：

1. **候选集**：**主导 ∈ 最高梯队**（≤阈值链式归组的第一组，可能含 **1–3 个成员**——**不是"最高两项"**；"最高两项"会在最高梯队有 3 个成员时漏掉合法候选）。每个候选主导按配对法则（§5.4）取合法辅助（合法候选里分最高者），得到**最多 3 个合法候选类型**。
2. **判据分两层，都不用权重**（权重系数是魔数，反奥卡姆）：
   - **第一层：意识四位（第 1–4 位）的对位分之和**，取最小；
   - **第二层（仅并列时）：阴影四位（第 5–8 位）的对位分之和**，取最小。
   对位分按 `html-templates.md` 01 章对位判定：**✓ = 0、≈ = 0.5、✗ = 1**。
3. **末位并列时**：取主导分更高者。
4. **主导 = 最高分是默认**；但**最高梯队含多个成员时**（成员两两分差 ≤阈值），主导判定视为**落在误差带内**，改由第 2–3 步决定谁当主导（即**允许主导不是最高分**）。
5. **输出**：只保留**一个类型**作为正文主线（`<h3>最接近的类型：X（仅供参考）</h3>` + 栈序一行 + 对位摘要）；其余候选在 01 章用**一句话**带过，形如「另一条路是 INFP，但它的辅助位要额外解释、意识四位要多解释三处，故不取」。

**依据**：

- **第一性原理**：理论预测的是**整条 8 槽剖面**（`1>2>3>4≳5≈6>7>8`），不是三个孤立的数。所以拟合度必须在**八格上算**——只看第 1/2/4 位，等于把模型自己做的另外五个预测丢掉；丢掉的信息又要靠"第 3 位 → 5–8 位 → 主导分"那条三级链捡回来，**那串补丁本身就是"主判据没抓住要点"的症状**。
- **可信度梯度用分层表达，不用权重**：荣格本人的三位与意识四位（1–4）比阴影四位（5–8）可信（§0.2 取舍 1：第 3 位与阴影位是后世构造）。这个梯度用**分层（lexicographic）**表达——"先满足意识、再满足阴影"——**不需要任何拍脑袋的系数**；加权重才是反奥卡姆。
- **候选集的理由**：主导按定义是"最发达、最认同、最省力"的功能（§1.6），它不可能不在最高梯队；而"允许主导不是最高分"的误差带逻辑，同样要求"**最高梯队里每个成员都有资格当主导**"，否则会漏候选。
- **奥卡姆**：一个类型、一条主线，只留**一个解释**；判据一个（分两层）、tiebreaker 一条（主导分），**不再有三级链**。

### 5.7 第 6 步：读动力（分数是症状，动力才是病灶）

三个必答问题（02 章、06 章的内容来源）：

1. **辅助功能是在支撑主导，还是在打架？** 主导 Ni 很强、辅助 Fe 也很强的人是流畅的；Ni 极高、Fe 极低的人，直觉飞得很高却无法落地与人沟通，会显得"有洞见但不可理喻"。
2. **第 6 位（批判父母）的高低 = 内在批判者的音量。** 偏高 → "对自己极其苛刻、也容易苛责别人"的体验。
3. **第 8 位（恶魔）是压力下的出口，不是弱点，是预警指标。** 当这个人开始高频使用第 8 位功能时，说明他已经进入**退行**状态。

**输出落点**：02 章"压力下的退行形态"固定小节（第 8 位出口 + 外部护栏；第 4 位膨胀作为另一种退行形态）+ "你的盲区：并非不足，是成本"固定小节（**第 4 / 5 / 6 / 7 / 8 位各压成一行结论**）。

### 5.8 双人分析规范（四个层次）

双人分析遵循一个**由外向内、由意识到无意识**的递进逻辑。以下四层是 `couple-report.md` 的理论骨架。

**层次 1 · 功能态度识别**
- 分别确定双方的主导功能态度（严格说只有八种心理类型，由主导功能定义）。
- **关系意义**：主导功能态度决定各自"最自然、最擅长、最认同"的意识模式。一方以该模式回应 → 沟通最顺畅；以相反态度运作 → 误解最易发生。

**层次 2 · 意识层级交叉**
- A 的优势功能，在 B 的意识层级中处于什么位置（优势/辅助/劣势/阴影）？
- A 的劣势功能，是否恰好是 B 的优势功能？反之亦然？
- 双方的劣势功能是否在**同一领域**（如都弱于 Se/Si）？→ 会导致**共同盲区**。

**层次 3 · 投射清单**

| 问题 | 要回答什么 |
|---|---|
| 我在伴侣身上**最被吸引**的特质是什么？ | 这是否是我自己**未活出的**功能态度？ |
| 我在伴侣身上**最被激怒**的特质是什么？ | 这是否是我自己**压抑的**阴影内容？ |
| 我把伴侣体验为"灵魂伴侣/命中注定"的强度有多高？ | 提示阿尼玛/阿尼姆斯投射的程度 |
| 我是否在期待伴侣"补全"我？ | 如果是，我**缺少的**究竟是什么？ |

**层次 4 · 关系动力学判断**
- **吸引来源**：互补吸引（一方的主导恰是另一方的劣势，劣势功能具有"令人着迷"的特性）／投射吸引（把阿尼玛/阿尼姆斯投射到对方身上，把对方体验为自己灵魂的"答案"）／两者兼有？
- **冲突热点**：优势功能之间的碰撞（双方都以最擅长的模式运作、互不相让）／劣势功能被触发（一方劣势领域被无意触碰，引发过度敏感和失控）／阴影投射的相互攻击（双方都在对方身上看到并攻击自己压抑的内容）？
- **个体化潜力**：双方是否愿意收回投射、面对自己的阴影与劣势功能？

**兼容地图的推导规则（05 章，由本剖面自身推导，不硬编伴侣原型）**：05 章的兼容地图共 **8 行**，全部从**本剖面自身**推导，不再枚举固定的伴侣原型（旧版只有 4 条硬编：Te/Si 强、Fi/Ni 强、Se 强、Fe 极强——**必然漏项**，如高 Ne、高 Ti 的人没有对应行）：

**首列一律「名字 + 括号里的类型名单」**：每一行都点名它说的是哪几种类型，读者不必为了知道「Se 常用的人」是谁去翻附录。名单取法只有一条——**「以这个功能为主导或辅助的人」**（首列写功能时），或**「主栈与本人相同的人」**（首列写同类时）。名单不是新增内容，就是 §5.4 配对法则表与附录 B 栈表里已经排好的配对，本节把它抄成一张速查表：

| 功能 | 以它为主导或辅助的类型（主导 2 型在前、辅助 2 型在后） |
|---|---|
| Ni | INTJ / INFJ / ENTJ / ENFJ |
| Ne | ENTP / ENFP / INTP / INFP |
| Se | ESTP / ESFP / ISTP / ISFP |
| Si | ISTJ / ISFJ / ESTJ / ESFJ |
| Ti | ISTP / INTP / ENTP / ENFP |
| Fi | ISFP / INFP / ENFP / ESFP |
| Te | ESTJ / ENTJ / INTJ / ISTJ |
| Fe | ESFJ / ENFJ / INFJ / ISFJ |

每个功能恰好 4 型。**只取主导与辅助**：第 3 位不算（第 3 位是玩伴轴那一行的事），阴影四位不算（阴影是投射那一组的事）。把 8 型都算进来会让「常用的人」这句话失焦——一个 INFJ 的第 6 位是 Fi，可他不算「Fi 常用的人」。

- **行 ①–⑤（低格位）**：取本剖面的第 **4 / 5 / 6 / 7 / 8** 位，各一行。这一格就是本剖面**排在后段、最容易投射到别人身上**的功能（§1.6 劣势功能的自主性、§4.2 阴影的投射、本节层次 2 的意识层级交叉），所以「这一格常用的人」这一行，正是在写"这位来访者会在什么样的人身上被吸引或被激怒"。每行给出三件：**互补是什么 / 摩擦是什么 / 解法是什么**。首列 = **「<功能> 常用的人（该功能 4 型）」+ 位次小字**（如 INFJ 的第 4 位：「Se 常用的人（ESTP / ESFP / ISTP / ISFP）」+「第 4 位」）。
- **行 ⑥（同类轴）**：与本剖面主栈相同的人 → **共鸣**（不用翻译）+ **摩擦**（同用一套模式，容易一起内耗）+ **解法**。首列 = **「同类主栈的人（本人那一型）」+ 主栈小字**（如 INFJ：「同类主栈的人（INFJ）」+「Ni-Fe-Ti-Se · 同类轴」）。
- **行 ⑦（玩伴轴）**：与本剖面第 **3 位（永恒少年）** 常用的人 → **玩伴** / 一起玩得起来 + **摩擦**（都不太负责）+ **解法**。首列 = **「<功能> 常用的人（同一条 4 型规则）」+「第 3 位 · 玩伴轴」**（如 INFJ：「Ti 常用的人（ISTP / INTP / ENTP / ENFP）」+「第 3 位 · 玩伴轴」）。
- **行 ⑧（镜像轴）**：与本剖面**互为镜像**的类型（附录 B 末列「镜像类型」、§3.4 镜像自检的配对，如 INFJ ↔ ENFP）——**他的主栈 = 你的阴影栈，你的主栈 = 他的阴影栈**，两个人合起来正好是完整八格。→ **极致互补**（你缺的四格他全会，他缺的四格你全会）+ **摩擦**（最容易被当成"我的另一半答案"——那正是投射最强的形态；也最容易滑成"你管四格、我管四格"的永久分工，结果双方那四格都不再长）+ **解法**（至少挑一格自己练，别把补位长期外包）。首列 = **「互为镜像的人（<镜像类型>）」+「主栈 = 你的阴影栈 · 镜像轴」**。**这一行不是投射，是栈结构**（谁的第几位对上谁的第几位，见 §3.4），故归结构组。注意镜像那一型也会出现在行 ①–⑤ 的某个名单里——行 ①–⑤ 按**单个功能**分，本行按**整条主栈**说，两处都要出现。


**05 章的第一性原理安排（单人口径）**：本章只有**一条机制、两种极性、一个判据**，全章都是这三样的展示，不引入第四样东西：

- **一条机制**：自己**未活出的部分**以**投射**的形式出现在别人身上（§1.6 劣势功能的自主性 + §4.2 阴影的投射）。
- **两种极性**：**被吸引与被激怒是同一枚硬币**（§4.2："无论被吸引，还是被激怒"）。行 ①–⑤ 因此**共享一个理由**（后段格位最容易外投），但**极性各不相同**——第 4 位偏吸引、第 6 位偏苛责、第 8 位偏退行。**不得把它写成一条单调的投射强度梯度**；位次标签本身已携带该行的动力。
- **一个判据**：**投射的语法**（§4.5）——内倾在投说判决句，外倾在投说条件句，"听语法就能分辨方向"。**判据必须与它判定的命题同章**（否则读者只能"信"、不能"核"），故在 05 章给一句，不只在附录 B 出现。

**三条排布红线**：

1. **主语是"你"，不是"对方"。** 列名、行首、内容句的主语都落在读者身上。一张以"对方是什么样的人"为行的表，会被读成"我该找哪一种类型"——那正是本节禁止的问题。
2. **一阶内容在前，二阶产物在后。** 单人报告里没有第二份剖面，**兼容地图是二阶产物**；一阶内容是**读者自己能回答的部分**，即**本节层次 3 的四问**（最被吸引的特质 → 是否是自己未活出的那一格／最被激怒的特质 → 是否是自己压抑的阴影／"命中注定"感的强度 → 第 4 位投射的程度／是否在期待对方"补全"自己 → 缺的究竟是哪一格）。四问放前，地图放后。
3. **拆成 5 + 3，并点明后三行不是投射。** 行 ①–⑤ 是投射（低格位外投），行 ⑥⑦⑧ 是**结构**（同类 = 共鸣与共谋；玩伴取第 3 位，是八格里最不投射的一格；镜像 = 两条主栈互为对方的阴影栈，见 §3.4）。压成一张八行平表、同一组列名，等于告诉读者这八种人是一类东西。**8 行仍是 8 行，只是分组可见。**

**为什么这样更第一性原理、也更省（奥卡姆）**：**5 条由本剖面推导 + 3 条结构轴（同类、玩伴、镜像）**，覆盖任何功能组合，自动适配全部 16 型；4 条硬编枚举既覆盖不全，又需要为新类型不断补条目。推导版把"伴侣原型"从一张枚举表变成一条**规则**。上面的四条排布同样是奥卡姆的账：**新增内容为零**——四问来自本节层次 3、判据来自 §4.5、"命中注定"来自 §4.3、镜像轴来自附录 B 末列与 §3.4 的配对、首列名单来自 §5.4 配对法则表（本节只把它们抄成一张速查表），全是把理论文档里已有的东西搬到它们该在的位置，表数仍是两张。

**必须记住的两条**：

1. **荣格本人对"互补即合适"持谨慎态度。** 他强调理解与自己类型不同的人是"完全困难的"；**差异本身不保证成长，也可能导致永久性的误解**。
2. **不判合分。** 关系的成熟标志不是"找到完美匹配的人"，而是双方逐渐收回投射、看见彼此的真实面目，并在此过程中整合自己的阴影与劣势功能（§4.1）。**"你们合不合"不是本框架能回答的问题。**

**方法论底线**：跨人比较只用**各自内部的比值**（§5.1 限制 1）。双人报告里的"互为触发点"（对照双方第 4/6/8 位撞上对方哪一格）就是这条的落地——它比的是**格位对格位**，不是分数对分数。

### 5.9 输出口径（能得出 / 不能得出）

**能得出**（报告 01–07 章承载）：

1. 类型归属与八维栈（主导、辅助、第三、劣势 + 阴影四位）。
2. **功能分化程度**——荣格最看重的指标，比类型标签重要得多。分化好 = 主导功能能独立工作、不被其他功能干扰；分化差 = 分数糊成一团。
3. 心理能量的分布与管理方式：哪类活动回血，哪类耗竭。
4. 压力下的退行形态：退到第 4 位还是第 8 位？表现是什么？
5. 人际冲突的机制：劣势功能与阴影功能，正是最容易被他**投射**到别人身上、并引发强烈情绪的部分。
6. **个体化的路径线索**：最低的那一格，是通往自性的门，也是成长空间最大的一格。

**不能得出**：

- **不是能力测评**：分数高不等于能力强，与智商、情商、任何绩效无关。
- **不是诊断工具**：无法区分人格结构与病理状态；低分可能是压抑、未开发，也可能是健康的谦逊。
- **不能预测行为**：类型是倾向，不是剧本。
- **不能推断童年经历的具体事实**、**不能推断缺席一方的心理**、**不能判定关系成败**。
- **不能脱离访谈使用**：任何只靠分数下结论的分析，都是把一个动态的能量系统压成一张静态照片。**"访谈区分"在本 skill 里一律转译为自查问题**（`writing-style.md` §3 R5）。

**措辞总纲**：结论说"**能量放在哪里、哪里还没被点亮**"，不说"你就是 X 型的人"；坏消息不回避、好消息不夸大；推测必须带标记（可能/往往/常见于）；两解场景给两种可能 + 自查问题。**所有待验证项在报告 06 章尾以「回到自己身上核对」小节汇总成自查清单。**

## 6. 结论

**一句话总结整个方法论**：

> 先看形状，再定主导，用配对法则的硬约束锁辅助，靠六个镜像规则补全八格，然后校验偏离、追问动力——**最后，把结论说成"这个人目前把能量放在哪里、哪里还没被点亮"，而不是"这个人属于哪一类"。前者是荣格学派，后者是星座。**

## 附录 E · 八维投射清单

**总则**：功能决定投什么（领域），态度决定投射以什么形态出现。
**内倾** → 无人称的绝对判决："这才是……"（标准在内部、不可协商）。
**外倾** → 对象作为必要条件："有你在，我才能／就能……"（把重量放在对象身上）。
**听语法就能分辨投射的方向。**

| 功能 | 投的内容 | 句子形态 | 对象被赋予 | 失效方式 |
|---|---|---|---|---|
| Ni | 意义与方向 | 判决："这是这一切的去向" | 终极意义、宿命 | **幻灭**——现实没长成愿景的样子；爱的是那个必然性，不是这个人 |
| Ne | 可能与开放 | 条件："和你在一起，一切都有可能" | 无限可能、未来的开放性 | **永不完成**——伴侣永远是一份草稿；可能性耗尽时，电荷自己转移 |
| Si | 连续与踏实 | 判决："这才是真的过日子" | 可靠的实在、归属的家 | **不许改变**——任何新东西都是背叛；也常表现为把怀旧投在人身上（"你让我想起……"） |
| Se | 当下与活着的实感 | 条件："和你在一起我才真正活着" | 存在感、活生生的现实 | **电荷随当下消失**——对方被要求持续供应"活着的感觉"，平淡就等于背叛 |
| Ti | 被理解与可信 | 判决："你是唯一真正理解我的人" | 理智上的可信、懂我的地位 | **无人能达标**——标准在内部，对方永远无法真正满足，于是长期失望与长期投射并存 |
| Te | 效能与秩序 | 条件："有你在，事情就能成" | 效力、能把事情变成真的的能力 | **伴侣变成工具**——交付失败时，整段关系被登记为"低效" |
| Fi | 价值与真实性 | 判决："这才是对的" | 绝对价值、真实感 | **差异即威胁**——分歧不再像观点差异，而像对身份的侵犯 |
| Fe | 归属与被接纳 | 条件："有你在，我才属于这里" | 归属、被容纳与被承认 | **温度一撤就是流放**——分不清"被爱"与"被容纳"；对方必须永远温暖，否则我不存在 |

**四领域小表**：思考 = 真（可信 / 懂 / 能办成）；情感 = 值（对 / 属于）；感觉 = 实（真的存在 / 真的在场）；直觉 = 义（意味着什么 / 可能成为什么）。同一对里的两个功能是同一领域的收敛版与发散版，最容易互相冒充。

**层级说明**：本清单是**灵魂意象（阿尼玛/阿尼姆斯）层**的——每个功能投的是未活出的一个部分。**自性投射是另一个层级**，投的是整全本身（意义本身、完整性本身）落到关系或事业上。**Ni 与 Fi 最容易从"部分"升级成"整全"**，其他六个要升级得先借道这两个。

**分数解读的两处限定**：分数高 = 在意识里发展得好；低分 = 藏进无意识、因而最容易以投射的形态出现。但两处限定不可省——① 被无意识内容"附身"的高分是借来的（§5.6 偏离 B）；② 低分 ≠ 没能力（§1.1、§5.1 限制 3）。
