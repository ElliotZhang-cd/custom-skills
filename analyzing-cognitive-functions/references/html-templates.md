# HTML Templates — 报告结构与视觉件

唯一视觉事实源 = `examples/mbti_sample.html`（双人 = `examples/mbti_sampleA_sampleB.html`）。设计令牌、组件 CSS、打印样式与其一致；改任何视觉规则前先看样例实际长什么样。

## 1. 设计令牌与全局（保持现状，不改）

纸感设计令牌、hero 86vh、680px 列宽（双人 720px）、hairline 表格（无外框、无竖线、无底色、无圆角）、打印样式逐字保持。功能色 `var(--ni)` 等八色沿用：颜色永远属于功能，不属于人。

## 2. 单人报告结构（hero + 01–08 + 附录 + footer，章节恰 8 个（附录另计））

**hero**：`.kicker`「Jungian Cognitive Functions · 人格坐标报告」+ 定位句 h1 + `.lede` 固定句 + 雷达（雷达下不设图注段）。

**01 · 类型与八维栈**（承载：类型与八维栈）
- 柱状图**先行**（精确分数，0–100 标尺，占主视觉）。几何参数（竖瘦）：viewBox `0 0 680 380`；基线 y=320；网格线 y=320/264/208/152/96/40（标 20–100，标签 x=22）；柱宽 38，8 槽位按分数降序排布 x=51,131,212,292,372,452,533,613（横中心 x=70/150/231/311/391/471/552/632）；柱高=分数×2.8（柱 y=基线−柱高）；数值标签 y=柱顶−9；功能名 y=348。**不设 chart-note**。
- 八维栈明细表（`table.lt`）**4 列**：功能 · 分数 · 栈位 · 对位（✓/≈/✗）。栈位=「1 · 英雄」式；**每个维度恰一行**；行序按分数降序，不设排名列。白话列移附录 A。
- 类型判定块（紧凑：栈序一行 + 对位摘要）：
  - 锁格成功：`<h3>最接近的类型：INFJ（仅供参考）</h3>` + 栈序（Ni-Fe-Ti-Se｜Ne-Fi-Te-Si）+ 对位摘要（八格全 ✓ 可写「判定高度可信」）。
  - 锁不住：`<h3>主导未定：两套合法栈（仅供参考）</h3>`；**两种情况分开成两个列表、各写各的栈序与栈表，不挤在一张表里** + 自查问题。
- 对位判定：✓ = 实测梯队与理论位次段位一致（1–2 位在最高两梯队、3–4 位居中、5–8 位低位）；≈ = 跨一档；✗ = 明显错位。
- 章末固定句「别把任何标签当身份证。」

**02 · 形状与分化**（承载：形状与功能分化）
- h2 照录「你的分布形状：」。
- 结构固定两行：
  - 「1. 形态：」点名五类之一（尖塔/双峰/高原/塌陷/反常）+ 一句定义（形态判据白话，如「尖塔型（一个极高，其余平滑递减）」，形态学名加粗）；形态学名解禁，此行可直接用尖塔型 / 双峰型 / 高原型 / 塌陷型 / 反常型。
  - 「2. 结论：」两句式（肯定句+"可能…"保留句）。
- 五形态结论模板（按形态取用）：
  - 尖塔型→主导功能分化清晰，自我认同稳固。可能认知工具箱比较单一，适应面可能不够宽。
  - 双峰型→不同轴=主辅齐飞理想；同功能反态度=态度未分化、身份困惑常见（两解+自查）
  - 高原型→未分化 vs 社会化良好但自我认同稀薄（两解+自查）
  - 塌陷型→优先怀疑答题防御或耗竭，建议重测、推断降权
  - 反常型→转动力学章偏离读法
- 标（两解+自查）的形态（双峰、高原）就地写两种可能 + 自查问题，不硬选一种写成定论。

**03 · 能量分布**（承载：能量分布 + 主辅协作）
- 四条轴（轴序固定：Se-Ni / Si-Ne / Te-Fi / Ti-Fe），每轴：`.beam` 天平图（分高端在下）→ `table.duo-t` 两端对照（「更常用的一头 / 它的代价」列名）→ [`table.pc-t` 双弱对照] → `.scene` 场景块。
- caption 按分差三档（writing-style §4）。
- 双弱判定 = 两端实测分均列全维后三位。
- 主辅是支撑还是打架（如 Ni 高 Fe 低 = 有洞见但不可理喻式落差）。

**04 · ENERGY MANAGEMENT「心理能量的分布与管理方式」**（承载：回血与耗竭 + 管理方式）
- `.sec-num`「04 · ENERGY MANAGEMENT」；h2 照录「心理能量的分布与管理方式」；lead 点题照录「哪类活动让你回血，哪类活动让你耗竭」。
- 回血表（每行 = 场景 + 哪个功能在回血）。
- 耗竭表（每行 = 场景 + 耗竭的点）。
- 管理方式小结（回血进日程、耗竭工具化/外包/限时、补电顺序）。

**05 · POSITION DYNAMICS「基于荣格动力学的八维位置分析」**（承载：位置动力学 + 退行形态 + 盲区）
- `.sec-num`「05 · POSITION DYNAMICS」；h2 照录「基于荣格动力学的八维位置分析」。
- ① 正常趋势 1>2>3>4≳5≈6>7>8 与实测对照。
- ② 偏离重点：偏离 A/B 两解读法（就地自查）。
- ③ 压力下的退行形态（固定小节名）：第 8 位出口=退行信号+护栏；第 4 位膨胀=另一种退行形态。
- ④ 第 6 位批判者音量。
- ⑤ h3 固定句「你的盲区：并非不足，是成本」+ 省力做法表。

**06 · 人际与投射：人际冲突的机制**（承载：人际冲突的机制 + 投射）
- h2 照录「人际与投射：人际冲突的机制」。
- 引言照录「你付出的和你想要的，经常不是同一种东西」。
- 投射机制：功能定投什么、态度定形态（内倾→无人称判决「这才是…」；外倾→条件句「有你在，我才能…」，听语法辨方向）+「最容易点燃你情绪的=对方带着你未被拥有的部分」+ 指向附录 B。
- `div.relg` rel 四键（你给出的 / 你索取的 / 你的摩擦点 / 关系里的你）+ 兼容地图（白话，不判合分）+ 三句句式。

**07 · 个体化路径**（承载：个体化）
- 引言照录「对成年人来说，守住你最常用的功能，回报远高于死磕最不常用的那一格」。
- 发展建议表：每行 = 方向（守常用 / 点亮不常用）+ 具体做法（含频次/场景）。最低那格 = 成长空间最大的门。
- 偏离 A 若出现：写责任回避信号与要练的功课（扛起辅助该扛的事），措辞随分差弱化。
- 章尾固定小节**「回到自己身上核对」**：汇总全部待验证项（崇拜污染、两解场景、锁格存疑）为自查问题清单。

**08 · 边界声明**：五条照录（writing-style §7），第 4 条括注照录「（清单见 07 章尾）」。

**附录**（`<section id="appendix">`，08 章后 footer 前；附录另计，不占 8 章）
- **附录 A · 八个位置的名字（白话）**（01 栈表的白话列移此）：
  - 1 英雄=你最自然、最拿手、最认同自己的部分
  - 2 好父母=你照顾、支撑别人的那双手
  - 3 永恒少年=放松时才玩得起来、孩子气、也容易在这里受伤的部分
  - 4 阿尼玛/阿尼姆斯=最费力、最想回避，也是最可能带你长大的门
  - 5 对立人格=被人反对时冒出来的防御姿态
  - 6 批判父母=内心那个挑剔的声音
  - 7 欺骗者=压力下自以为聪明、容易把你带沟里的把戏
  - 8 恶魔=压力最大时才出现、破坏性最强的出口
- **附录 B · 八维投射**：
  - 引言（分数低的部分藏在无意识里，最容易以投射的形态出现；功能决定投什么，态度决定投什么形态——内倾→无人称判决「这才是…」，外倾→条件句「有你在，我才能…」；听语法就能分辨方向）。
  - 8 条列表（格式：**功能** 投的内容｜句型与例句｜对象被赋予｜失效方式）：
    - Ni 意义与方向｜判决「这是这一切的去向」｜宿命与终极意义｜幻灭——现实没长成愿景的样子，爱的是必然性不是这个人
    - Ne 可能与开放｜条件「和你在一起，一切都有可能」｜无限可能｜永不完成——伴侣永远是草稿，可能性耗尽时电荷自己转移
    - Si 连续与踏实｜判决「这才是真的过日子」｜可靠的实在、归属的家｜不许改变——新东西都是背叛，也常以怀旧形态出现
    - Se 当下与活着的实感｜条件「和你在一起我才真正活着」｜存在感、活生生的现实｜电荷随当下消失——要求对方持续供应活着的感觉，平淡等于背叛
    - Ti 被理解与可信｜判决「你是唯一真正理解我的人」｜懂我的地位｜无人能达标——标准在内部，长期失望与长期投射并存
    - Te 效能与秩序｜条件「有你在，事情就能成」｜把事情变成真的的能力｜伴侣变成工具——交付失败时整段关系被登记为「低效」
    - Fi 价值与真实性｜判决「这才是对的」｜绝对价值、真实感｜差异即威胁——分歧像对身份的侵犯
    - Fe 归属与被接纳｜条件「有你在，我才属于这里」｜被容纳与被承认｜温度一撤就是流放——分不清「被爱」与「被容纳」
  - 四领域小表（思考=真：可信/懂/能办成；情感=值：对/属于；感觉=实：真的存在/真的在场；直觉=义：意味着什么/可能成为什么；同一对的两个功能是同一领域的收敛版与发散版，最容易互相冒充）。
  - 层级说明（本清单是灵魂意象层——投的是未活出的一个部分；自性投射是另一层级，投的是整全本身；Ni 与 Fi 最容易从「部分」升级成「整全」，其他六个要升级得借道这两个）。
  - （柱状图 chart-note 删除后，其分数解读并入引言——正确解读：分数高=意识里发展得好，低分=藏进无意识/被投射，两处限定：被无意识内容「附身」的高分是借来的、低分≠没能力。）

**footer**：`.disc` 临床句照录。
