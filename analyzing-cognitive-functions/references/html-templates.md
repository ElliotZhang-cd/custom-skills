# HTML Templates — 报告结构与视觉件

唯一视觉事实源 = `examples/mbti_sample.html`（双人 = `examples/mbti_sampleA_sampleB.html`）。设计令牌、组件 CSS、打印样式与其一致；改任何视觉规则前先看样例实际长什么样。

## 1. 设计令牌与全局（保持现状，不改）

纸感设计令牌、hero 86vh、680px 列宽（双人 720px）、hairline 表格（无外框、无竖线、无底色、无圆角）、打印样式逐字保持。功能色 `var(--ni)` 等八色沿用：颜色永远属于功能，不属于人。

## 2. 单人报告结构（hero + 01–07 + 附录 + footer，章节恰 7 个（附录另计））

正文只给结论：不解释理论、不写「见 XX 章」「参看附录」「参考 XX」式指引（附录内部互指除外）；解释性内容仅允许存在于附录。

**全章贯彻 writing-style §3 R8（结论前置、拆段为件）**：每章 = 一句结论（放最前）+ 一张图或表承载 + 必要时一句代价或做法；禁止连续两段以上的说明性叙述，三条以上并列信息一律进表/列表。各章「本章结论句位置」见下。

**hero**：`.kicker`「Jungian Cognitive Functions · 人格坐标报告」+ 定位句 h1 + `.lede` 固定句 + 雷达。

**01 · TYPE & STACK**（承载：类型与八维栈 + 形状与分化）
- `.sec-num`「01 · TYPE & STACK」；h2「类型与八维栈：谁站在哪个位置」。
- **本章结论句位置**：h2 之后**直接进三块**，每块**首行给一句结论**，再是表/列表（R8：结论前置、拆段为件，不堆叙述段）。**本栏不设主视觉图**——八格位次与对位由 01 章栈表承载，错位的解释由下面的「偏离与错位」表承载。
- 柱状图**先行**（精确分数，0–100 标尺，占主视觉）。几何参数（竖瘦）：viewBox `0 0 680 380`；基线 y=320；网格线 y=320/264/208/152/96/40（标 20–100，标签 x=22）；柱宽 38，8 槽位按分数降序排布 x=51,131,212,292,372,452,533,613（横中心 x=70/150/231/311/391/471/552/632）；柱高=分数×2.8（柱 y=基线−柱高）；数值标签 y=柱顶−9；功能名 y=348。
- 类型判定块（**奥卡姆单线**：候选 = 最高梯队每个功能分别当主导、按配对法则取辅助，按两层判据取最小者，即唯一输出；紧凑：栈序一行 + 对位摘要）：
  - 唯一类型：`<h3>最接近的类型：INFJ（仅供参考）</h3>` + 栈序一行（Ni-Fe-Ti-Se｜Ne-Fi-Te-Si）+ 对位摘要（八格全 ✓ 可写「判定高度可信」；出现 ≈ 或 ✗ 就逐格说明，不写「高度可信」）。
  - 落选候选**一句话带过**（不设小标题、不并列表、不写栈表），形如「另一条路是 INFP，它要多解释 7 对可靠反序，故不取」。
  - **删除分支**：不再有「锁不住 → 主导未定两套栈并列」这一支（依据 theory-spec §5.6.2）。lint 的字面要求由「最接近的类型」满足，**规格只产出**「最接近的类型」这一种标题。
- 八维栈明细表（`table.lt`）**4 列**：功能 · 分数 · 栈位 · **对位**（✓ / ≈ / ✗）。栈位=「1 · 英雄」式；每个维度恰一行；行序按分数降序。白话列移附录 A。
- **固定句（照录，紧接栈表）**：「分数低的那几格，不代表你做不到——它更多说明能量被撤到了别处，或者这块还没被你自己认领。」（theory-spec §1.1 等值原则给出的替代读法；与 07 章第 2 条互补——那条是否定「低分=弱」，这条给出替代读法）
- 对位判定：✓ = 实测梯队与理论位次段位一致（**第 1–2 位在最高两梯队、第 3 位居中、第 4–8 位在低位**）；≈ = 跨一档；✗ = 明显错位。**第 4 位按「偏低」处理**（theory-spec §3.2：劣势功能最不发达、常最低）。
- **段位定义**：八项按分数降序、≤阈值链式归组为梯队后，**最高两梯队 = 高段、第 3–4 梯队 = 中段、第 5 梯队起 = 低段**。

- 章尾**「你的分布形状：」**小节，结构固定两行（形态名 = **判定树**命中的那一个，自上而下命中即停）：
  - 「1. 形态：」只写形态名称（**尖塔型** / **双峰型** / **高原型** / **塌陷型** / **反常型** 五取一），不带定义括注。
  - 「2. 结论：」两句式（肯定句 +「可能…」保留句），按判定树（theory-spec §5.2）命中顺序取模板：
    - ① 塌陷型（作答质量异常：八项普遍低，或全距 <10）→ 优先怀疑答题防御或耗竭，建议重测、推断降权。
    - ② 高原型（≥4 项同一梯队）→ 未分化 vs 社会化良好但自我认同稀薄（两解 + 自查）。
    - ③ 双峰型（最高两项 ≤3 **且构成合法主辅对**）→ 主辅齐飞，理想：两股力量互为支撑。
    - ④ 反常型（最高两项 ≤3 **但不构成合法主辅对**；或镜像自检不过；或**对位出现 ✗**）→ 就地写偏离两解结论（膨胀 vs 误判）+ 自查（完整读法由 02 章偏离块承载，正文只写结论）。注意：**「第 4 位分数不低」本身不触发反常型**，它只是 02 章的软观察；只有导致**对位 ✗**才升级。
    - ⑤ 尖塔型（其余：一个明确最高、其余平滑递减）→ 主导功能分化清晰，自我认同稳固。可能认知工具箱比较单一，适应面可能不够宽。
    - **双峰型与反常型互斥**，同一个剖面只会命中其中一个。
- 章末固定句「别把任何标签当身份证。」（照录；其后不接任何指引句）

**02 · POSITION DYNAMICS**（承载：压力下的退行形态 + 偏离）
- `.sec-num`「02 · POSITION DYNAMICS」；h2 照录「基于荣格动力学的八维位置分析」。

- 三块内容，**结论前置的表**：

  - ③ **你的盲区：并非不足，是成本**（**小节名照录，lint 检查**）：**五格表，第 4 / 5 / 6 / 7 / 8 位各一行结论**（八格全覆盖；第 1/2/3 位的读法归 01 章与 04 章），**无做法列**（做法列移 06 章）。第 5 位（对立人格）= 被反对时冒出来的防御姿态；第 7 位（欺骗者）= 压力下自以为聪明、容易把你带沟里的把戏；两格即使分数偏低也要各写一行，不得留空。首行一句结论。

**04 · 四条轴**（承载：四条轴能量偏向）
- `.sec-num`「04 · ENERGY AXES」；h2「能量分布：四条轴上你偏哪一头」。
- **本章结论句位置**：h2 之后**先给一条总结论**（最常用的一头总体偏向），再逐轴展开；每轴的 caption 即该轴的一句结论（R8）。无章引言理论段、无场景块。

- **天平几何（写死；工程约定，不是荣格的心理学主张）**：
  - 支点固定 `(320, 142)`；中点在 `y=120`；两端 x 固定 `80` 与 `560`；viewBox `0 0 640 210`。

**05 · PEOPLE & PROJECTION**（承载：人际投射与冲突机制）
- `.sec-num`「05 · PEOPLE & PROJECTION」；h2 照录「人际与投射：人际冲突的机制」。
- **本章结论句位置**：h2 之后按固定顺序——引言（照录），随后**人际冲突机制结论 1–2 句**（本章结论句），再进投射自查表、投射语法一句、`relg`、兼容地图（R8）。无投射理论段、无附录指引句。
- 引言照录「你付出的和你想要的，经常不是同一种东西」。
- 人际冲突机制结论 1–2 句：最容易点燃你情绪的，是对方身上带着你未被拥有的部分；**被吸引与被激怒是同一枚硬币**（theory-spec §4.2）。
- **本章主语一律是「你」，不是「对方」**：全章不得写成「伴侣类型目录」——列名、行首、内容句的主语都落在读者身上（红线：不判合分，theory-spec §5.8「必须记住的两条」）。单人报告里没有第二份剖面，兼容地图是二阶产物，**一阶内容是读者自己能回答的部分**，故自查表在前、地图在后。
- **投射自查表**（h3「先认出来：这四件事往自己身上核对」；4 行，列 = 问自己 / 往自己身上核对的落点）：四问取自 theory-spec §5.8 层次 3 —— ① 最被吸引的特质 → 是否是自己**没活出来**的那一格；② 最被激怒的特质 → 是否是自己压抑的阴影内容；③ 「命中注定」感的强度 → 提示第 4 位（阿尼玛/阿尼姆斯）投射的程度；④ 是否在期待对方「补全」自己 → 缺的究竟是哪一格。**放 `relg` 之前**（先让读者对号入座，再给地图）。
- **投射语法一句**（紧随自查表，**不搬**附录 B 的矩阵表）：「内倾功能在投，说判决句（「这才是对的」）；外倾功能在投，说条件句（「有你在，事情就能成」）——**听语法就能分辨方向**。」（theory-spec §4.5；把判据放在它判定的命题同章）
- `div.relg` rel 四键（你给出的 / 你索取的 / **最容易被点燃的** / 关系里的你）。第三键即机制里的「激怒」极性，与兼容地图第三列同指。
- **兼容地图**（h3 照录「兼容地图：没有对错，只有磨合」；**由本剖面自身推导**，不硬编伴侣原型；白话，不判合分）。表前一句导语交代分组理由，并交代行数与口径（**八行分两组**：前五行投射、后三行结构；括号里的类型 = **以这个功能为主导或辅助的人**）；表体**拆成 5 行 + 3 行两张表**，中间以 h4 分组标题隔开（列 = 对方 / 你在他身上看到的 / 你最容易被他点燃的 / 你这边要做的动作）——
  - **首列一律「名字（括号：类型名单）」**：读者不该为了知道「Se 常用的人」是谁去翻附录。名单取**「以它为主导或辅助的 4 型」**，主导 2 型在前、辅助 2 型在后，照抄 theory-spec §5.8 速查表（如 Se → ESTP / ESFP / ISTP / ISFP；Ni → INTJ / INFJ / ENTJ / ENFJ）。**只取主导与辅助**，第 3 位与阴影四位不进名单。名单写在第一行名字之后（括号内），位次/轴名仍走第二行 `.muted` 小字；首列宽度按此调（`table.map-t` 首列 13em），别让名单挤掉内容列。
  - **h4「投射：你排在后面的五格」→ 5 行表**：取本剖面第 **4 / 5 / 6 / 7 / 8** 位，各一行，首列 = **「<功能> 常用的人（4 型名单）」+ 位次小字**（如「Se 常用的人（ESTP / ESFP / ISTP / ISFP）」/ 小字「第 4 位」；**不写「与…的人」**）→ 你在他身上看到的 / 你最容易被他点燃的 / 你这边要做的动作。依据：这一格是本剖面排在后段、最容易投射到别人身上的功能（theory-spec §1.6、§4.2、§5.8 层次 2）。**第 4 位（阿尼玛/阿尼姆斯）那行补一句**：「命中注定」感多半就是这一格在投（§4.3），并接一句收回投射的做法（§4.1）。**五行共享一个理由（后段格位最容易外投），但极性不同**（4 偏吸引、6 偏苛责、8 偏退行）——不写成一条单调的强度梯度，位次标签自己带着动力。
  - **h4「不是投射，是结构：同类、玩伴与镜像」→ 3 行表**：行 ⑥ **同类轴** = 与本剖面主栈相同的人（首列「同类主栈的人（本人那一型）」+ 主栈小字，如「同类主栈的人（INFJ）」/「Ni-Fe-Ti-Se · 同类轴」）→ 共鸣（不用翻译）+ 摩擦（同用一套模式，容易一起内耗）+ 做法；行 ⑦ **玩伴轴** = 与本剖面第 **3 位（永恒少年）** 常用的人（首列「<功能> 常用的人（4 型名单）」+「第 3 位 · 玩伴轴」）→ 玩伴 / 一起玩得起来 + 摩擦（都不太负责）+ 做法；行 ⑧ **镜像轴** = 与本剖面互为镜像的类型（首列「互为镜像的人（<镜像类型>）」+ 小字「主栈 = 你的阴影栈 · 镜像轴」，如 INFJ ↔ ENFP）→ 极致互补（你缺的四格他全会、他缺的四格你全会）+ 摩擦（最容易被当成「我的另一半答案」；也最容易滑成「你管四格、我管四格」的永久分工，双方那四格都不再长）+ 做法（至少挑一格自己练，别把补位长期外包）。**分组标题必须点明这三行不是投射**——同类是共鸣与共谋，玩伴取第 3 位（八格里最不投射的一格），镜像是一条栈结构配对（theory-spec §3.4）。镜像那一型也会出现在前五行的某个名单里，**两处都保留**：前五行按单个功能分，本行按整条主栈说；导语里点一句以免读者以为是重复。
  - 依据：5 条低格位由本剖面推导 + 3 条结构轴（同类、玩伴、镜像），覆盖任何功能组合（奥卡姆；旧版 4 条硬编枚举必然漏项）。
