# 双人（恋人）关系分析报告规则（2026-09-07 新版）

> 本文件取代 `couple-dynamics.md`（旧八维度评分/天赋/四阶段/冲突/风险模板，已归档至 `examples/backup-2026-09-07/couple-dynamics.md`）。
> 视觉事实源 = `examples/mbti_sampleA_sampleB.html`（lint 双人口径 PASS）；组件 CSS 与 lint 双人口径规范见 `html-templates.md` §5；完整设计规格存档 `docs/2026-09-07-couple-report-design.md`（as-built v2.0）。

## 0. 定位与口径

- **目的**：读懂彼此差异 → 减少摩擦（诊断 + 药方），**只诊断模式、不判合分**
- **视角**：对称「你们 / A 和 B」，不预设读者方
- **机制**：逐功能对照；每根轴看「各自自比偏向」（A 用本人两版之比、B 用本人两版之比，互不换算）
- **语义**：大差值双面解读——摩擦 = 翻译成本，互补 = 分工资源；不把任何刻度当测量值
- **类型标签**：每人「最接近 X（仅供参考）」，MBTI 四字母不是身份证
- **数据完整性（硬前置，不可跳过，§0.1）**：双人报告**必须双方数据齐全**（各 8 项功能分数）才能生成；只有一方数据时降级为单人报告 + 一节「从你这方看到的关系模式」，**明确禁止**分析、推测缺席另一方的任何心理特征
- **语言**：遵循 writing-style.md 全部规则——读者画像（无学术基础、受过良好教育的年轻人，直观形象一次读懂）、比喻收缩原则（§4.1）、裸代码彩色 = 功能身份、具体化形式多样、防伤害措辞、去 AI 味
- **证据标签**：正文**不出现** ✅🔶⚪ 与「结论依据构成」统计行（与单人一致，2026-09-07）；证据地位进咨询师备注

## 1. 数据契约（换数据时改哪里）

所有图表由内联 `<script>` 从两个数据对象自动重算：

```js
const A = {Fi:...,Ni:...,Fe:...,Ti:...,Te:...,Ne:...,Se:...,Si:...};  // 甲方 8 分
const B = {Ti:...,Ne:...,Fi:...,Te:...,Ni:...,Si:...,Se:...,Fe:...};  // 乙方 8 分
```

1. 改 `A`、`B` 两个对象 → 雷达/四象限/四光谱全部自动重算
2. 光谱满偏系数 `K=256`：新数据最大 |log 比值| 明显不同则调 K，让最大落点贴近轨道端部
3. 四轴的 L/R 定义在 `renderBeam` 挂载参数：`Ne-Ni / Se-Si / Fi-Te / Fe-Ti`（L = 第一个功能在左，两端标签 = 轴词对，见 writing-style §2.1）
4. 四象限功能标签避让偏移表 `OFF`（8 个功能名偏移，手工定）
5. 象限分类表文字、光谱读数文案**需按新数据人工复核**（阈值语义：比值≈1 中立、1.2+ 温和、1.4+ 明显、2+ 强烈；最大错位按 |log 比值| 排序定）

## 3. 视觉件规格（内联 JS 驱动 SVG，零外部依赖）

> 双人报告**用内联 `<script>` 数据驱动**（与单人 09-07 静态 SVG 不同）：A/B 对象喂进脚本、图表自动重算——这是双人「换数据即生成」的刻意设计（§1 复现要点）。打印安全靠浏览器加载时渲染。功能身份色全报告常量，**与单人同一套**；人物编码：**实心 = A，空心/描边 = B**（颜色永远属于功能，不属于人——这是双人报告相对旧「颜色 = 人」的定稿变更）。

### 3.1 封面双人雷达
- 8 辐条序 `Fi,Ni,Te,Se,Fe,Ne,Ti,Si`（对置成轴 1-5/2-6/3-7/4-8）；viewBox 560×560，圆心 280，R=180
- 半径归一化（两人共用同一标尺，形状可比）：`r = R×(0.30 + 0.62×(v−min)/(max−min))`，min/max 取 16 个分的极值
- A 多边形：实线描边 + `rgba(31,95,102,.12)` 浅填充；B 多边形：虚线描边（`6 4`）、无填充、opacity .55
- 顶点圆点 = 功能身份色；外圈功能名同色（衬线 16 600，纸色描边光晕）；4 层参考环 + 8 辐条 #DCD6C8
- 图例（cover-legend）：「实线（浅填充）= A · 虚线 = B」+「重叠的部分是你们的共同底色，各自凸出的翅膀是互补的入口」

### 3.2 01 四象限矩阵
- X = A 分、Y = B 分，0–100 原始分线性映射；viewBox 560×560，pad 70
- 50 中线（虚线 #B9B29F）切四象限；对角虚线 = A=B 参考线（opacity .15），点到对角线距离 ≈ 差值
- 象限底色各 4% 透明（功能色）+ 四角角名：右上 = 共识区、左下 = 共同盲区、右下 = A 带 B、左上 = B 补 A
- 网格线 20/40/60/80；轴名「A 的分数 →」「B 的分数 →」
- 8 点：功能身份色实心圆 r8（opacity .85）+ 功能名标签（衬线 13 600 同色，按 OFF 表手工避让）
- 下方配「象限 → 含义」分类表（5 行：共识区/共同盲区/A 带 B/B 补 A/差距不大）+ 边界一句

### 3.3 02 单轨光谱条（每轴一条，核心件）
- 形态：每轴一条水平轨道（x0=96→x1=544，y=88）；两端 = 该轴两版（L 左 / R 右：功能代码 + 中文轴词）
- **落点映射（log 比值刻度）**：`offset = clamp(log(P[R]/P[L]) × K, −215, +215)` 像素，K=256；`x = 轨道中点 + offset`
  - 中点 = **平衡点**（两版相当 1:1），轨道上唯一标注的刻度（短竖线 #B9B29F，无文字）
  - 比值 > 1 落右侧（偏 R）、< 1 落左侧（偏 L）；对数刻度使 2:1 与 1:2 离平衡点等距
  - 满量程 ±215px ≈ log±0.84 ≈ 2.3:1
- 落点圆：A 实心 r9、B 空心 r8（bg 填充 + 2.6 描边）；颜色 = 各自偏向侧的功能色；A 标签在上「A · 偏X」、B 标签在下「B · 偏X」
- 两点间渐变带（左功能色→右功能色，30% 透明、rx6）：**纯视觉连接，不代表错位量**
- 读数口径：错位 = 「方向是否相反 + 各自倍数差多少」；两点间距 ≠ 错位量。**无刻度数字、无 2:1/1:2 参考线、轴下无图注**（机制解释只在章引言）
- 每轴固定结构：光谱图 → 自比读数（chart-note，「方向相反/同向 + 谁的 Ni 是 Ne 的 1.57 倍」式倍数表述）→ 摩擦点 → 互补点 →（关键轴配）场景块

### 3.4 其余件
- 速写卡（portraits）：双列网格（≤600px 单列）；顶角 A/B 色块标签（A 墨青底白字 / B 纸灰底深字）、两个功能色点 + 学术名 + 排名、一句话 desc、虚线上框内 MBTI 参考
- 场景块（scene）：左 3px accent 竖线 + 小标签 b + 衬线正文（与单人同款线型件）
- rel 定义列表（relg）：A 的雷区 / B 的雷区 / 你们的共同盲区（三键，斑马纹同款）
- 边界声明（bound-list）+ 附录得分对照表 + footer（均与单人同款 CSS 类）

## 4. 文案口径

- 人称对称「你们 / A 和 B」；读数用倍数表述（「Ni 是 Ne 的 1.57 倍」），**不用分差绝对值**
- 禁区：不写「你们合不合 / 要不要继续」；摩擦一律表述为「差异 + 可操作解法」；不指责任何一方
- 机制解释（log、实心空心含义、50 线性质）只出现在章引言或边界句，不重复在图下（语言密度规则）
- 场景示例：吵架 / 选目的地 / 搬家等「一起做的事」对照两人内心戏 + 双向「翻译」话术（给 A 的话术、给 B 的话术对称给）

## 5. 伦理与边界口径（体现在 05 边界声明 + footer，无独立伦理框）

新双人报告**不设独立伦理框**——伦理口径由封面定位句、05 边界声明、页脚临床句共同承载（与单人 09-07 的 07 边界 + footer 同构）。以下三条为**照录、不得改写**（lint 双人口径校验其子串）：

### 5.1 05 边界声明「不判决」句（bound-list 内）

> · 八维模型是理解差异的透镜之一，**不是「你们合不合」的判决书**；它只能帮你看清「你们的认知模式放一起会怎样」，不能替代真实的相处。

### 5.2 05 边界声明收束句「不判合分」（bound-list 末条，替代旧「非预测承诺」——四阶段推演已废弃）

> · **最后**：如果这份报告让你们更愿意理解对方、少一些「你怎么这样」，它就有用了。关系是做出来的，不是算出来的。

### 5.3 页脚临床句（footer .disc 照录）

> 荣格八维 · 双人关系分析 — 基于你们俩的测评分数做的理论分析。本报告不构成临床诊断，也不判断「你们合不合」。数据是快照，不是宿命；理解是开始，相处才是答案。

（05 边界声明完整五条、封面 lede 固定句「荣格八维理论——看见你们俩的认知模式…」为照录基线，见样例；换数据/换人物时边界条措辞可按语境微调但「不判决 / 不判合分 / 不构成临床诊断」三层含义不得删。）

## 6. 与单人报告的口径差异（防串）

| 维度 | 单人 | 双人 |
|---|---|---|
| 图表实现 | 静态内联 SVG（手写坐标，lint 可数） | 内联 `<script>` 数据驱动（A/B 对象自动重算，lint 查脚本结构） |
| 人物编码 | 功能身份色 | 功能色不变 + **实心 = A / 空心 = B**（颜色只属于功能） |
| 核心叙事 | 你一个人的坐标（四组对照=天平） | 你们俩的错位与搭法（逐功能对照 + 四轴光谱） |
| 判决红线 | 不构成临床诊断 | 另加**不判合分**（关系走向不由分数决定） |
| 证据标签 / 速览卡 / pull 锐评 / chapter-sub | 全废 | 全废（同单人 09-07） |
