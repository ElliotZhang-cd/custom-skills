## 1. 轴结构分析

> **为什么废弃"梯度分层"**：八项分数各自独立累加，按分数排序后"相邻两项"只是碰巧挨着，它们之间的分差不构成理论单位——旧版"Δ>8 切断层/梯队"由此废弃。荣格理论的结构单位是**四条功能轴**：互补功能对（直觉↔感觉、思考↔情感）＋ 态度一内一外。

### 1.1 合法的轴只有四条（配对规则）

| 轴 | 两端 | 管 |
|----|------|----|
| Ni—Se | 内倾直觉 ↔ 外倾感觉 | 感知 |
| Ne—Si | 外倾直觉 ↔ 内倾感觉 | 感知 |
| Fi—Te | 内倾情感 ↔ 外倾思考 | 判断 |
| Fe—Ti | 外倾情感 ↔ 内倾思考 | 判断 |

感知轴是 Ni—Se 与 Ne—Si 两条子轴的统称；判断轴是 Fi—Te 与 Fe—Ti 的统称。解读顺序：先看大类（判断 vs 感知总量、内倾 vs 外倾），再看每条轴内倒向哪端。

### 1.2 逐轴读法

对每条轴记录：两端分数、**倒向哪端**、差距多大、均衡还是失衡。倒向的一端是这条轴上你顺手的方向。

### 1.3 结构发现模板（逐项报告）

- **最强端**：八项里的最高分落在哪条轴、哪个方向 → 主导功能候选
- **主导轴倾斜幅度**：强端与弱端之差
- **配合轴（另一条意识轴）**：均衡还是失衡 → 决定辅助功能
- **两条阴影轴**：有无异常端（理论低位却实测明显偏高）
- **态度总量**：内倾四项 vs 外倾四项
- **判断 vs 感知总量**：情感+思考 vs 实感+直觉

### 1.4 从轴结构到类型推断

1. 最强端功能 = 主导功能候选 → 限定类型家族（如最强端为 Ni → INFJ/INTJ）
2. 配合轴哪端略强 → 辅助功能 → 在家族内定型（如 Fe 强于 Ti → INFJ 而非 INTJ）
3. 最终以 §2.3 打分表逐位验证，输出前两名候选 + 主观置信度

### 2.3 类型推断算法

1. **主导-劣势轴锁定**：找到最高分功能（候选主导）及其同轴相反态度功能。若相反态度功能为全局最低或次低 → 该轴为主轴，强证据。
2. **辅助-第三确认**：在剩余功能中，找到与主导同态度（内倾/外倾）相反的功能——该功能应为辅助；其同轴相反态度功能为第三。
3. **逐位置评分**：将 8 项实测分数与候选类型的 8 个位置理论预期对比，按下表量化打分。
4. **影子功能检验**：检查 5-8 位功能是否符合理论预期的低位。异常偏高的影子功能需要特别解释。
5. **奥卡姆剃刀排序**：按量化打分表累计解释成本，成本越低的类型越优先（见下表）。
6. **输出**：排名前两位的类型 + 主观置信度（见 §2.4）+ 匹配论据 + 偏离分析。

**量化打分表**（保证可复现：同一份分数跑两遍，top-2 候选与排序必须一致）：

| 评分项 | 计分 |
|--------|------|
| 8 个位置逐一比对：实测分数落在该位置理论预期区间内 | ✓ = 0 |
| 实测分数轻度偏离预期区间 | ≈ = 1 |
| 实测分数明显偏离（如影子位异常偏高、主导位低于第三位） | ✗ = 2 |
| 每个异常偏高的影子功能（5-8 位实测明显高于理论预期低位） | +2 |

- **解释成本** = 上述累计分。16 型全部计算，成本最低者为第一候选
- **平局**：成本差 <3 视为平局，用奥卡姆剃刀裁决（所需额外假设更少者优先）；仍平局 → 如实输出并列，置信度下调一档
- 打分过程在**咨询师备注**中汇报（附录 A 类型栈打分表已随结构废弃；备注含两候选的成本差与关键 ✓/≈/✗ 位置，不写入报告文件）

### 2.4 类型不确定性的诚实表达

- 使用"**主观置信度**"（如 55–65%），禁止单独使用"概率"一词；首次出现必须附固定说明：
  > "置信度是分析者把你的分数和不同类型的样子逐条对比后得出的主观估计，不是统计概率。它表示'在现有数据下，这个判断有多大把握'，而不是'你有百分之多少的可能性是这个类型'。"
- 必须输出前两名候选类型 + 各自的支持论据与解释难点
- 解释为何某一类型被优先排序（奥卡姆剃刀原理）
- 当与来访者的实际体验冲突时，以来访者反馈为准并调整置信度

### 2.5 阴影面（5-8 位）的通俗输出规则（输出到咨询师备注）

分析层使用完整 Beebe 位置（§2.2）；来访者报告正文**不出现原型名称**（新基线无画像章/压力小节——压力模式输出落点 = **咨询师备注**；若咨询师明确要求写入报告，只能以「你是不是也这样」场景块承载且不出现原型名）。

咨询师备注的推导与写作规则：
1. **素材来源**：候选类型第 5-8 位功能 + 实测中的异常项（异常偏高的影子功能、全局最低功能）
2. **输出内容**：压力下最可能冒出来的 1-2 个模式，全部 🔶 理论推断（备注口径）
3. **措辞公式**：压力情境 → 可能的表现 → "比如"具体场景 → 一句中性的应对提示（不教导、不开处方）
4. **禁忌**：禁止写成"你压力大时会变成 XX 型"（类型互换无实证依据）；禁止灾难化；禁止原型名称

常见映射（通俗版）：
| 实测结构 | 压力下的可能模式（🔶） |
|----------|----------------------|
| 第 6 位（"评论家"位）功能异常偏高 | 内心的挑剔声音变响——对自己、也可能对亲近的人，标准突然变得苛刻 |
| 第 4 位（劣势）+ 第 8 位双双垫底 | 平时被忽略的通道在压力下"宕机式"反扑：如 Se/Si 双低者可能突然身体垮掉、或对琐碎细节产生反常的执念 |
| 第 5 位（"对立"位）偏高 | 压力下可能出现与平时相反的态度：平时收敛的人突然抬杠、唱反调 |


## 3. 输入质量前置检查（在轴结构分析之前执行）

1. **完整性**：必须 8 项齐全、每项 0–100；缺项/超界 → 退回要求重发
2. **十分制护栏**：若 8 项全部 ≤10 → 不静默处理，反问确认是否为十分制量表
3. **扁平剖面检测**：全距（最高分−最低分）<10 → "本次测试区分度不足"，建议重测；所有推断降权
4. **作答质量检查**（纯数据模式识别，不是诊断）：
   - 全部 ≥85 或全部 ≤30，且全距 <10 → 可能存在极端应答或敷衍作答
   - 出现以上模式 → 在向咨询师汇报时警告，并在报告中弱化结论强度
