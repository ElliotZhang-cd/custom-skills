## 1. 语气总纲（最高优先级写作原则）

本总纲**高于本规范其余所有规则**，冲突时以此为准。

语气目标：**像真正为来访者着想、敢说真话的朋友**——平等、诚实、把来访者当作能承受真相的成年人，口语但克制、客观但不冰冷、不亲昵。读者是没有心理学背景的普通人，读完要能"看见"报告在说什么，而不是"看懂"一堆术语。

1. **冷静、直接**：先说结论再说理由，不绕弯、不堆情绪形容词。
2. **不说教、不奉承**：不用"你应该/你最好"指点，不用"你太棒了"夸奖；禁止安慰句式（"别担心"）、亲昵称呼、感叹号轰炸、轻慢承诺；成长空间用"现状 + 好处 + 代价 + 可以试着做"描述。
3. **好消息不夸大**：正向结果如实陈述，不拔高成"天赋异禀"。
4. **坏消息不回避**：该指出的短板、风险照说，用描述性语言，不回避也不灾难化。
5. **分析中立、建议利他**：分析保持中立客观；提建议站在来访者利益和处境一侧。
6. **宁可不舒服也不误导**：宁可让来访者短暂不适，也不给虚假安慰或误导性结论；不确定的一律标"可能/推测"。
7. 用"你"指称来访者；多主动语态和具体动词，少堆抽象名词。
8. **直白、形象**：每个心理学概念都要翻译成普通人日常能直接感受到的动作或状态——能用画面、动作、日常物件说的，不用抽象词；宁可啰嗦半句，不留一个术语。

## 2. 八功能命名表（正文唯一合法称呼）

**弃用一切器物比喻名**（价值罗盘、情绪天线等已列入 lint 禁词）。正文使用学术名，首次出现附一句白描：

| 学术名（代码） | 白描（一句，可按语境微调措辞但不得改变含义） |
|------|------|
| 内倾直觉（Ni） | 把零碎的信息慢慢攒成一个判断，常提前"感觉"到事情会往哪儿走 |
| 内倾情感（Fi） | 心里有一把"什么重要、什么对"的尺子，决定多由它来做 |
| 内倾思考（Ti） | 喜欢把道理追问到底，看它说不说得通，习惯把问题拆到根上 |
| 外倾思考（Te） | 盯着目标、效率和步骤，习惯把事情推着往前走到完成 |
| 外倾情感（Fe） | 容易察觉到别人的情绪和现场的气氛，自然会去照顾、去协调 |
| 外倾直觉（Ne） | 从一个点飞快地联想到一大片新的可能性 |
| 内倾感觉（Si） | 把过去的经历存成一套细致的记忆，从中得到熟悉和踏实 |
| 外倾感觉（Se） | 把注意力放在眼前正发生、身体正感受到的东西上，反应快 |

引用规则：
- 首次出现 = **学术名（代码）＋白描**，代码用灰色小字 `<span class="fn-code">`
- 之后 = 只用学术名（如"内倾直觉"），不再带代码
- 全篇比喻（任何比喻）≤2-3 处，且只在比喻真正照亮概念时才允许使用

### 2.1 功能轴 → 大白话（讲法统一）

**先讲两大类（轴的上位概念）**：**感知**＝直觉＋感觉，管你怎么接收信息（直觉跳着看：抓走向、抓重点、听懂话外音；感觉接着看：眼前、具体、此刻真实发生的）；**判断**＝思考＋情感，管你怎么拿主意（思考讲道理：逻辑、因果、对不对得上；情感看价值：什么重要、对不对得起人）。

轴 = 同一对心理活动的两个方向，一端内倾、一端外倾，互为互补。**合法的轴只有四条**，配对规则：功能互补（直觉↔感觉、思考↔情感）且态度相反（一内一外）。

| 轴 | 两端 | 管 |
|----|------|----|
| Ni—Se | 内倾直觉 ↔ 外倾感觉 | 感知 |
| Ne—Si | 外倾直觉 ↔ 内倾感觉 | 感知 |
| Fi—Te | 内倾情感 ↔ 外倾思考 | 判断 |
| Fe—Ti | 外倾情感 ↔ 内倾思考 | 判断 |

讲法模板："X 和 Y 是一条轴的两端：你 X 端强、Y 端弱——意味着你只走「……」这一头，「……」那一头几乎不用。"

**场景模板**：每条轴配一个**假设场景**——把同一情境放到两种方向的人面前（如看完同一场电影、商量同一个决定），写出各自会注意到什么、先做什么。对比画面比定义更好懂；分数不进场景。

**禁止**"梯队""断层""分数分层"这类排序叙事——八项分数各自独立累加，排序是人为的，相邻分差不构成理论单位。有意义的对比只有三种：轴内（同一功能的两个方向）、态度（内倾四项 vs 外倾四项）、功能类别（情感/直觉/思考/感觉各自加总）。

### 2.2 八位置原型 → 大白话（🔶 理论模型，无实证常模）

一个类型是八个位置，从最顺手排到最费力。**前四位是"平时的你"，后四位是"压力下的你"**：

| 位置 | 原型名 | 大白话 |
|------|--------|--------|
| 第一位 | 英雄 | 你最自然、最拿手、最认同自己的部分 |
| 第二位 | 父母 | 你用来照顾别人、帮别人做事的工具 |
| 第三位 | 孩子 | 放松时才玩得起来、有点孩子气、也容易在这里受伤 |
| 第四位 | 灵魂 | 最费力、最想回避，但压力或亲密关系里会冒出来 |
| 第五位 | 对手 | 压力下冒出来跟你唱反调（和第一位相反） |
| 第六位 | 批评者 | 内心的挑剔声（和第二位相反） |
| 第七位 | 恶作剧者 | 最不听使唤、关键时刻最容易搞砸（和第三位相反） |
| 第八位 | 恶魔 | 压力最大时才出现、破坏性最强（和第四位相反） |

原型名（英雄/父母/孩子/灵魂/对手/批评者/恶作剧者/恶魔）**不进正文**，仅附录可用并需引号＋一句解释；正文用右列大白话。涉及此框架的章节必须标 🔶 并声明"理论模型、无实证常模"。

### 2.3 类型只是名字（固定说明，类型章必附）

> 类型帮你快速定位，但它不能概括你的全部，也不能预测你的人生——类型学有已知的局限（二分简化、重测波动、学界争议）。下面按荣格理论展开的解读，才是这份报告的重点。

## 3. 硬性规则

- **R1**：代码（Fi、Ni……）只允许出现在两种地方：① 学术名后的灰色小字括注；② 可选阅读附录。正文其余位置禁止裸代码
- **R2**：每条抽象结论必须有**具体化支撑**，形式不限：场景、对话、细节、反问、实例（见 §4.2 多样性要求）
- **R3**：凡推测内容必须带"可能/推测"字样；禁止"你就是""你一定""你肯定会"
- **R4**：描述功能差异用"更自然 / 更省力 / 更费力"，禁用"优势/劣势/强/弱"评价词（"优势与成长空间"作章节标题除外）
- **R5**：每个章节性结论标注证据等级（见 §7）
- **R6**：报告正文**禁止出现**"咨询师""会谈""咨询中""建议你和咨询师讨论"等字样——报告只服务于来访者自我了解，不转介到外部关系
- **R7（术语零容忍）**：正文出现的每个心理学概念，必须翻译成普通读者日常能直接感受到的说法；术语只留在咨询师读的 reference 文件里。对照见 §6。这是正向规则——黑名单抓不住没列进去的词，只有这条总原则能保证不漏
- **R8（不给机制性解释）**：正文不解释分析是怎么做的——梯度怎么分层、打分表怎么算、阈值怎么定、归一化顺序等，只给"怎么读"的结果；机制与算法留在可选阅读附录。来访者看到的是"你最高的两项明显强过其余"，而不是"Δ>8 就是断层"

## 4. 去 AI 味与去程序员味规则

### 4.1 比喻纪律
全篇比喻总数 ≤2-3 处。比喻只用于真正抽象、难以直说的概念；能直说的一律直说。

### 4.2 具体化形式必须多样
禁止连续多段以"比如："开头。交替使用：
- **场景**：有地点、动作、对话片段的小画面
- **对话**：引用可能真实发生的两句话
- **细节**：具体的、可观察的行为
- **反问**：让读者自己对照
- **实例**：直接举例，不必冠以"比如"

### 4.3 结构有详有略
禁止所有小节同构（每节都"定义→解释→例子"、长度均匀）。重点张力展开写，次要内容一笔带过。

### 4.4 句式
- 少用"不是……而是……"对仗句（全篇 ≤2 处）和排比
- 句子长短交错；允许短句单独成段
- 避免空转的连接词（"值得注意的是""总而言之""换句话说"）

### 4.5 绝对禁词（工程/IT/系统类）
**以下词汇及其变形，报告正文任何位置禁止出现**：

> 系统、架构、机制、流程、输入、输出、通道、带宽、负载、算法、迭代、反馈、模块、组件、审查、监控、容器、支架、空转、宕机、重启、调试、程序、数据库、接口、回路、闭环、触发器、运算、处理器、默认设置、双核、双引擎

**例外**：电量、充电、能量 允许使用

### 4.6 真实感
鼓励使用具体数字、具体时间、具体物件，而非泛指。

## 5. 深度规范（功能互动动力学）

报告的分析单位是**功能之间的互动**，不是单个功能。

- **禁止清单式写法**：八个功能逐个点评、每个两三句
- **每份报告必须识别出 1-2 个"核心张力"**：两个高位功能之间的协作或摩擦，或高位与低位之间的结构性落差，并用完整段落展开
- **依恋章必须含一个"误解全过程"场景分解**：触发 → 内部解读 → 情绪 → 行为 → 对方可能的反应 → 你的再解读 → 循环
- **建议章每条 = 现状 + 理解（为什么会有这个模式）+ 可以试着做（含频次/场景）**
- 全文目标 6000-8500 字（结构含原型章与成长方向章时取上限）
- **分工原则**：图表与功能速览网格承载分数与对比；正文只说倾向、含义与场景——数字不进正文（R8 的姊妹条：不解释机制，也不罗列数据）
- **每章一句话结论框**：各章 h2 后用一句话给出本章结论（模板：「一句话：……」），全报告形成 速览卡 → 章结论 → 正文 的三级速读

## 7. 证据三级标签

| 标签 | 含义 | 正文标准措辞 |
|------|------|-------------|
| ✅ 研究支持 | 有同行评议的实证研究支撑 | "心理学研究一致发现……" |
| 🔶 理论推断 | 荣格/MBTI 理论体系内的演绎 | "根据人格类型理论……" |
| ⚪ 探索性假设 | 尚无实证对应的理论桥接 | "一种可能的解释是……（仅为推测）" |

- 标签以小徽章形式出现在小节标题旁
- 报告末尾附"结论依据构成"一行统计（与实际标签数一致，生成后数一遍再写）

## 8. 防伤害措辞（来访者无心理学基础，且可能处于情绪脆弱期）

1. 永远不把分数与价值挂钩："得分靠后 ≠ 有毛病"
2. 依恋、成长环境两章末尾必须附固定谦卑段落（见 §9.1）
3. 描述冲突/风险时用"模式"而非"人"作主语
4. 禁止灾难化预测：不说"必然分手/必然失败"，只说"需要留意的风险"

## 9. 固定文本块（照录，不得改写）

### 9.1 谦卑段落（依恋章、成长环境章末尾）

> 这一部分的内容全部来自分数的理论推测。你的真实经历和感受，只有你自己知道——如果哪里说得不对，以你的经历为准。如果某处内容让你有触动，可以留给自己慢慢消化，也可以和任何你信任的人聊聊。

### 9.2 阅读指南（报告开头，半页以内）

> **怎么读这份报告**
>
> 这份报告用荣格的一套理论来解读你的测试分数，讲的是你心里几种不同的做事方式。报告里每个重要结论旁边有一个小标记：✅ 表示有心理学研究支持；🔶 表示来自人格类型理论；⚪ 表示只是一种可能的推测。标着"推测"的地方，请只当参考。这份报告不是心理诊断。读的过程中如有疑问，可以在读完之后，把它当作一个了解自己的起点，慢慢想，不着急。

### 9.3 报告局限声明（"这份报告的局限"章节开头）

> 本报告基于这份测试分数的理论分析，不构成临床诊断，不作为任何重大决定的依据。测试分数反映的是你作答时的自我认知，可能受当时状态影响。如需正式评估，请寻求专业的心理评估服务。
