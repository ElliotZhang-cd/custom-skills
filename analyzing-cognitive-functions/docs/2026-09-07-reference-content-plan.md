### 2.1 hero 雷达图(SVG)

- `viewBox 0 0 380 380`,圆心 (190,190),R=132;顶点序 `Fi, Ni, Te, Se, Fe, Ne, Ti, Si`——对角(1-5/2-6/3-7/4-8)恰为四组同能力对照:Fi–Fe、Ni–Ne、Te–Ti、Se–Si
