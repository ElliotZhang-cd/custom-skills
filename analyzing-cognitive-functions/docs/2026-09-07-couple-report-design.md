## 0. 定位与口径（已对齐决策）

- **目的**：读懂彼此差异 → 减少摩擦（诊断 + 药方）
- **视角**：对称"你们 / A 和 B"，不预设读者方
- **机制**：逐功能对照；每根轴看"各自自比偏向"
- **语义**：大差值双面解读（摩擦 = 翻译成本；互补 = 分工资源）
- **红线**：只诊断模式，**不判合分**；不把任何刻度当测量值
- **类型标签**：A≈INFP/INFJ、B≈ENTP，仅参考

## 3. 视觉系统规格

### 3.1 基础
- 功能身份色（全报告常量）：`--fi:#c0392b --ni:#8e44ad --fe:#2980b9 --ti:#16a085 --te:#d35400 --ne:#e67e22 --se:#27ae60 --si:#7f8c8d`
- 人物编码：**实心 = A，空心/描边 = B**（颜色永远属于功能，不属于人）
- 字体：标题衬线（Noto Serif SC），正文/标签黑体；浅色纸质底 + 噪点纹理
- 打印：`@page A4`，`@media print` 去背景、`break-inside:avoid`、`print-color-adjust:exact`

### 3.2 封面 · 双人雷达
- 8 辐条顺序 `Fi,Ni,Te,Se,Fe,Ne,Ti,Si`（对置成轴：1-5、2-6、3-7、4-8）
- 半径归一化（两人共用同一标尺）：`r = R×(0.30 + 0.62×(v−min)/(max−min))`，min/max 取 16 个分的极值
- A 多边形：实线描边 + 浅填充；B 多边形：虚线描边、无填充
- 顶点圆点 = 功能身份色；外圈功能名同色
- 图例："重叠=共同底色，凸出的翅膀=互补入口"

### 3.3 01 · 四象限矩阵
- X = A 的分，Y = B 的分，均为 0–100 原始分线性映射
- 50 中线切四象限：右上=共识区、左下=共同盲区、左上=B 补 A、右下=A 带 B；角内文字标注
- 对角虚线 = A=B 参考线；点到对角线的距离 ≈ 差值
- 每点：功能身份色实心圆 + 功能名标签（手工避让偏移表 OFF）
- 下方配"象限 → 含义"分类表；已知边界：50 线是几何中点非"及格线"，Ti 贴线临界

### 3.4 02 · 单轨光谱条（核心规格）

**形态**：每轴一条水平轨道；两端 = 该轴两版（L 左 / R 右，功能色 + 中文短注）。

**落点映射（log 比值刻度）**：
```
offset = clamp( log(P[R] / P[L]) × K, −215, +215 )   像素，K = 256
x = 轨道中点 + offset
```
- 中点 = **平衡点**（两版相当，比值 1:1），是轨道上唯一标注的刻度（短竖线，无文字）
- 比值 > 1 → 落点在平衡点右侧（偏 R）；< 1 → 左侧（偏 L）
- 对数刻度的性质：2:1 与 1:2 离平衡点等距；倍数直觉对称
- 满量程：±215px ≈ log±0.84 ≈ 2.3:1（当前数据下 B 的 Ti/Fe=2.24 接近满偏）
- 落点圆：A 实心 r9、B 空心 r7.5，颜色 = 各自偏向侧的功能色
- 两点间渐变带（左功能色→右功能色，30% 透明）：**纯视觉连接，不代表错位量**
- **读数口径**：错位 = "方向是否相反 + 各自倍数差多少"；两点间距 ≠ 错位量
- 无刻度数字、无 2:1/1:2 参考线、轴下无图注（机制解释只出现在章引言）

**四轴当前读数**：
| 轴 | A 自比 | B 自比 | 方向 |
|---|---|---|---|
| Ne—Ni | Ni/Ne=1.57 偏预见 | Ne/Ni=1.14 偏发散 | 相反 |

| Fe—Ti | Ti/Fe=0.94 中立 | Ti/Fe=2.24 强烈偏 Ti | 相反（最大） |

## 4. 文案口径

-人称对称"你们/A和B"；读数用倍数表述（"Ni 是 Ne 的 1.57 倍"），不用分差绝对值
- 每轴固定结构：光谱图 → 自比读数 → 摩擦点 → 互补点 →（可选）场景块
- 禁区：不写"你们合不合/要不要继续"；摩擦表述为"差异 + 可操作解法"
- 机制解释（log、实心空心含义）只出现在章引言，不重复在图下

## 5. 复现要点（换数据时改哪里）

1. `couple_report.html` 内 `<script>` 顶部的 `A`、`B` 两个对象——所有图表自动重算
2. 满偏系数 `K=256`：若新数据的最大 |log 比值| 明显更小/更大，可调 K 让最大落点贴近轨道端部
3. 四轴的 L/R 定义在 `renderBeam` 挂载参数里：`Ne-Ni / Se-Si / Fi-Te / Fe-Ti`（L=第一个功能在左）
4. 象限分类表文字、光谱读数文案需按新数据人工复核（阈值语义：比值≈1 中立、1.2+ 温和、1.4+ 明显、2+ 强烈）
