## 1. 五维度定义与命名

BFI-2 五个维度。报告中**统一使用以下命名**：

| 报告用名 | 英文 | 核心含义（首次出现时的白描） | 子维度 |
|---------|------|---------------------------|--------|
| 外向性 | Extraversion | 你从外部世界（人、活动、互动）获取和消耗能量的倾向 | 社交、果断、活力 |
| 宜人性 | Agreeableness | 你在人际交往中倾向于合作、体贴和信任他人的程度 | 同情、谦恭、信任 |
| 尽责性 | Conscientiousness | 你在目标导向行为中表现出的自律、条理和可靠程度 | 条理、效率、负责 |
| 情绪稳定性 | Neuroticism (reverse-scored) | 你在日常生活中情绪波动的倾向。得分高意味着你多数时候心平气和，得分低意味着你对外界刺激的反应更敏感、情绪起伏更大 | 焦虑、抑郁、易变 |
| 开放性 | Openness to Experience | 你对新想法、新体验、审美和想象力的接受和欣赏程度 | 好奇、审美、想象 |

**命名规则**：
- 首次出现 = 学术名 + 白描（上表第三列），学术名用灰色小字 `<span class="fn-code">`
- 之后 = 只用学术名
- "负性情绪"或"神经质"**不得出现在报告正文**（统一用"情绪稳定性"）
- 高分的含义：情绪稳定性高 = 情绪稳定、不容易波动；情绪稳定性低 = 情绪敏感、容易波动

### 1.2 原始分 → z 分计算与第 4 域方向

**z 分一律由本 skill 计算**：用内置常模 `references/bfi2_norms_cn.json`（Zhang et al. 2022 Table 1），z = (原始分 − M) / SD，四舍五入到 2 位小数（判档口径见 §2.1）。**输入中的 z/等级/M/SD 列一律忽略**——它们可能来自其他常模或旧版本工具，不可信。

BFI-2 的第 4 域存在两种通行方向，取决于输入来源的输出约定：

| 输入 label 可能值 | 方向 | 本义原始分含义 |
|------------------|------|---------|
| `负性情绪` / `神经质` / `Neuroticism` / `N` / 未标注（默认） | BFI-2 原始方向 | 高 = 更敏感 |
| `情绪稳定性` / `Emotional Stability` / `ES` | 反向（bfi2_interactive.html 复制文本/导出 JSON 默认） | 高 = 更稳定（分数 = 6 − 原始分） |

**本 skill 内部统一按"情绪稳定性"方向解读**（因 `writing-style.md §6` 禁止正文出现"负性情绪/神经质"，且 §2.2 等级描述模板全部按情绪稳定性方向书写）。

**计算规则（Phase 0 执行）**：
1. 检查输入第 4 域 label 及子维度方向
2. **子维度恒为本义方向**：焦虑/抑郁/易变 3 项**始终**用 z = (score − M_facet) / SD 计算（高分=更敏感，见 §1.3），**不随第 4 域翻转而翻转**——bfi2_interactive.html 复制/导出中的子维度原始分已是本义方向，直接计算即可
3. 第 4 域为「情绪稳定性/ES」→ 该域 z = (score − M′)/SD，其中 M′ = 6 − M（负性情绪常模 M），SD 不变；不再做任何额外翻转
4. 第 4 域为「负性情绪/神经质」或未标注 → **旧格式输入，不得静默翻转**：先向用户回显警告并等待确认；确认后该域 z = (score − M)/SD **再取反**得稳定性方向 z
5. 两条路径计算出的稳定性方向 z 等价（(6−score)−(6−M) ≡ −(score−M)）；方向错误 = chart/正文 180° 反转（A001 即此 bug）。宁可对旧格式多问一次，不可静默处理
6. 未标注方向的输入：默认按本义方向处理，并把"第 4 域方向"列入 Phase 0 询问清单确认

### 1.3 方向语言规范（全链路统一，防符号歧义）

**问题根源**：第 4 域翻转成"情绪稳定性"方向后，其 3 个子维度（焦虑/抑郁/易变）的 z 也被取反——同一个数字存在两套解读语言（本义方向 vs 稳定性方向），来回翻译必然出错。

**统一规则**：
1. **全链路（z 分计算 → 报告文字 → 得分 JSON）只用一套语言：管线输出方向**（即：第 4 域用「情绪稳定性」方向，焦虑/抑郁/易变子维度用本义方向——不翻转，见 §1.2）
2. **维度层**：说"情绪稳定性"，**低 = 敏感**（z 负 = 比同龄人更敏感）
3. **子维度层（仅焦虑/抑郁/易变 3 项）**：z 为**正 = 敏感度高于同龄人**（更易担心/更易低落/更易波动）；z 为负 = 敏感度低于同龄人。**解读永远用"敏感度"作主语**，不用"焦虑高/抑郁低"这种裸方向词
4. **禁止混用**：正文不同时出现本义方向（"焦虑高"）和翻转方向（"稳定性低"）两套表述；速览卡/矛盾分析/咨询师备注一律按本规范措辞
5. **矛盾分析的触发判据**也按统一方向算：3 个子维度 z 极差 > 2 时（例：抑郁 +1.48 vs 易变 -0.52 极差 2.0）

**解读示例（管线方向下的正确读法）**：
- 焦虑 z=+0.92 → "对还没发生的事的担心程度，高于同龄人"
- 抑郁 z=+1.48 → "挫折后情绪恢复的速度慢于同龄人"（**不是**"有抑郁倾向"）
- 易变 z=-0.52 → "情绪切换频率低于同龄人——情绪来了不快翻篇，但也不反复无常"

**为何必须翻转**：若不翻转，一个焦虑 +1.42、抑郁 +1.72 的人（全场最敏感）会被 skill 解读为 z=+0.89 → "情绪稳定、心态好、遇事沉稳"——180 度相反。这正是 A001 报告中雷达图 z=+0.89 与正文 z=-0.89 符号翻转的根因。

## 2. 等级划分与描述模板

### 2.1 等级分档（基于常模 z 的正态近似，仅作粗略参考）

> 本表把 z 按正态分布粗略切 5 档，仅供报告中的**粗略参考**（⚪经验推测），**不是实证百分位**，且只在"相对所用常模人群"的意义下成立（常模选择见 §4.1，年轻来访者优先中国大学生常模）。主叙事（自比画像）不依赖本表。

| 档位 | z 分范围 | 正态近似（非实证百分位） |
|------|---------|-----------|
| 低 | z ≤ -1 | bottom ~16% |
| 中等偏低 | -1 < z ≤ -0.5 | ~15% |
| 中 | -0.5 < z ≤ 0.5 | middle ~38% |
| 中等偏高 | 0.5 < z < 1 | ~15% |
| 高 | z ≥ 1 | top ~16% |

**分档执行规则**：
- 判档前先把 z **四舍五入到 2 位小数**（与报告/工具展示的 z 一致，所见即所判），消除浮点尘埃导致的越界（如 0.5000000001 被推过档）
- 边界归属严格按上表：-0.5 归"中等偏低"，+0.5 归"中"，±1.0 归"低/高"（两侧不对称是有意设计，与 bottom/top ~16% 的口径对应）
- 分档仅由本表定义（bfi2_interactive.html 已不再内嵌分档/常模，只输出原始分）；任何工具算等级，均以本表为准

### 2.2 各维度等级描述模板

每个维度的输出 = 程度判断 + 2-3 句大白话描述 + "比如"具体例子。以下为描述骨架，按来访者实际分数填充具体例子。

> **等级判定（双层）**：
> - **常模层（第 1 章）**：用 §2.1 的 5 档标签 + z 分，标明常模人群（如"相对中国大学生样本"）；叙事回答"你在同龄人中什么位置"。
> - **自比层（第 2–3 章）**：按来访者 5 维度的**原始分**（1–5 均值）排序，判定每个维度相对来访者自己是"偏低 / 居中 / 偏高"，落到下方 3 桶模板；回答"你的内部格局与矛盾"，不依赖常模。

#### 外向性

- **偏低**：更可能从独处中恢复精力，社交之后需要安静时间回血。不是不会社交，而是社交对你来说是一件"耗电"的事。比如参加完一个聚会后，你可能需要一两个小时独自待着，才能把精力补回来。
- **居中**：独处和社交都能接受，更多取决于场合和当时的状态。你既可以享受和朋友在一起的时光，也能安然地一个人待着。
- **偏高**：更可能从与人的互动中获得能量，独处太久反而觉得没劲。比如让你一个人在家待一整天，你可能会觉得闷，想找人说说话。

#### 宜人性

- **偏低**：更倾向于直接表达自己的想法和需求，不太习惯迁就他人。你可能会被认为"有主见"或"不太好说话"，但在需要坚持立场的时候，你通常能做到。
- **居中**：大多数时候愿意合作和体谅，但涉及重要原则时也能坚持自己。
- **偏高**：倾向于优先考虑他人的感受和需要，愿意信任和帮助别人。你可能会被认为"好相处"或"体贴"，但有时可能会因为不好意思拒绝而感到为难。

#### 尽责性

- **偏低**：做事更随性灵活，不太喜欢被计划和条条框框束缚。你可能更喜欢"到时候再说"，但在需要赶截止日期的时候也未必完不成。
- **居中**：该认真的时候会认真，该放松的时候也不会给自己太大压力。
- **偏高**：做事有计划、有条理，对自己认定的任务会负责到底。你可能会被认为"靠谱"或"靠谱得有点较真"。

#### 情绪稳定性

- **偏低**：对外界刺激的情绪反应比较敏感，情绪起伏相对更大。你可能会因为一句批评低落好几天，或者因为一件小事焦虑不安。这不意味着你"有问题"，只是你的情绪系统更"灵敏"。
- **居中**：大多数时候情绪平稳，但遇到特别大的事情也会有明显的情绪波动。
- **偏高**：情绪比较稳定，不太容易因为外界的事情大起大落。你可能会被评价"心态好"或"遇事沉稳"。

#### 开放性

- **偏低**：更偏好熟悉和实际的事物，对抽象理论或新奇体验兴趣不大。你可能会被认为"务实"或"接地气"。
- **居中**：有些新事物让你好奇，有些则觉得"没必要"。你对兴趣范围内的事可以很投入。
- **偏高**：对新想法、新体验、艺术和美有比较强的兴趣。你可能会喜欢思考"如果……会怎样"，或者被音乐、绘画、文学之类的东西打动。

## 3. 子维度矛盾分析规则

### 3.1 何时触发

同一维度下三个子维度的 z 分极差 > 2 时，必须专门分析。

### 3.2 分析模板

```
你在 [维度名] 方面，整体得分 [等级]。但拆开来看，你的三个子维度表现并不一致：

- [高子维度]：[等级] → [一句话解读]
- [中子维度]：[等级] → [一句话解读]
- [低子维度]：[等级] → [一句话解读]

这说明：[一段综合解读，把"矛盾"解释为"有特定模式的敏感而非全面敏感"]
```

### 3.3 常见矛盾组合示例

| 矛盾模式 | 解读方向 |
|----------|---------|
| 情绪敏感性高 + 易变低 | 你的情绪波动主要来自焦虑和低落两个方向，而不是情绪本身反复无常。你一旦陷入某种情绪会比较持久，不容易快速切换。 |
| 尽责性高 + 效率低 | 你做事有条理、有计划（条理高），但在执行力和推动力上可能不太够。你能规划，但"开始做"这一步可能需要多一点动力。 |
| 开放性高 + 好奇低 | 你的开放性主要体现在审美和想象上，而不是对抽象概念或理论的好奇。你更容易被艺术和"画面感"打动，而不是"想法"本身。 |
| 外向性高 + 社交低 | 你的外向性主要体现在果断和活力上（比如做事主动、精力充沛），而不是特别喜欢社交场合。你可能有能量但不一定需要从人群中获得。 |

### 3.4 报告中的位置

子维度矛盾分析放在第 2 章（子维度画像）中，紧跟在该维度的子维度卡片之后。**不单独成章**。

## 4. 常模与文化差异提示

### 4.1 常模来源与选择

- **常模 = skill 内置数据**：`references/bfi2_norms_cn.json`（Zhang et al. 2022, *Assessment*, 29(6), 1262–1284 Table 1，5 维度 + 15 子维度 M/SD，1–5 条目均值刻度；程序化提取并逐项锚点验证）。**单一数据源、随 skill 迁移**——交互页的常模可能随版本迭代，skill 不读取交互页常模，输入只需原始分。**美国常模不参与默认计算**——受众多为中国年轻人，全链路默认只用中国常模。
- **Phase 0 询问清单让用户选常模**（未指定默认中国大学生）；输入带年龄/身份信息时按以下顺序判定（在读身份优先于年龄）：
  1. 来访者在读/近期在读（大学/高中）→ 对应学生常模；
  2. 25+ 且在职 → 员工常模；
  3. 其余（含 17–28 边界重叠者）→ 大学生常模，报告注明"按年龄就近选择，仅供参考"。
- **背景知识表**（报告注明样本详情时使用）：
  - 中国大学生（N=1194，17–28 岁，M=19.46）
  - 中国在职员工（N=486，M=29.38 岁）
  - 中国青少年（N=315，15–16 岁）——**仅维度层稳妥**：子维度 α 偏低（求知欲 .39、谦恭 .47 等），解释需谨慎
- 物质滥用治疗样本（n=765）**不收录**：临床人群、监督性施测偏差、部分子维度信度过低（求知欲 α=.28）。
- 报告须**注明所用常模人群**；常模层（第 1 章）回答"你在同龄人中什么位置"，自比层（第 2–3 章）不依赖常模。

### 4.2 报告中的处理

- 报告正文提及常模来源（可在第 1 章末尾或附录中）
- 补充一句文化差异提示：不同文化人群的自我评分存在「参照群体效应」，跨文化比较的方向和大小都不确定，因此**不做"你在中国同龄人中偏高/低"的判断**；分数更适合与身边同龄人对照理解
- **不放大文化差异**（避免让读者觉得"这个测试不准"），一句话带过即可

### 4.3 固定文本块（附录 B）

在"这份报告的局限"章节中照录：

> 本报告基于 Big Five Inventory-2（BFI-2）的测评数据，同时呈现两层信息：你相对同龄人的位置（z 分相对中国常模人群，Zhang et al., 2022），和你自身的内部格局与矛盾（自比）。常模为中国便利样本、非全国代表性，分数请与身边同龄人对照理解，而非绝对化的"高低"判断。

### 4.4 量表信效度与实测注意事项（中文版）

**信效度证据（✅研究支持，Zhang et al., 2022, *Assessment* 29(6), 1262–1284，中国四样本）**：
- 内部一致性：大学生/在职成人各维度 α 0.83~0.90，各子维度 α 0.66~0.85
- 跨文化结构效度：中美因子载荷模型一致性系数 0.87~0.97，五维度 + 15 子维度结构对中国样本同样成立
- 外部效度：与 BFI 对应维度相关 0.87~0.94

**含义**：五维度结构对中国来访者成立，**自比画像有效**；且有中国常模可用（见 §4.1），可算中国同龄人 z 分，不必再依赖美国常模。

**实测注意事项（写入咨询师备注，勿写入报告正文）**：
- **作答风格更保守**：中国样本 SD 普遍小于美国（中国两样本 SD≈0.66–0.70 vs 美国 0.75–0.88），更倾向选中间项、更少选极端项——中国常模下 z 的"±1"边界含义与美常模略有差异，判档时心里有数即可。
- **反向计分题阅读难度**：反向题用否定措辞，低学历/高风险样本中反向题交叉载荷高、主载荷下降——此类人群建议只做**维度层**解释，**子维度解释需谨慎**。
- **监督性施测偏差**：纸笔测验、同事在场时，尽责性得分易偏高、神经质得分易偏低（物质滥用样本即如此）——若来访者数据来自此类施测，尽责性可能高估、情绪敏感性可能低估。
