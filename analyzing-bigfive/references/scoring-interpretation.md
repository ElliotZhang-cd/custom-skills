## 1. 五维度定义与命名

BFI-2 五个维度。报告中**统一使用以下命名**：

| 报告用名 | 英文 | 核心含义（首次出现时的白描） | 子维度 |
|---------|------|---------------------------|--------|
| 外向性 | Extraversion | 你从外部世界（人、活动、互动）获取和消耗能量的倾向 | 社交、果断、活力 |
| 宜人性 | Agreeableness | 你在人际交往中倾向于合作、体贴和信任他人的程度 | 同情、谦恭、信任 |
| 尽责性 | Conscientiousness | 你在目标导向行为中表现出的自律、条理和可靠程度 | 条理、效率、负责 |
| 情绪稳定性 | Neuroticism (reverse-scored) | 你在日常生活中情绪波动的倾向。得分高意味着你多数时候心平气和，得分低意味着你对外界刺激的反应更敏感、情绪起伏更大 | 焦虑、抑郁、易变 |
| 开放性 | Openness to Experience | 你对新想法、新体验、审美和想象力的接受和欣赏程度 | 好奇、审美、想象 |

**命名规则**：
- 首次出现 = 学术名 + 白描（上表第三列），学术名用灰色小字 `<span class="fn-code">`
- 之后 = 只用学术名
- "负性情绪"或"神经质"**不得出现在报告正文**（统一用"情绪稳定性"）
- 高分的含义：情绪稳定性高 = 情绪稳定、不容易波动；情绪稳定性低 = 情绪敏感、容易波动

### 1.2 输入方向约定（第 4 域翻转规则）

BFI-2 的第 4 域存在两种通行方向，取决于评分工具的输出约定：

| 输入 label 可能值 | 方向 | z+ 含义 |
|------------------|------|---------|
| `负性情绪` / `神经质` / `Neuroticism` / `N` | BFI-2 原始方向 | 焦虑高 = 情绪敏感 |
| `情绪稳定性` / `Emotional Stability` / `ES` | 反向 | 稳定 = 心平气和 |

**本 skill 内部统一按"情绪稳定性"方向解读**（因 `writing-style.md §6` 禁止正文出现"负性情绪/神经质"，且 §2.2 等级描述模板全部按情绪稳定性方向书写）。

**Phase 0 必须执行方向检测**：
1. 检查输入第 4 域的 label
2. 若 label 属于 BFI-2 原始方向（含"负性情绪/神经质/N/Neuroticism"任一）→ **将该域及其 3 个子维度（焦虑、抑郁、易变）的 z 分全部取反**，label 改为"情绪稳定性"
3. 若 label 已是"情绪稳定性/ES/Emotional Stability" → 直接使用，不翻转
4. **翻转后必须回显确认**："检测到输入第 4 域为 BFI-2 原始方向（负性情绪），已将 z 分取反转为情绪稳定性方向。翻转后：情绪稳定性 z = [新值]，焦虑 z = [新值]，抑郁 z = [新值]，易变 z = [新值]。请确认。"

**这不是"修评分"**——评分工具原样输出，skill 在入口做一次性翻转。翻转只影响第 4 域及其 3 个子维度，其他 4 个域不受影响。

**为何必须翻转**：若不翻转，一个焦虑 +1.42、抑郁 +1.72 的人（全场最敏感）会被 skill 解读为 z=+0.89 → "情绪稳定、心态好、遇事沉稳"——180 度相反。这正是 A001 报告中雷达图 z=+0.89 与正文 z=-0.89 符号翻转的根因。

## 2. 等级划分与描述模板

### 2.1 等级阈值（基于 z 分）

| 等级 | z 分范围 | 百分位近似 |
|------|---------|-----------|
| 低 | z ≤ -1 | bottom ~16% |
| 中等偏低 | -1 < z ≤ -0.5 | ~15% |
| 中 | -0.5 < z ≤ 0.5 | middle ~38% |
| 中等偏高 | 0.5 < z ≤ 1 | ~15% |
| 高 | z ≥ 1 | top ~16% |

### 2.2 各维度等级描述模板

每个维度的输出 = 程度判断 + 2-3 句大白话描述 + "比如"具体例子。以下为描述骨架，按来访者实际分数填充具体例子。

> **等级合并规则**：§2.1 输出的标签是 5 档（低/中等偏低/中/中等偏高/高），但叙事段落为了行文顺畅，统一合并为 **3 桶**：
> - **偏低** = 低 + 中等偏低（z ≤ -0.5）
> - **居中** = 中（-0.5 < z ≤ 0.5）
> - **偏高** = 中等偏高 + 高（z > 0.5）
>
> 速览卡 / 仪表条 / 维度解释小节标题等"标签化"位置仍按 §2.1 写 5 档标签（高、中等偏高、中、中等偏低、低），不合并；只有叙事段落的"程度判断"按 3 桶落到下方模板。

#### 外向性

- **偏低（z ≤ -0.5）**：更可能从独处中恢复精力，社交之后需要安静时间回血。不是不会社交，而是社交对你来说是一件"耗电"的事。比如参加完一个聚会后，你可能需要一两个小时独自待着，才能把精力补回来。
- **居中（-0.5 < z ≤ 0.5）**：独处和社交都能接受，更多取决于场合和当时的状态。你既可以享受和朋友在一起的时光，也能安然地一个人待着。
- **偏高（z > 0.5）**：更可能从与人的互动中获得能量，独处太久反而觉得没劲。比如让你一个人在家待一整天，你可能会觉得闷，想找人说说话。

#### 宜人性

- **偏低（z ≤ -0.5）**：更倾向于直接表达自己的想法和需求，不太习惯迁就他人。你可能会被认为"有主见"或"不太好说话"，但在需要坚持立场的时候，你通常能做到。
- **居中（-0.5 < z ≤ 0.5）**：大多数时候愿意合作和体谅，但涉及重要原则时也能坚持自己。
- **偏高（z > 0.5）**：倾向于优先考虑他人的感受和需要，愿意信任和帮助别人。你可能会被认为"好相处"或"体贴"，但有时可能会因为不好意思拒绝而感到为难。

#### 尽责性

- **偏低（z ≤ -0.5）**：做事更随性灵活，不太喜欢被计划和条条框框束缚。你可能更喜欢"到时候再说"，但在需要赶截止日期的时候也未必完不成。
- **居中（-0.5 < z ≤ 0.5）**：该认真的时候会认真，该放松的时候也不会给自己太大压力。
- **偏高（z > 0.5）**：做事有计划、有条理，对自己认定的任务会负责到底。你可能会被认为"靠谱"或"靠谱得有点较真"。

#### 情绪稳定性

- **低（z ≤ -0.5）**：对外界刺激的情绪反应比较敏感，情绪起伏相对更大。你可能会因为一句批评低落好几天，或者因为一件小事焦虑不安。这不意味着你"有问题"，只是你的情绪系统更"灵敏"。
- **居中（-0.5 < z ≤ 0.5）**：大多数时候情绪平稳，但遇到特别大的事情也会有明显的情绪波动。
- **高（z > 0.5）**：情绪比较稳定，不太容易因为外界的事情大起大落。你可能会被评价"心态好"或"遇事沉稳"。

#### 开放性

- **偏低（z ≤ -0.5）**：更偏好熟悉和实际的事物，对抽象理论或新奇体验兴趣不大。你可能会被认为"务实"或"接地气"。
- **居中（-0.5 < z ≤ 0.5）**：有些新事物让你好奇，有些则觉得"没必要"。你对兴趣范围内的事可以很投入。
- **偏高（z > 0.5）**：对新想法、新体验、艺术和美有比较强的兴趣。你可能会喜欢思考"如果……会怎样"，或者被音乐、绘画、文学之类的东西打动。

## 3. 子维度矛盾分析规则

### 3.1 何时触发

同一维度下三个子维度的 z 分极差 > 2 时，必须专门分析。

### 3.2 分析模板

```
你在 [维度名] 方面，整体得分 [等级]。但拆开来看，你的三个子维度表现并不一致：

- [高子维度]：[等级] → [一句话解读]
- [中子维度]：[等级] → [一句话解读]
- [低子维度]：[等级] → [一句话解读]

这说明：[一段综合解读，把"矛盾"解释为"有特定模式的敏感而非全面敏感"]
```

### 3.3 常见矛盾组合示例

| 矛盾模式 | 解读方向 |
|----------|---------|
| 情绪敏感性高 + 易变低 | 你的情绪波动主要来自焦虑和低落两个方向，而不是情绪本身反复无常。你一旦陷入某种情绪会比较持久，不容易快速切换。 |
| 尽责性高 + 效率低 | 你做事有条理、有计划（条理高），但在执行力和推动力上可能不太够。你能规划，但"开始做"这一步可能需要多一点动力。 |
| 开放性高 + 好奇低 | 你的开放性主要体现在审美和想象上，而不是对抽象概念或理论的好奇。你更容易被艺术和"画面感"打动，而不是"想法"本身。 |
| 外向性高 + 社交低 | 你的外向性主要体现在果断和活力上（比如做事主动、精力充沛），而不是特别喜欢社交场合。你可能有能量但不一定需要从人群中获得。 |

### 3.4 报告中的位置

子维度矛盾分析放在第 2 章（子维度画像）中，紧跟在该维度的子维度卡片之后。**不单独成章**。

## 4. 常模与文化差异提示

### 4.1 常模来源

BFI-2 的常模基于 Soto & John (2017)，美国大学生与网络样本（N ≈ 2,000+）。

### 4.2 报告中的处理

- 报告正文提及常模来源（可以在第 1 章末尾或附录中）
- 补充一句文化差异提示：不同文化背景下的人群在某些维度上存在系统性差异（例如亚洲样本在宜人性和情绪稳定性的平均分通常略高于美国常模），解读时可以参考你身边同龄人的表现
- **不放大文化差异**（避免让读者觉得"这个测试不准"），一句话带过即可

### 4.3 固定文本块

在"这份报告的局限"章节中照录：

> 本报告基于 Big Five Inventory-2（BFI-2）的测评数据，常模参考自美国常模（Soto & John, 2017）。不同文化背景下的人群在某些人格维度上存在系统性差异，你的分数更适合与身边同龄人的表现对照理解，而非绝对化的"高低"判断。
