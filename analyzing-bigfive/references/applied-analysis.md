# 应用分析规则（职业匹配 + 压力应对 + 人际关系）

## 1. 职业匹配：五维度 → 霍兰德 RIASEC 映射

### 1.1 理论基础

依据 Barrick & Mount (1991) 元分析，大五人格与霍兰德 RIASEC 六种职业类型存在稳定的相关关系。

### 1.2 映射规则

| RIASEC 类型 | 核心特征 | 最相关的维度 | 高分有利 | 低分有利 |
|------------|---------|-------------|---------|---------|
| 现实型(R) | 动手操作、机械、户外 | 开放性（负向） | — | ✓ |
| 研究型(I) | 分析、思考、探索 | 开放性（正向） | ✓ | — |
| 艺术型(A) | 创造、表达、审美 | 开放性（正向） | ✓ | — |
| 社会型(S) | 帮助、教学、服务 | 宜人性（正向）+ 外向性（正向） | ✓ | — |
| 企业型(E) | 领导、说服、管理 | 外向性（正向）+ 尽责性（正向） | ✓ | — |
| 常规型(C) | 组织、规则、细节 | 尽责性（正向） | ✓ | — |

### 1.3 代码计算规则

1. 找出五维度中 z 分最高的 1-2 个维度
2. 按映射规则对应到 RIASEC 类型
3. 如果出现"混合"（如开放性高 + 尽责性高），输出两个代码（如 A-C）
4. 如果所有维度 z 分都在 ±0.5 内，输出"RIASEC 剖面居中——没有特别突出的职业偏好方向，可以结合兴趣和技能进一步探索"

### 1.4 各 RIASEC 类型的描述模板

#### 现实型(R)
你可能在需要动手操作、实际动脑的工作中比较自在。机械、技术、户外或需要实际操作的领域可能让你觉得舒服。不需要太多社交或抽象理论的工作节奏对你来说更合适。

#### 研究型(I)
你可能喜欢需要深入思考和分析的工作。面对复杂问题让你有探索的欲望，需要创造力和独立思考的环境可能让你如鱼得水。

#### 艺术型(A)
你可能在需要创造、表达和审美的工作中比较投入。灵活、有想象空间、允许你发挥个人风格的环境可能让你最舒服。

#### 社会型(S)
你可能在需要帮助他人、教学或协作的工作中比较满足。如果你做的事情能让你看到自己对别人的正面影响，你会觉得有意义。

#### 企业型(E)
你可能在需要领导、说服或推动事情向前的环境中比较自在。有挑战、有竞争、能看到成果的工作节奏可能让你最有干劲。

### 1.5 报告中的输出格式

```
［RIASEC 代码标签：如 "IA" 或 "S"］

文字描述 = 代码对应描述 + 来访者实际维度的具体化支撑 + 可能需要留意的方面

示例（开放性高 + 尽责性高）：
"你属于艺术-常规型（AC）。这意味着你既有创造力又能落地执行——
你可能适合那种既需要想象力又需要规范流程的工作，比如设计、编辑、
内容策划等。你既能想出好点子，也能把它做成成品。"
```

## 2. 压力应对：脆弱性与韧性因素

### 2.1 理论基础

基于 Lazarus & Folkman (1984) 的压力认知评价理论，结合大五人格与应对方式的研究（Connor-Smith & Flachsbart, 2007）。

### 2.2 脆弱性因素（高压力风险）

| 维度特征 | 脆弱性 | 触发场景 |
|----------|--------|---------|
| 情绪稳定性低 | 核心脆弱性——对压力的情绪反应更强烈、持续更久 | 不确定、失控、被否定 |
| 尽责性低 | 面对需要长期规划和自我管理的压力时容易失控 | 赶截止日期、多任务并行 |
| 外向性低 | 在需要寻求社交支持时不习惯主动求助 | 独自面对问题、长期孤立 |
| 宜人性高 | 过度承担他人的情绪和需求，容易忽视自己 | 人际冲突、别人求助 |
| 开放性低 | 面对需要灵活应变的场景时容易固守旧方法 | 环境突变、被迫改变 |

### 2.3 韧性因素（压力保护因子）

| 维度特征 | 韧性 | 具体表现 |
|----------|------|---------|
| 情绪稳定性高 | 核心韧性——情绪恢复快、不容易被搅动 | 遇到挫折能较快平复 |
| 尽责性高 | 通过计划和行动感获得掌控感 | 面对压力倾向于制定计划、逐步推进 |
| 外向性高 | 倾向于主动寻求社会支持 | 遇到困难会找人聊、找人帮 |
| 宜人性高 | 拥有更好的社会支持网络 | 平时积累的关系在困难时能帮上忙 |
| 开放性高 | 对新情境适应性强，能灵活调整预期 | 面对变化时能换一个角度看问题 |

### 2.4 报告中的输出规则

1. 识别来访者**最突出的 1-2 个脆弱性**和**最突出的 1-2 个韧性**
2. 脆弱性 ≠ 缺点，描述时用"特点"不用"问题"
3. 每条应对建议 = 现状理解 + 具体可操作的方法（含场景/频次）
4. 避免空泛建议（如"你应该放松"），给具体场景

### 2.5 压力应对建议模板

```
你面对压力的时候，最可能需要留意的是：
  ［脆弱性1 + 触发场景 + 具体建议］
  ［脆弱性2 + 触发场景 + 具体建议］

你面对压力的时候，已经拥有的优势是：
  ［韧性1 + 如何主动利用］
  ［韧性2 + 如何主动利用］
```

## 3. 人际关系模式

### 3.1 五维度×人际特征映射

| 维度 | 高分的社交特征 | 低分的社交特征 |
|------|--------------|--------------|
| 外向性 | 主动社交、喜欢互动、从人群中获取能量 | 社交偏被动、需要独处恢复能量、不讨厌社交但需要"充电" |
| 宜人性 | 愿意合作、善于体谅、避免冲突 | 更直接、不轻易迁就、能坚持立场 |
| 尽责性 | 可靠守约、做事有条理、对承诺负责 | 更随性灵活、不喜欢被规则束缚、临时变动也能接受 |
| 情绪稳定性 | 情绪恢复快、不容易因为关系中的波动大起大落 | 对关系中的波动比较敏感、需要更多安全感 |
| 开放性 | 喜欢深入的、有新意的对话、接受不同的观点 | 偏好熟悉的话题和相处方式、不太习惯"聊太深" |

### 3.2 报告中的输出规则

1. 基于来访者五维度组合，描述其在**亲密关系**和**普通社交**中的典型模式
2. 给出至少一个**具体场景**（不是泛泛而谈）
3. 如果情绪稳定性低 → 需要专门描述"当你在关系中感到不安时"的模式
4. 如果宜人性高 → 需要专门描述"你可能不太擅长拒绝"的模式
5. 如果尽责性高 + 宜人低 → 可能"对别人要求高、对自己更严格"

### 3.3 人际关系模板

```
在亲密关系中：
  ［描述典型互动模式 + 至少一个场景］

在普通社交中：
  ［描述典型社交风格 + 至少一个场景］

你可能需要留意的是：
  ［1-2 个潜在卡点 + 不是"你有问题"，而是"这种模式下容易遇到……"］
```
