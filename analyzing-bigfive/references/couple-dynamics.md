## 理论基础

- Karney & Bradbury (1995)：脆弱-应激-适应模型（Vulnerability-Stress-Adaptation Model）
- Gottman & Silver (1999)：四种关系末日骑士（批评、蔑视、防御、石墙）
- Malouff et al. (2010)：大五人格与关系满意度的元分析
- 相似-吸引效应（Byrne, 1971）：相似的人格特质与更高的关系满意度相关

## 1. 相似-吸引效应分析

### 1.1 差异量计算

对每个维度，计算双方 z 分的差值 Δ = |z₁ - z₂|：

| Δ 范围 | 相似度标签 | 解读方向 |
|--------|-----------|---------|
| Δ ≤ 0.5 | 高度相似 | 在这一维度上你们体验世界的方式接近，容易互相理解 |
| 0.5 < Δ ≤ 1 | 中度差异 | 你们在这一维度上有可见的差异，但可以通过沟通弥合 |
| 1 < Δ ≤ 2 | 显著差异 | 你们在这一维度上的差异可能经常带来"对不上"的感觉 |
| Δ > 2 | 高度差异 | 你们在这一维度上的体验可能截然不同，需要主动"翻译" |

### 1.2 报告中的输出

- 列出五个维度的 Δ 值和相似度标签
- 相似度高的维度 → 关系中的天然"默契点"
- 差异大的维度 → 关系中需要"主动沟通"的领域

## 2. 五维度差异评分与解读

### 2.1 各维度差异的特定含义

| 维度 | 差异大时的典型张力 |
|------|------------------|
| 外向性 | 一个需要社交充电，一个需要安静独处 → 对"周末怎么过"可能有分歧 |
| 宜人性 | 一个倾向于迁就，一个更直接 → 迁就的一方可能积累怨气，直接的一方可能觉得"你想太多了" |
| 尽责性 | 一个做事井井有条，一个更随性 → 生活习惯（整洁度、时间观念）可能成为摩擦点 |
| 情绪稳定性 | 一个情绪平稳，一个情绪起伏大 → 敏感的一方可能觉得"你怎么这么容易波动"，稳定的一方可能觉得"你怎么老是不开心" |
| 开放性 | 一个喜欢探索新事物，一个偏好熟悉 → 对"尝试新餐厅""旅行计划"等可能有不同态度 |

### 2.2 报告输出规则

对 Δ > 1 的维度，必须给出：
1. 差异描述（用大白话）
2. 一个具体可能发生的场景
3. 一个"翻译"建议（帮助双方理解对方的行为不是"针对自己"）

## 3. Gottman 高风险组合识别

### 3.1 高风险组合清单

以下组合被研究证实与更高的关系冲突和更低的满意度相关：

| 组合 | 风险机制 | 报告中如何提示 |
|------|---------|--------------|
| 双方情绪稳定性都低（z < -0.5） | 双方情绪波动都大，容易互相触发，修复能力都较弱 | "你们两人对情绪都比较敏感，一旦进入负面循环可能比较难自我修复。建议建立'暂停机制'。" |
| 双方宜人性都低（z < -0.5） | 双方都更直接、不太愿意退让，冲突频率可能更高 | "你们两人都倾向于直接表达、不太习惯迁就。这意味着你们可能'吵得快但好的也快'，但需要注意别把'直接'变成'尖锐'。" |
| 一方情绪稳定性极低（z < -1），另一方宜人性低（z < -0.5） | 敏感的一方觉得对方"不理解自己的感受"，直接的一方觉得对方"想太多" | "你们在情绪处理节奏上差异较大：一方需要更多安抚和确认，另一方可能觉得'没什么大不了'。这可能是关系中最需要刻意练习的地方。" |
| 双方尽责性差异 > 2 | 生活习惯和时间观念的差异可能导致持续性摩擦 | "你们在'过日子的节奏'上差异较大。一个可能觉得另一个'太随意'，另一个可能觉得'被管太多'。建议协商出双方都能接受的'底线规则'。" |

### 3.2 报告中的处理

- 只提示风险，**不预测分手**
- 措辞："可能带来挑战"而非"必然出问题"
- 每个风险点必须跟一个"可以怎么做"

## 4. 关系满意度预测

### 4.1 基于 Malouff et al. (2010) 元分析

与关系满意度最相关的维度（效应量排序）：
1. 情绪稳定性（负向关联最强：情绪越稳定，满意度越高）
2. 宜人性（正向：宜人性越高，满意度越高）
3. 尽责性（正向）
4. 外向性（正向但效应较小）
5. 开放性（效应最小）

### 4.2 满意度预测规则

```
综合评估基于：
1. 双方情绪稳定性水平（最重要）
2. 双方宜人性水平
3. 五维度相似度
4. 高风险组合数量

输出格式：
- 有利因素（3-5 项）："你们的关系中，……是一个天然的优势。"
- 需要留意的挑战（1-3 项）："在……方面，你们可能需要多花一点心思。"
- 不输出"你们一定会幸福"或"你们肯定有问题"
```

### 4.3 诚实度约束

- 人格特质只能预测关系满意度的约 10-15% 变异（诚实告知读者）
- 关系质量更多取决于沟通技巧、冲突修复能力和外部压力管理
- **报告中必须包含一句话**："人格特质只是影响关系的因素之一，不是决定性因素。你们的沟通方式和一起面对困难的态度，比分数更重要。"

## 5. 冲突模式预测

### 5.1 五维度×冲突触发

| 维度组合 | 最可能的冲突触发 |
|----------|----------------|
| 外向性差异大 | 社交需求不匹配：一方想出门一方想在家 |
| 尽责性差异大 | 生活节奏不同步：整洁度、时间观念、花钱方式 |
| 情绪稳定性低的一方 | 对批评或忽视特别敏感，可能过度解读中性行为 |
| 宜人性高的一方 | 长期压抑不满后"突然爆发" |
| 开放性差异大 | 对变化的态度：一方想尝试新事物另一方觉得"现在挺好的" |

### 5.2 报告输出

为每个 Δ > 1 的维度写一个**冲突场景对话**（如 MBTI skill 的 `.scene-box` 格式）：
```
场景：［可能发生的具体情境］
A（高一方）：［可能说的话/做的事］
B（低一方）：［可能说的话/做的事］
可能的卡点：［为什么双方都没恶意但对不上］
可以怎么做：［一个具体的沟通建议］
```

## 6. 沟通风格差异分析

### 6.1 沟通风格的两个核心维度

| 风格维度 | 由什么决定 | 差异大时的表现 |
|----------|-----------|--------------|
| 能量方向 | 外向性差异 | 一个喜欢"聊着解决问题"，一个需要"先想清楚再说" |
| 情绪基调 | 情绪稳定性差异 | 一个在沟通中情绪平稳，一个情绪起伏更明显 |

### 6.2 报告输出规则

1. 描述双方各自的沟通偏好（不是"谁对谁错"）
2. 差异大的地方给出"翻译卡"——帮助 A 理解 B 的行为，帮助 B 理解 A 的行为
3. 示例格式：
   - "当你（A）说'你想太多了'的时候，B 听到的好像是在否定 ta 的感受。你可以试着换成：'我知道这件事让你很难过，我们一起看看怎么办。'"

## 7. 伦理声明（双人报告开头照录）

> **这份报告基于双方的人格测评数据分析，旨在帮助你们更好地理解彼此的关系动态。**
>
> 人格特质只是影响关系的因素之一，不是决定性因素。你们的沟通方式和一起面对困难的态度，比分数更重要。这份报告不是对你们关系的"判决"，而是一个帮助你们了解彼此的工具。报告中任何让你觉得"说的不对"的地方，以你们的真实感受为准。
