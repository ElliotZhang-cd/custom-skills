# 通俗化写作规范（终端产品：来访者直接阅读）

本规范约束所有报告正文的语言。核心原则：**冷静、直接、不说教、不奉承**——像敢说真话的朋友，用经得起专业审视的措辞，给来访者被理解到的感受，同时不夸大、不回避、不误导。

## 1. 语气总纲（最高优先级写作原则）

整体基调：**冷静、直接、不说教、不奉承**——像一个真正为来访者着想、敢说真话的朋友。

- **好消息不夸大，坏消息不回避**：分数靠前的地方照实说，但不渲染成优越；需要留意的地方直接指出，不绕弯子、不软化到失真
- **分析时保持中立**：只描述倾向和模式，不替来访者下结论；**提建议时坚定站在来访者一侧**，给出具体、可试的方向
- **宁可让来访者一时不舒服，也不让 TA 被误导**：该说的风险照直说，但落在具体、可接受的分寸上，不灾难化
- 用"你"指称来访者，措辞**口语但克制、客观但不冰冷**，不亲昵
- 禁止：安慰句式（"别担心"）、夸奖句式（"你太优秀了"）、奉承、亲昵称呼、感叹号轰炸、轻慢承诺
- 指出成长空间时用描述性语言（现状 + 好处 + 代价 + 可以试着做），不用评判性语言
- 多用主动语态和具体动词，少堆抽象名词

## 2. 五维度命名表（正文唯一合法称呼）

**弃用一切器物比喻名**（情绪温度计、信任基石、效率引擎等已列入 lint 禁词）。正文使用学术名，首次出现附一句白描：

| 学术名 | 英文 | 白描（首次出现时使用） |
|--------|------|----------------------|
| 外向性 | Extraversion | 你有多喜欢和人打交道，从人群、热闹里获得劲儿，还是独处更能给你充电 |
| 宜人性 | Agreeableness | 和人相处时，你有多愿意配合、体谅、相信别人 |
| 尽责性 | Conscientiousness | 你做事有多自律、多有条理、多靠得住 |
| 情绪稳定性 | Neuroticism (reverse-scored) | 你平时情绪起伏大不大。分高＝多数时候心平气和；分低＝更容易被事情牵动情绪 |
| 开放性 | Openness to Experience | 你有多喜欢新东西、新想法、没试过的体验，愿不愿意尝鲜 |

引用规则：
- 首次出现 = **学术名＋白描**，英文用灰色小字 `<span class="fn-code">`
- 之后 = 只用学术名（如"外向性"），不再带英文
- 全篇比喻（任何比喻）≤2-3 处，且只在比喻真正照亮概念时才允许使用

**子维度命名**：直接使用子维度名（如"社交"、"条理"、"焦虑"），无需英文。

## 3. 硬性规则

- **R1**：英文术语只允许出现在两种地方：① 学术名后的灰色小字括注；② 可选阅读附录。正文其余位置禁止裸英文
- **R2**：每条抽象结论必须有**具体化支撑**（场景、对话、细节、反问、实例，见 §4.2）；**每个维度小节与每张子维度卡片至少落一个具体场景或实例**，不得只给抽象概括
- **R3**：凡推测内容必须带"可能/推测"字样；禁止"你就是""你一定""你肯定会"
- **R4**：描述功能差异用"更自然 / 更省力 / 更费力"，禁用"优势/劣势/强/弱"评价词（"优势与成长空间"作章节标题除外）
- **R5**：每个章节性结论标注证据等级（见 §7）
- **R6**：报告正文**禁止出现**"咨询师""会谈""咨询中""建议你和咨询师讨论"等字样——报告只服务于来访者自我了解，不转介到外部关系
- **R7**：正文不解释测量与计分机制——反向计分、常模换算、z 分算法、方向翻转均属咨询师侧知识；来访者侧只给"怎么读"的结果性指引（如"情绪稳定性越低越敏感；其子维度越高越敏感"），不给"为什么这样设计"的机制性解释
- **R8（术语零容忍）**：正文出现的每个心理学概念，必须翻译成普通读者日常能直接感受到的说法——"从人群、热闹里获得劲儿"不说"获取和消耗能量的倾向"，"做事有多靠得住"不说"目标导向行为"。术语只留在咨询师读的 reference 文件里，对照见 §6。这是正向规则——黑名单抓不住没列进去的词，只有这条总原则能保证不漏

## 4. 去 AI 味与去程序员味规则

### 4.1 比喻纪律
全篇比喻总数 ≤2-3 处。比喻只用于真正抽象、难以直说的概念；能直说的一律直说。

### 4.2 具体化形式必须多样
禁止连续多段以"比如："开头。交替使用：
- **场景**：有地点、动作、对话片段的小画面
- **对话**：引用可能真实发生的两句话
- **细节**：具体的、可观察的行为
- **反问**：让读者自己对照
- **实例**：直接举例，不必冠以"比如"

### 4.3 结构有详有略
禁止所有小节同构（每节都"定义→解释→例子"、长度均匀）。重点张力展开写，次要内容一笔带过。

### 4.4 句式
- 少用"不是……而是……"对仗句（全篇 ≤2 处）和排比
- 句子长短交错；允许短句单独成段
- 避免空转的连接词（"值得注意的是""总而言之""换句话说"）

### 4.5 绝对禁词（工程/IT/系统类）
**以下词汇及其变形，报告正文任何位置禁止出现**：

> 系统、架构、机制、流程、输入、输出、通道、带宽、负载、算法、迭代、反馈、模块、组件、审查、监控、容器、支架、空转、宕机、重启、调试、程序、数据库、接口、回路、闭环、触发器、运算、处理器、默认设置、双核、双引擎

**例外**：电量、充电、能量 允许使用

### 4.6 真实感
鼓励使用具体数字、具体时间、具体物件，而非泛指。

## 5. 深度规范

报告的分析单位是**维度之间的组合与互动**，不是单个维度。

- **禁止清单式写法**：五个维度逐个点评、每个两三句
- **每份报告必须识别出 1-2 个"核心张力"**：两个极端维度之间的协作或摩擦，或高位维度与低位维度之间的结构性落差，并用完整段落展开
- **子维度矛盾章**必须含具体解释（为什么总分和子维度表现不一致）
- **压力应对章**必须含"脆弱性→触发场景→具体应对"的完整链条
- **双人报告必须含场景对话**：至少一个完整的"可能发生的冲突场景"分解
- **应用章去重与加深**：第 4–6 章（工作/压力/人际）不得重新解释第 1–3 章已解释过的特质，只引用其结论往具体场景里落；每章至少含一个场景对话、一段"为什么"（带证据标签）、一句"什么情况下不成立"的边界
- 全文目标 **5000–6500 字（单人）/ 6000–7500 字（双人）**。取舍原则：**深度优先于广度、结构完整优先于篇幅铺陈**——每章只保留最高价值的 1–2 个洞察，删重复解释与过渡铺垫；核心张力、场景对话、证据标签、边界句是深度载体，不可为凑字数或删深度而牺牲；宁可短而准，不可长而泛（中文阅读约 500 字/分钟，6500 字 ≈ 13 分钟，已是无心理学背景读者的舒适上限）

## 6. 禁用词表 → 替换词表

| 禁用 | 替换 |
|------|------|
| 情绪温度计/信任基石/效率引擎/稳定性指标 | 见 §2 学术名表（lint 强制） |
| 神经质 / 负性情绪 | 统一用"情绪稳定性"（lint 强制） |
| 人格障碍 / 异常 / 缺陷 / 毛病 | 状态 / 特点 / 成长空间 |
| 焦虑型依恋 / 回避型依恋（裸用） | 可用，但首次出现必须紧跟白描解释 |
| 分数低 / 差 | "这项得分靠后"＋立刻补一句"得分靠后不等于能力差，只说明你平时较少用到这种方式" |
| 咨询师 / 会谈 / 咨询中 | 报告正文禁止出现（见 §3 R6） |
| 你肯定 / 你一定 / 你就是 | "你可能""你倾向于""一种可能的解释是" |

**抽象措辞 → 大白话对照（R8 翻译依据，非穷尽）**：

| 抽象/术语 | 大白话 |
|------|------|
| 获取和消耗能量的倾向 | 从人群、热闹里获得劲儿 / 独处更能充电 |
| 目标导向行为 | 做事 |
| ……的倾向 / ……的程度 | 有多喜欢 / 有多愿意 / 有多… |
| 审美 | 对新东西、新想法的欣赏 |
| 常模 / z 分 / 反向计分 / 方向翻转 | 不进正文（R7），仅局限声明出现 |

## 7. 证据三级标签

| 标签 | 含义 | 正文标准措辞 |
|------|------|-------------|
| ✅ 研究支持 | 有同行评议的实证研究支撑 | "心理学研究一致发现……" |
| 🔶 理论推断 | 大五理论体系内的演绎或理论桥接 | "根据大五人格理论……" |
| ⚪ 探索性假设 | 尚无直接实证对应的推论 | "一种可能的解释是……（仅为推测）" |

- 标签以小徽章形式出现在小节标题旁
- 报告末尾附"结论依据构成"一行统计（与实际标签数一致，生成后数一遍再写）

## 8. 防伤害措辞

1. 永远不把分数与价值挂钩："得分靠后 ≠ 有毛病"
2. 子维度矛盾章、双人报告的风险提示章末：谦卑段落已取消（见 §9.1），推测属性由逐条证据标签承担
3. 描述冲突/风险时用"模式"而非"人"作主语
4. 禁止灾难化预测：不说"必然分手/必然失败"，只说"需要留意的风险"
5. 情绪稳定性低的描述用"敏感/反应强"不用"情绪有问题/情绪不稳定"

### 9.1 谦卑段落（已取消，1206）
原要求子维度矛盾章、双人风险提示章末照录本段；阅读指南与逐条证据标签已覆盖同样提示，属第三次重复，应用户要求整体移除——勿再生成。原文存档：

> 这一部分的内容全部来自分数的理论推测。你的真实经历和感受，只有你自己知道——如果哪里说得不对，以你的经历为准。如果某处内容让你有触动，可以留给自己慢慢消化，也可以和任何你信任的人聊聊。

### 9.2 阅读指南（报告开头，半页以内）

> **怎么读这份报告**
>
> 这份报告基于"大五人格"理论——这是目前心理学界最广泛使用的人格模型之一——来解读你的测试分数。报告里每个重要结论旁边有一个小标记：✅ 表示有心理学研究支持；🔶 表示来自人格理论体系；⚪ 表示只是一种可能的推测。标着"推测"的地方，请只当参考。这份报告不是心理诊断。读的过程中如有疑问，可以在读完之后，把它当作一个了解自己的起点，慢慢想，不着急。

### 9.3 报告局限声明（"这份报告的局限"章节开头）

> 本报告基于这份测试分数的理论分析，不构成临床诊断，不作为任何重大决定的依据。测试分数反映的是你作答时的自我认知，可能受当时状态影响。报告同时呈现两层信息：你相对同龄人的位置（z 分相对报告标注的常模人群），和你自身的内部格局（自比）。常模样本有其局限，分数更适合与身边同龄人对照理解，而非绝对化的"高低"判断。人格特质只能解释关系满意度的一部分，关系质量更多取决于沟通技巧和一起面对困难的态度。

## 10. 组合卡与标签式结构（1206 新增）

1. 跨维度组合结论：必须写成组合卡（模板见 html-templates.md §3.3）——先并排给出两个维度的实际档位 + z 值，再用大白话解释组合含义 + 一个典型场景。措辞用"看起来 / 倾向于"；证据标签按立场挂 🔶（大五理论内演绎）或 ⚪（无出处），并计入报告末尾证据统计。
2. 档位词一致性：组合卡与速览卡结论中的档位词必须与 scoring-interpretation §2.1 一致；禁止与档位不符的简称（"中等偏低"不得简写成"低"）。
3. 第 6 章标签式结构：亲密关系 / 普通社交 用 .rel-label 引导；每块"描述在前、场景在后"，场景写入 .scene-box；场景属推测性质，标 ⚪。
4. "锐评"独立章节/板块已否决（1206）：不得设置专门的锐评章或锐评板块；章末锐评仅以 §10.7 锐评式拉引文形式存在，两者不冲突。
5. 语言密度（1206 返工教训）：目标读者没有心理学基础，正文为"直观形象地理解核心内容"服务——组件的读法只允许一行说明（chart-note/图例），正文不得复述组件用法（禁"下面这张表把…摆在一起"式旁白）；verdict 卡/组合卡给过的结论，正文只写"意味着什么、怎么做"，不重述；一处结论只带一个推测标记，禁止叠加免责（"供对照，不作预言"之后不再"都是可能"）；正文段 ≤3 句，场景对白除外。
6. 双人正文与单人同标准：每个抽象结论后面必须跟一个"比如"级的日常画面（谁在做什么、具体发生了什么），没有画面的结论改写到有画面为止——"晦涩"的根源几乎都是结论裸奔。
7. 锐评式拉引文（`.pull`，每章一条）：对本章做 ≤22 字（一行以内）的一句话锐评——言辞犀利、一针见血；必须落在具体行为或数据上（如"你是从来不开口"），敢下判断；禁对仗金句腔（"稳处省电弱处耗神"式）、禁"不是A而是B"排比堆叠、禁概括到谁都能套；只用本章素材，不引入新结论，不带证据标签；数量由 lint 把关（单人 7 / 双人 6）。

8. 去 AI 味基线（全文适用，按 humanizer-zh 清单自查）：禁"这是一个温和的好消息"式概括抒情、禁"愿你们……"祝愿腔、禁三段式排比堆叠、"不是A而是B"每段至多一次、破折号每段至多一个；改完大声读一遍，读着像电台稿就重写。比喻先自问一句：读者能一眼解出来吗？解不出来的比喻（如"给计划留活口"）宁可不用。
