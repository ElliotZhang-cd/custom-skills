# 设计规范：颜色语义与图形编码（v3 单人 + 双人共用）

> 本文是两份模板（`templates/report-template.html`、`templates/couple-report-template.html`）**颜色与图形编码的唯一规范**。
> 核心原则：**颜色只承担语义，绝不承担好坏**；语义分三层，互不混用。改任何 `:root` 色值必须同步本文与两个模板。
> 来源：2026-09-07 双人工具书设计稿（DESIGN_SPEC v1.0，已收编为本文件）；单人模板已按本规范补齐至满配。

## 1. 三层语义色板

### 1.1 纸面与中性层（版面骨架）

| 变量 | Hex | 用途 |
|---|---|---|
| `--paper` | `#FAF7F2` | 屏幕底色（奶油纸面） |
| `--paper2` | `#F2EBE0` | 次级底（说明条、引用卡） |
| `--card` | `#FFFDF9` | 卡片底 |
| `--ink` | `#2B2B2B` | 主文字 |
| `--soft` | `#5C564C` | 次级文字 |
| `--muted` | `#8A8378` | 注释/辅助文字 |
| `--line` | `#E6DECF` | 分隔线 / 卡片描边 |
| `--tick` | `#C9BFA8` | 刻度 / 虚线提示框 |
| `--neutral` | `#7A7484` | 无维度的中性强调（单人「隐形代价」卡左边线），不用于档位 |
| `--seg-bg` | `#F2EFE8` | 百分位带底色 |
| `--seg-border` | `#D3CCBD` | 百分位带描边 |
| `--seg` | `#E6E1D4` | 百分位带分段统一色（**五段同色，不分深浅**） |
| `--amber` | `#C98F2E` | 警示框（求助红线等），只用边框或强调 |

### 1.2 五维身份色（维度 = 单一语义，单人/双人完全一致，不可改）

| 变量 | Hex | 维度 |
|---|---|---|
| `--e` | `#E07A4F` | 外向性（珊瑚橙） |
| `--a` | `#7C9B6D` | 宜人性（暖绿） |
| `--c` | `#5A7CA6` | 尽责性（靛蓝） |
| `--es` | `#9A7FB8` | 情绪稳定性（雾紫） |
| `--o` | `#D9A441` | 开放性（金黄） |

> 语义：颜色 = 是哪个维度。维度色永不用于区分「人」。

### 1.3 人物身份色（仅双人）

| 变量 | Hex | 人物 | 线型 |
|---|---|---|---|
| `--pa` | `#1B6B5F` | A | 深青，实线 / 实心点 |
| `--pb` | `#C0531F` | B | 赭棕，虚线 / 空心点 |

> 语义：颜色 = 是哪个人。人物色只出现在「谁」的语境（头像、卡片边框、泳道人名、雷达轮廓、A/B 标签），永不用于「是哪个维度」。
> **双重编码**（青/棕 + 实线/虚线、实心/空心）保证黑白打印仍可区分两人。

## 2. 图形编码规则

| 语义 | 图形 |
|---|---|
| 水平 = 倾向程度 | 百分位五段带：远低/偏低/中间/偏高/远高 |
| 活跃档位（这个人在人群的位置） | 该段用**维度身份色**高亮（`color-mix 42%` + `inset 1.6px` 内描边）+ 档位词加粗着色 |
| 人群平均 | 虚线五边形（雷达 z=0 环）/ 子维度轨道刻度线（常模 M/5 处） |
| z 位置 | 游标 3px 竖条（单人用维度色；双人 A 实青条 / B 赭棕虚线条），无圆点 |
| 差异桥 | 一根带两个游标；左右卡边框 = 人物色；桥标题的 --dc = 面子所属维度色 |

> 雷达最内环（z = −2）保留 0.12R 最小半径：极端值不落圆心，避免多顶点重叠、轮廓自交（单/双模板同式，改一处必须同步另一处）。

## 3. 五段百分位带（唯一定义）

| 档位 | 百分位 | 段宽 |
|---|---|---|
| 远低 | <10% | 10 |
| 偏低 | 10–35% | 25 |
| 中间 | 35–65% | 30 |
| 偏高 | 65–90% | 25 |
| 远高 | ≥90% | 10 |

约束：中性层只用暖灰 token，不发明偏黄/褐新色，不给档位分配深浅；维度身份色只在活跃档出现；带底/描边比纸面深一档，避免与背景融为一体。

## 4. 打印规范（两模板一致，已内置）

- `@page{size:A4;margin:0}` + `body{padding:14mm 15mm}`（边距为 0 → 浏览器页眉页脚无处渲染，自动消失）
- 打印白底（屏幕纸色不印）；`print-color-adjust:exact` 强制保留全部数据色
- 结构线索不依赖颜色：A 实线/实心、B 虚线/空心
- `beforeprint` 展开所有 `<details>`；卡片/场景/刻度带/表格 `break-inside:avoid`；封面 `break-after:page`

## 5. 禁区（Do Not）

- ❌ 红/绿表示输赢、好坏、危险（一律换中性或语义色）
- ❌ 男蓝/女粉等性别化配色分配给 A/B
- ❌ 人物色画维度条、维度色画「谁」
- ❌ 给关系打匹配分、或用任何视觉暗示「谁对谁错」
- ❌ 大圆点/粗描边/高饱和填充抢数据（表达靠线型、高亮档、刻度）
- ❌ 透明叠同色让图与纸面融为一体（带底/卡底须深一档并带描边）

## 6. 已知实现差异备忘

- 桥刻度带：本规范要求「活跃段用维度色」；当前实现的桥带为中性带 + A/B 双游标（维度色用在桥的 `--dc` 上下文）。如需补齐，改 `bridgeHTML` 的 seg class，不动规范。
- 双人游标色：规范「A 实青 / B 赭棕」适用于同一条带同时出现两人的语境（桥带、共鸣带）；02/03 章每人独立的百分位条当前用**维度色**（`--dc`，该条只属于一个人，颜色语义仍是「哪个维度」，不违反「维度色不区分人」）。如需统一为人物色，改 `trackHTML` 的 marker 配色，不动规范。
