## 1. 15 子维度：含义 + 画面

**两列怎么用**：「含义」是这一项的准确定义（判断某个结论是否跑偏时看它）；「画面」是落到报告里的具体场景方向（写 behaviors / facet line 时看它）。
**触发条件**：分数明显（|z| ≥ 0.5，阈值见 `thresholds.json`）时才写该向画面；接近均值（|z| < 0.5）时**不要硬写**，改中性行为或换更极端的子维度。behavior 句式要求见 `writing-style.md` §4。

> ⚠️ **第 4 域方向**：焦虑/抑郁/易变三项**高分 = 更敏感**（本义方向，不翻转）；而第 4 域**维度分**是反向呈现的（高 = 情绪平稳）。详见 `scoring-interpretation.md` §1.3。

### 1.1 外向性

| 子维度 | 高分含义 | 高分画面 | 低分含义 | 低分画面 |
|---|---|---|---|---|
| 社交 | 喜欢和人待在一起，社交场合中如鱼得水 | 人多时来劲，主动张罗；一个人待久了闷 | 不太需要频繁的社交，独处也自在 | 群聊多数时候潜水；更愿和少数熟人在安静地方待着 |
| 果断 | 喜欢主导局面，愿意表达观点、做决定 | 开会先开口，抢话筒不怵 | 更倾向于跟随，不太习惯站出来拍板 | 讨论里先听再说；想好时话题已经过去 |
| 活力 | 行动快、精力充沛，喜欢忙碌的节奏 | 连轴转不累，闲下来难受 | 节奏偏慢，不太喜欢被催促或同时处理多件事 | 忙完一天要安静回血；连续社交几天会被掏空 |

### 1.2 宜人性

| 子维度 | 高分含义 | 高分画面 | 低分含义 | 低分画面 |
|---|---|---|---|---|
| 同情 | 容易感受到他人的情绪和处境，愿意提供帮助 | 别人难受会真的跟着难受；朋友的事当自己的事 | 不太容易被打动，更习惯理性地看待问题 | 更理性看问题，不太容易被打动 |
| 谦恭 | 尊重他人意见，不喜欢冲突或争强好胜 | 常把"都行、听你的"挂嘴边；矛盾先低头 | 更直接，不太介意表达不同意见 | 直接表达不同意见；不怕争 |
| 信任 | 倾向于相信别人是善意和可靠的 | 先信一个人，不先设防 | 更谨慎，需要时间观察后才愿意信任 | 要观察一阵才放心；不容易信 |

### 1.3 尽责性

| 子维度 | 高分含义 | 高分画面 | 低分含义 | 低分画面 |
|---|---|---|---|---|
| 条理 | 喜欢有序、有计划，东西有自己的位置 | 文件、收藏夹、计划表比多数人整齐 | 对环境秩序要求不高，能接受一定程度的混乱 | 对秩序要求不高，能接受乱 |
| 效率 | 执行力强，推动事情往前走 | 推动事情往前走，说到做到 | 推动力偏弱，可能需要外部压力才能开始行动 | 没截止日期的事能在清单里无限期躺着 |
| 负责 | 对自己的承诺和任务负责到底 | 答应的事记在心里会兑现 | 不太喜欢被责任绑住，更倾向于灵活应对 | 不喜欢被责任绑住，临期才动 |

### 1.4 情绪稳定性（⚠️ 高 = 更敏感，本义方向）

| 子维度 | 高分含义 | 高分画面 | 低分含义 | 低分画面 |
|---|---|---|---|---|
| 焦虑 | 容易担心还没发生的事，对潜在风险敏感 | 消息没被回能想出八种最坏可能；为还没发生的事排队上演 | 不太容易焦虑，面对不确定性比较平静 | 对不确定比较平静 |
| 抑郁 | 容易陷入低落情绪，遇到挫折恢复较慢 | 躺下后复盘白天每句话；低落时待得比别人久 | 情绪低落期较短，遇到挫折恢复较快 | 低落期短，恢复快 |
| 易变 | 情绪切换快，一会儿高兴一会儿低落 | 情绪切换快，一会儿好一会儿糟 | 情绪比较持久稳定，不太会因为小事剧烈波动 | 很少当场爆炸；火都烧在自己身上（内耗型） |

### 1.5 开放性

| 子维度 | 高分含义 | 高分画面 | 低分含义 | 低分画面 |
|---|---|---|---|---|
| 好奇 | 对抽象概念、理论和"为什么"感兴趣 | 为一个奇怪的问题查资料到半夜 | 对具体和实际的事情更感兴趣 | 对具体实际的事更感兴趣 |
| 审美 | 对艺术、音乐、自然之美有感受力 | 能一眼挑出配乐毛病，被一句话戳中很久 | 对"美"这件事不太敏感 | 对"美"不太敏感 |
| 想象 | 想象力丰富，喜欢"如果……会怎样"的思维游戏 | 常走神，脑内平行世界比现实热闹 | 思维偏实际，不太喜欢脱离现实的空想 | 思维偏着陆，不爱空想 |

## 2. 同域矛盾组合速查表

**触发**：同一维度下三个子维度 z 分极差 ≥ 2（阈值见 `thresholds.json`；按报告中四舍五入到 2 位的 z 计算）→ 必须专门分析。
**落点**：融入 02 章该维度块的 `line`（点出"总分和子维度不一致"）与 facets 行白描；矛盾最尖锐的组合在 03 章用优盲卡承载。**不单独成章**。
**分析模板**：

```
你在 [维度名] 方面，整体得分 [等级]。但拆开来看，你的三个子维度表现并不一致：
- [高子维度]：[等级] → [一句话解读]
- [中子维度]：[等级] → [一句话解读]
- [低子维度]：[等级] → [一句话解读]
这说明：[一段综合解读，把"矛盾"解释为"有特定模式的敏感而非全面敏感"]
```

### 2.1 外向性矛盾

| 组合 | 解读 |
|------|------|
| 总分低 + 果断高 | 你不太喜欢社交场合（社交低），但你在该站出来的时候其实能站出来。你不是不会领导，只是不太需要从人群中获得能量。 |
| 总分中/高 + 社交低 | 你的外向主要体现在做事主动、有活力上，而不是喜欢和人聊天。你有能量，但不一定需要"从人群中获取"。 |
| 总分低 + 活力高 | 你的活力更多体现在做事情上（比如专注投入），而不是"精力旺盛地到处社交"。 |

### 2.2 宜人性矛盾

| 组合 | 解读 |
|------|------|
| 总分中/高 + 谦恭低 | 你其实很能体谅别人（同情高、信任高），但在意见不合的时候不会一味退让。你不是不善良，而是有主见的善良。 |
| 总分低 + 信任高 | 你对他人的信任度其实不低，但你可能比较直接（谦恭低）或不太容易被打动（同情低）。你不是多疑，只是需要看到实际的证据才愿意配合。 |
| 总分高 + 同情低 | 你愿意合作和配合，但不太容易被他人的情绪影响。你不是不善良，而是更习惯用理性的方式处理人际问题。 |

### 2.3 尽责性矛盾

| 组合 | 解读 |
|------|------|
| 总分中/高 + 效率低 | 你做事有计划、有条理（条理高），但在"推动执行"这一步可能偏弱。你能规划，但开始做这件事可能需要多一点动力或外部压力。 |
| 总分中/高 + 负责低 | 你对自己认可的事情其实能做到有条有理，但不太喜欢被"应该做"的责任绑住。你更愿意做"想做的事"而非"该做的事"。 |
| 总分低 + 条理高 | 你对特定领域的秩序和计划有要求（比如工作文件整理得特别好），但整体生活节奏不太喜欢被严格规划束缚。 |

### 2.4 情绪稳定性矛盾

| 组合 | 解读 |
|------|------|
| 总分低（敏感）+ 易变低 | 你的情绪波动主要来自焦虑和低落，而不是情绪本身反复无常。你一旦陷入某种情绪，会持续比较久，不容易快速切换。你不是"喜怒无常"，而是"一旦不开心就很难马上好起来"。 |
| 总分低 + 焦虑低 | 你的情绪敏感性主要来自容易低落（抑郁高），而不是担心未来。你不是容易焦虑的人，但遇到挫折可能比较难恢复。 |
| 总分低 + 抑郁低 | 你的情绪敏感性主要来自容易担忧和紧张（焦虑高），而不是低落。你对未来的担心比对当下的失落更突出。 |
| 总分高（稳定）+ 焦虑高 | 你整体情绪恢复比较快（抑郁低、易变低），但对某些特定事情可能会比较紧张。你的"稳定"是整体性的，不是"什么都不在乎"。 |

### 2.5 开放性矛盾

| 组合 | 解读 |
|------|------|
| 总分高 + 好奇低 | 你的开放性主要体现在审美和想象上，而不是对抽象理论的兴趣。你更容易被"画面"和"感受"打动，而不是"概念"本身。 |
| 总分高 + 审美低 | 你的开放性主要体现在好奇心和想象力上——你喜欢思考新可能、新角度，但对艺术和"美"这件事不太敏感。 |
| 总分高 + 想象低 | 你的开放性主要体现在好奇和审美上——你喜欢理论和抽象思考，也能被艺术打动，但思维比较"着陆"，不太做天马行空的联想。 |
| 总分中/低 + 审美高 | 你可能不太喜欢抽象理论或新奇的体验，但对音乐、绘画、自然之美有特别的感受力。你的开放性是有"选择"的。 |

## 3. 跨条目组合 → 优势卡 / 盲区卡

**触发**：两条目组合后能推出一个有画面的结论时才写卡；单条极端不写组合卡。每条至少引用两个具体条目（子维度或维度，点名 + 档位），落"适合做什么/像什么场景"。档位词与 pct 一致。

**数量弹性（硬规则）**：数量由分数分布决定——组合明显时优势、盲区各 3–5 张；不明显（扁平剖面或只有 1–2 条突出线）时允许各 2 张，并在卡组前加一句降级说明（如"你的剖面比较平，下面是最相对的两组"）。**不得为凑数量硬写**（lint：常规 3–5，扁平剖面 2–5）。

### 3.1 优势卡方向
| 组合模式 | 卡的落点 | 参考标签 |
|---------|---------|---------|
| 审美/想象高 + 同情高 | 创意共情型：先理解人再表达，适合内容/设计/教育/用户研究 | 开放性·偏高 + 宜人性·偏高 |
| 外向性低 + 信任/同情高 | 天生的倾听者/树洞：安静的人常是最好的接住情绪的人 | 外向性·偏低 + 信任·偏高 |
| 条理高 + 审美高 | 有条理的审美：不光有想法还摆得整齐，接近"天赋"的日常 | 条理·偏高 + 审美·偏高 |
| 易变低（情绪不外泄）| 跟你相处安全、稳：不迁怒 | 易变·偏低 |
| 负责高 + 信任高 | 靠得住：答应的事会兑现，也愿意先信人 | 负责·偏高 + 信任·偏高 |
| 果断高 + 同情高 | 会替人争取的推动者 | 果断·偏高 + 同情·偏高 |

### 3.2 盲区卡方向
| 组合模式 | 代价落点 | 参考标签 |
|---------|---------|---------|
| 宜人性高 + 果断低 | 心软且不敢说不：接下不该接的活，"都行"说多别人真以为你都行 | 宜人性·偏高 + 果断·偏低 |
| 焦虑高 + 外向性低 | 压力没出口：不往外倒也不在热闹里释放，体内回放→失眠/拖延 | 焦虑·偏高 + 外向性·偏低 |
| 条理高 + 效率低 | 完美启动失败：八成力气做计划，两成说服自己开始 | 条理·偏高 + 效率·远低 |
| 想象不低 + 焦虑高 | 想象力给焦虑供弹药：能想到的最坏情况比别人多 | 想象·中间 + 焦虑·偏高 |
| 同情高 + 负责高 | 扛太多：把别人的事也当承诺 | 同情·偏高 + 负责·偏高 |
| 信任高 + 果断低 | 难拒绝+轻信：容易被消耗 | 信任·偏高 + 果断·偏低 |
| 好奇高 + 效率低 | 开坑多过填坑：收藏全是"以后看" | 好奇·偏高 + 效率·偏低 |

## 4. 亲密关系章推导规则

**泛化措辞（硬规则）**：不预设来访者恋爱状态。用"和在意的人相处时""当你们……""TA"等，单身/恋爱中都成立；「给伴侣的一段话」标题可写"给在意的人的一小段话"。**禁**通篇假设"你对象/你男朋友"存在。若来访者明确说明关系状态，从其语境。

本章全部标"基于分数推演"（lead 已含"如果某条不像你，以你的真实感受为准"）。

### 4.1 默认模式（patterns，3 条）
| 分数驱动 | 模式句方向 |
|---------|-----------|
| 同情高 + 果断低 | 你的爱/在乎是做事不是说：记得对方喜好却少说"我要什么"，常是付出更多的一方 |
| 焦虑高 + 外向性低 | 需要确认但要得含蓄：不安被包装成"没事我也在忙" |
| 外向性低 | 累时要独处回血，对方可能读成冷淡——充电方式不同最易误会 |
| 宜人性高 + 谦恭高 | 迁就型：改自己日程喜好去配合 |
| 信任高 | 先给信任、后知受伤 |

### 4.2 容易踩的坑（pitfalls，3 条）
| 分数驱动 | 坑方向 |
|---------|-------|
| 宜人性高 + 果断低 | 迁就到失联：久不表达需求→攒够失望突然抽离 |
| 焦虑高 + 外向性低 | 用胡思乱想代替直接问：内心连续剧 vs 一句"你是不是不太开心" |
| 外向性低 | 把独处说成"没事"：不解释的沉默像惩罚 |
| 负责高 | 把关系问题也当"我的责任"全揽 |
| 信任高 + 同情高 | 过度给予，边界失守 |

### 4.3 沟通话术（phrases，3 张，✗→✓ 对比）
| 场景 | ✗ 旧反应（按分数）| ✓ 替换句方向 |
|------|-----------------|-------------|
| 想说偏好时 | 「随便都行听你的」 | 「我更想 A，B 也可以，你定」（说一半好过不说） |
| 明明在意时 | 「没事你忙吧」 | 「你刚才没回消息，我有点在意，是在忙吗」（一句终结八百种猜想） |
| 需要独处时 | 消失式冷静 | 「我需要自己待 20 分钟，不是生气，一会儿来找你」 |
| 对方让你不舒服时（信任高）| 憋着帮对方找理由 | 「你那样说，我有点难受」 |
| 想答应又为难时（谦恭高）| 立刻"好啊" | 「让我看一眼安排再回你」 |

每张 phrase 的 badHint/goodHint 各 ≤14 字的括号点评。

### 4.4 给在意的人的一段话（partner）
第一人称，100–160 字，收束 2–3 个最突出的默认模式为"请你这样对我"式请求；以"有事直说，我也会同样待你"式对等承诺结尾。保留中文引号对。

## 5. 成长建议动作库（growth cards）

每条 = 编号「N · 」+ 动作名 + 具体做法（含频次/时长）+ tags「对应：<子维度> · <档位>」；可选「原理：…」。**原理字段只允许复用本库既有原理句（见下表括号内），库外组合不写原理**——禁止即兴编造机制解释。**措辞不评判，给可试的小动作**。数量同 §3 弹性规则：常规 3–5 条，扁平剖面 2–5 条（lint 强制）。

| 触发分数 | 动作方向 |
|---------|---------|
| 焦虑高 | 给焦虑设"办公时间"：每天固定 15 分钟专门担心；其余"到点再想"（预约着想比硬压有效） |
| 效率低 + 条理高 | 五分钟启动法：只要求开始 5 分钟，条理感会接手 |
| 社交低 + 孤独需求 | 维护 3 段深关系而非拓人脉：每月主动约那两三个人一次 |
| 谦恭高 + 果断低 | 练习说"半个需求"：小事先说"我更想…" |
| 抑郁高 | 低落时给身体先于给道理：散步/晒太阳/固定吃饭时间 |
| 想象高 + 焦虑高 | 把"最坏情况彩排"改写成"下一步做什么"清单 |
| 易变低（内耗型）| 给情绪一个出口物：写下来 / 对信任的人说 / 运动 |
| 负责高 | 区分"我的责任/别人的事"，允许不接 |
| 信任低 | 小步信任实验：每周把一件低风险小事交出去（托人办、不复查一次），记录结果与预期的差距 |
| 果断高 + 谦恭低 | 反对前先接一句：复述对方的点再说不（"你说的 X 是对的，同时……"）——赢道理也留住合作 |
| 易变高 | 给反应设缓冲：情绪上头时等 20 分钟再回消息、隔一晚再做决定 |
| 负责低 | 承诺外包：答应的事当场说给第三个人听或写进共享日历，用外部锚点替意志力 |
| 条理低 + 效率高 | 只整理"明天要用"的：每天收尾花 10 分钟，把明天要用的三样东西放到固定位置 |
| 想象高 + 条理低 | 想法落地卡：每个新点子只写一行"下一步动作 + 日期"，写完就回到手头的事 |
| 同情低（先讲道理型）| 对方低落时先不急着给方案：先问"你想要建议，还是想让我听你说" |
| 社交高（日程排满型）| 每周留一晚"无安排"：社交挤掉回血时间会透支，留白也是日程 |

成长章末必带模板固定的「什么时候该认真求助」callout（模型不写、勿删）。

## 6. 封面三标签与一句话

**chips（恰好 3 个）**：每个 = "modifier 的 role 者/型选手"式白描（6–10 字），取自三条最突出的维度线——通常覆盖"最强的一面 / 最软的一面 / 最张力的面"。例：外向性低+审美高→"安静的观察者"；宜人性高→"心软的共情者"；情绪稳定低+开放高→"绷着一根弦的梦想家"。**必须随分数变**，不同来访者不得雷同。

**oneliner（1–2 短句）**：点出全篇最大张力（常是某优势与其代价同源），如"你的温柔和你的紧张，常常来自同一份敏感"。句式："你把 X…，把 Y…。你的 A 和 B，常常来自同一份 C。"——不复用样例原句。

## 7. 扁平剖面文案策略（全维度 |z|≤0.3，meta.qualityNote 已填）

扁平剖面本身是信息：各项都接近人群平均。策略是"把平写成稳/广"，不硬找张力：

- **封面**：chips 走"均衡型白描"（如"什么都来一点的人""没有明显短板的多面手"）；oneliner 不写"最大张力"（没有），改写定性句——"你的剖面很平，大多数线都贴着人群中线：这说明适应面广，也说明没有哪一根线特别突出"式
- **优盲卡**：允许各 2 张（lint 下限），用"最相对"框架——相对自己而非相对人群："如果非要挑两组相对显眼的……"；正文明确这些组合的位置感比常模意义大
- **亲密/成长**：模式与坑正常写（关系语境下中庸分数也有组合含义）；成长卡优先挑"通用维护型"动作（睡眠/运动/表达练习），tags 挂对应子维度档位
- **降权口径**：qualityNote 已声明"作答可能不够认真，结论仅供参考"；正文避免笃定判断句（writing-style §1"判断敢下"在本剖面降级为倾向性描述）
- lint：strengths / flaws / growth 最低数量在扁平剖面放宽为 2（2–5）

## 8. 内容边界（与旧版一致）
- 每条结论可追溯到具体分数；推测用"可能/倾向于/常常"，不裸断言（禁词与措辞见 writing-style.md）
- 无心理诊断语气；情绪敏感用"接收得更清楚/更灵敏"，不用"有问题/不稳定"
- 不把分数与价值挂钩；"得分靠后"必补"不等于差"
