## 1. 子维度典型表现库（behaviors 素材）

每个子维度按"分数明显（|z|≥0.5）"给画面方向；接近均值（|z|<0.5）时**不要硬写该条表现**，改写中性行为或换更极端的子维度。behavior 句式要求见 writing-style §4。

### 1.1 外向性
| 子维度 | 偏高方向 | 偏低方向 |
|--------|---------|---------|
| 社交 | 人多时来劲，主动张罗；一个人待久了闷 | 群聊多数时候潜水；更愿和少数熟人在安静地方待着 |
| 果断 | 开会先开口，抢话筒不怵 | 讨论里先听再说；想好时话题已经过去 |
| 活力 | 连轴转不累，闲下来难受 | 忙完一天要安静回血；连续社交几天会被掏空 |

### 1.2 宜人性
| 子维度 | 偏高方向 | 偏低方向 |
|--------|---------|---------|
| 同情 | 别人难受会真的跟着难受；朋友的事当自己的事 | 更理性看问题，不太容易被打动 |
| 谦恭 | 常把"都行、听你的"挂嘴边；矛盾先低头 | 直接表达不同意见；不怕争 |
| 信任 | 先信一个人，不先设防 | 要观察一阵才放心；不容易信 |

### 1.3 尽责性
| 子维度 | 偏高方向 | 偏低方向 |
|--------|---------|---------|
| 条理 | 文件、收藏夹、计划表比多数人整齐 | 对秩序要求不高，能接受乱 |
| 效率 | 推动事情往前走，说到做到 | 没截止日期的事能在清单里无限期躺着 |
| 负责 | 答应的事记在心里会兑现 | 不喜欢被责任绑住，临期才动 |

### 1.4 情绪稳定性子维度（高=更敏感）
| 子维度 | 偏高方向 | 偏低方向 |
|--------|---------|---------|
| 焦虑 | 消息没被回能想出八种最坏可能；为还没发生的事排队上演 | 对不确定比较平静 |
| 抑郁 | 躺下后复盘白天每句话；低落时待得比别人久 | 低落期短，恢复快 |
| 易变 | 情绪切换快，一会儿好一会儿糟 | 很少当场爆炸；火都烧在自己身上（内耗型） |

### 1.5 开放性
| 子维度 | 偏高方向 | 偏低方向 |
|--------|---------|---------|
| 好奇 | 为一个奇怪的问题查资料到半夜 | 对具体实际的事更感兴趣 |
| 审美 | 能一眼挑出配乐毛病，被一句话戳中很久 | 对"美"不太敏感 |
| 想象 | 常走神，脑内平行世界比现实热闹 | 思维偏着陆，不爱空想 |

## 2. 组合 → 优势卡 / 盲区卡

**触发**：两条目组合后能推出一个有画面的结论时才写卡；单条极端不写组合卡。每条至少引用两个具体分数（子维度或维度），落"适合做什么/像什么场景"。档位词与 pct 一致。

### 2.1 优势卡方向
| 组合模式 | 卡的落点 | 参考标签 |
|---------|---------|---------|
| 审美/想象高 + 同情高 | 创意共情型：先理解人再表达，适合内容/设计/教育/用户研究 | 开放性·偏高 + 宜人性·偏高 |
| 外向性低 + 信任/同情高 | 天生的倾听者/树洞：安静的人常是最好的接住情绪的人 | 外向性·偏低 + 信任·偏高 |
| 条理高 + 审美高 | 有条理的审美：不光有想法还摆得整齐，接近"天赋"的日常 | 条理·偏高 + 审美·偏高 |
| 易变低（情绪不外泄）| 跟你相处安全、稳：不迁怒 | 易变·偏低 |
| 负责高 + 信任高 | 靠得住：答应的事会兑现，也愿意先信人 | 负责·偏高 + 信任·偏高 |
| 果断高 + 同情高 | 会替人争取的推动者 | 果断·偏高 + 同情·偏高 |

### 2.2 盲区卡方向
| 组合模式 | 代价落点 | 参考标签 |
|---------|---------|---------|
| 宜人性高 + 果断低 | 心软且不敢说不：接下不该接的活，"都行"说多别人真以为你都行 | 宜人性·偏高 + 果断·偏低 |
| 焦虑高 + 外向性低 | 压力没出口：不往外倒也不在热闹里释放，体内回放→失眠/拖延 | 焦虑·偏高 + 外向性·偏低 |
| 条理高 + 效率低 | 完美启动失败：八成力气做计划，两成说服自己开始 | 条理·偏高 + 效率·远低 |
| 想象高 + 焦虑高 | 想象力给焦虑供弹药：能想到的最坏情况比别人多 | 想象·中间 + 焦虑·偏高 |
| 同情高 + 负责高 | 扛太多：把别人的事也当承诺 | 同情·偏高 + 负责·偏高 |
| 信任高 + 果断低 | 难拒绝+轻信：容易被消耗 | 信任·偏高 + 果断·偏低 |
| 好奇高 + 效率低 | 开坑多过填坑：收藏全是"以后看" | 好奇·偏高 + 效率·偏低 |

## 3. 亲密关系章推导规则

**泛化措辞（硬规则）**：不预设来访者恋爱状态。用"和在意的人相处时""当你们……""TA"等，单身/恋爱中都成立；「给伴侣的一段话」标题可写"给在意的人的一小段话"。**禁**通篇假设"你对象/你男朋友"存在。若来访者明确说明关系状态，从其语境。

本章全部标"基于分数推演"（lead 已含"如果某条不像你，以你的真实感受为准"）。

### 3.1 默认模式（patterns，3 条）
| 分数驱动 | 模式句方向 |
|---------|-----------|
| 同情高 + 果断低 | 你的爱/在乎是做事不是说：记得对方喜好却少说"我要什么"，常是付出更多的一方 |
| 焦虑高 + 外向性低 | 需要确认但要得含蓄：不安被包装成"没事我也在忙" |
| 外向性低 | 累时要独处回血，对方可能读成冷淡——充电方式不同最易误会 |
| 宜人性高 + 谦恭高 | 迁就型：改自己日程喜好去配合 |
| 信任高 | 先给信任、后知受伤 |

### 3.2 容易踩的坑（pitfalls，3 条）
| 分数驱动 | 坑方向 |
|---------|-------|
| 宜人性高 + 果断低 | 迁就到失联：久不表达需求→攒够失望突然抽离 |
| 焦虑高 + 外向性低 | 用胡思乱想代替直接问：内心连续剧 vs 一句"你是不是不太开心" |
| 外向性低 | 把独处说成"没事"：不解释的沉默像惩罚 |
| 负责高 | 把关系问题也当"我的责任"全揽 |
| 信任高 + 同情高 | 过度给予，边界失守 |

### 3.3 沟通话术（phrases，3 张，✗→✓ 对比）
| 场景 | ✗ 旧反应（按分数）| ✓ 替换句方向 |
|------|-----------------|-------------|
| 想说偏好时 | 「随便都行听你的」 | 「我更想 A，B 也可以，你定」（说一半好过不说） |
| 明明在意时 | 「没事你忙吧」 | 「你刚才没回消息，我有点在意，是在忙吗」（一句终结八百种猜想） |
| 需要独处时 | 消失式冷静 | 「我需要自己待 20 分钟，不是生气，一会儿来找你」 |
| 对方让你不舒服时（信任高）| 憋着帮对方找理由 | 「你那样说，我有点难受」 |
| 想答应又为难时（谦恭高）| 立刻"好啊" | 「让我看一眼安排再回你」 |

每张 phrase 的 badHint/goodHint 各 ≤14 字的括号点评。

### 3.4 给在意的人的一段话（partner）
第一人称，100–160 字，收束 2–3 个最突出的默认模式为"请你这样对我"式请求；以"有事直说，我也会同样待你"式对等承诺结尾。保留中文引号对。

## 4. 成长建议动作库（growth cards）

每条 = 编号「N · 」+ 动作名 + 具体做法（含频次/时长）+ tags「对应：<子维度> <分数>」；可选「原理：…」。**措辞不评判，给可试的小动作**。

| 触发分数 | 动作方向 |
|---------|---------|
| 焦虑高 | 给焦虑设"办公时间"：每天固定 15 分钟专门担心；其余"到点再想"（预约着想比硬压有效） |
| 效率低 + 条理高 | 五分钟启动法：只要求开始 5 分钟，条理感会接手 |
| 社交低 + 孤独需求 | 维护 3 段深关系而非拓人脉：每月主动约那两三个人一次 |
| 谦恭高 + 果断低 | 练习说"半个需求"：小事先说"我更想…" |
| 抑郁高 | 低落时给身体先于给道理：散步/晒太阳/固定吃饭时间 |
| 想象高 + 焦虑高 | 把"最坏情况彩排"改写成"下一步做什么"清单 |
| 易变低（内耗型）| 给情绪一个出口物：写下来 / 对信任的人说 / 运动 |
| 负责高 | 区分"我的责任/别人的事"，允许不接 |

成长章末必带模板固定的「什么时候该认真求助」callout（模型不写、勿删）。

## 5. 封面三标签与一句话

**chips（恰好 3 个）**：每个 = "modifier 的 role 者/型选手"式白描（6–10 字），取自三条最突出的维度线——通常覆盖"最强的一面 / 最软的一面 / 最张力的面"。例：外向性低+审美高→"安静的观察者"；宜人性高→"心软的共情者"；情绪稳定低+开放高→"绷着一根弦的梦想家"。**必须随分数变**，不同来访者不得雷同。

**oneliner（1–2 短句）**：点出全篇最大张力（常是某优势与其代价同源），如"你的温柔和你的紧张，常常来自同一份敏感"。句式："你把 X…，把 Y…。你的 A 和 B，常常来自同一份 C。"——不复用样例原句。

## 6. 内容边界（与旧版一致）
- 每条结论可追溯到具体分数；推测用"可能/倾向于/常常"，不裸断言（禁词与措辞见 writing-style.md）
- 无心理诊断语气；情绪敏感用"接收得更清楚/更灵敏"，不用"有问题/不稳定"
- 不把分数与价值挂钩；"得分靠后"必补"不等于差"
