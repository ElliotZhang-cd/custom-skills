# 产品定义框架（初衷 + 定位四问 + 不可能三角 + 迁移成本）

## Overview

立项前的产品定义框架：用初衷分类确定"为什么做"，用定位四问明确"为谁、在哪用、解决什么、凭什么是我们"，用不可能三角与迁移成本三层检查取舍，产出定位声明与放弃清单。

## When to Use

**用：**
- 新项目/新产品/新功能立项，写 PRD 第一章（背景与目标）时
- 产品定位模糊、团队争论"该先做什么"、需求评审吵不出优先级时
- 产品方向反复漂移、定位多次改写但问题依旧时（诊断用）
- 评估新产品 vs 替代方案（**含公司内部旧功能**）的切入价值时
- AI 产品/Agent 类产品做场景选择与目标取舍时

**不用（Don't use for）：**
- 已进入执行/迭代阶段，问题在实现细节、数据指标、运营策略——该做执行审查而非重新定义
- 纯信息查询（"XX 产品的定位是什么"）——检索不是决策
- 单一角色的内部工具/一次性脚本——定义成本高于收益

## 流程（按序执行，每步有完成标准）

### 步骤 1 — 列目标（初衷）清单
列出产品发起人最原始的出发点，标注类型：**解决具体问题 → 提升效率 → 服务人群 → 推广理念 → 销售资源**（越靠前越可能产生长期价值）。
- 完成标准：目标清单 + 类型标注齐全

### 步骤 2 — 检查主次结构
确定唯一主目标，其余为次；能用一句话说清产品价值。
- 完成标准：写出一句话价值声明
- 判停：若多目标无主次 → 输出"目标冲突诊断"（列出互相拉扯的具体决策场景），停下讨论取舍，不进入步骤 3

### 步骤 3 — 过定位四问
1. **为谁**（用户定位）：目标用户是谁？**不是谁**？买单者/使用者/受影响者是否同一人？
2. **在哪用**（场景定位）：什么情境下想到它？高频日常工具还是特定场景方案？
3. **解决什么**（价值定位）：核心价值是什么？**用户原本愿意为此付出多少**（钱/时间/资源）？
4. **为什么是我们**（竞争定位）：与替代方案——**含内部旧功能**——差异在哪？可持续吗？

- 完成标准：四问各有一句话答案；第①问含"不是谁"与角色拆分；第③问含用户原本成本；第④问含内部替代品
- 判停：任一问答不出 → 定位未完成，补证据（访谈/数据/竞品走查）后再进步骤 4

### 步骤 4 — 检查不可能三角与迁移成本
- **目标不可能三角**：广大基数、高频行为、付费意愿三者难以同时满足，必须**主动放弃一角**（写死放弃哪一角）；双模块求解（如"工作+发现"）通常失败
- **迁移成本三层**：入口迁移（从哪开始）、心智迁移（按什么逻辑组织）、责任迁移（系统主动推送改变责任感知）。必须找到"不靠新系统就无解"的场景才能击穿迁移成本；旧系统最大的优点是"可预期"
- 完成标准：写死放弃的一角 + 迁移成本三层各自的壁垒与击穿场景

### 步骤 5 — 输出定位声明并设置改写纪律
产出一句话定位声明 + **放弃清单**（明确不做什么）；约定"下次改写定位时，必须先说明上一次遗留的矛盾是否解决"。
- 完成标准：定位声明 + 放弃清单 + 改写纪律三条齐全

## 常见陷阱

1. **多目标无主次**：每个决策被多目标牵引而摇摆，且后续所有环节的问题都可追溯至此（产品目标冲突是系统性失败的源头）
2. **定位改写不补缝**：每次改写都有理由，但前一次的矛盾从未解决，缝越积越大
3. **假装求解不可能三角**：双模块方案内部自洽，但用户感知是打扰——被当成广告，要求关闭成为高频反馈；后期放弃大包大揽、只保留"首页为空即无紧急依赖"单一心智后，留存显著提升
4. **通用痛点不够痛、深度变定制**：想做所有人的入口，又难替任何一类人做透（SaaS vs To C 两难）
5. **指标进场收束定位**：定位向可计量部分靠拢（曝光/点击/AI 调用），真正深的用户价值被挤出
6. **内部替代品被忽视**：旧系统路径"肉眼扫视、手动标记、特意置顶"就能应付时，用户不迁移——肌肉记忆获胜；历史积累（内容/习惯/关系）不构成护城河，可能被新范式抽象、吸收和绕过

## 边界

- **主观题 vs 客观题**：闭源/开源、DAU/塔尖是主观选择，无关真伪，选完走到底；逡巡不定比选错更伤
- **定位 ≠ 命名/口号**：定位是取舍后留下的方向，检验法是四问皆可一句话回答
- **框架盲点**：定位问题的归因可能混合品类风险（同类产品都难时，定位未必是主因）；技术语境变化可能让部分约束过时（如模型成本下降后，实时性不再是硬约束）；用户价值优先的假设在组织使命多重时不总是成立

## Verification Checklist

- [ ] 一句话价值声明（主目标）已写出
- [ ] 定位四问各有答案，含"不是谁"、用户原本成本、内部替代品
- [ ] 不可能三角已主动放弃一角（写死）
- [ ] 迁移成本三层已列出，且有"不靠新系统就无解"的击穿场景
- [ ] 定位声明 + 放弃清单 + 改写纪律已输出
