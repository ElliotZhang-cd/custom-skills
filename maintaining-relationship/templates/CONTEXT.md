# 关系分析卷宗

这套文档的术语表。存在的理由：没有它，同一个概念会在五份文档里有三到四个名字（"一句话带走"/"一句话结论"/"摘要"；"本周动作"/"即时行动"/"行为练习"/"一次复制"），读者无法判断哪句话是结论、哪句话是证据。

**用法**：复制到工作区根目录，删掉不适用的条目，随会话更新。术语一旦定下，所有产出只用这个词。

## Language

**A / B**:
A = 用户本人（`platform_id = meta.owner_id`）；B = 伴侣（`wxid_*`）。判定只按 `meta.owner_id` + `sender_account_name` 核对，不按昵称、不按话多话少。
_Avoid_: 我/他（正文用第二人称"你"和第三人称"他"，只在方法与锚点处用 A/B）

**卷宗**:
按 agent 划分的分析正文（冲突/成长/追踪/期待/未来），只承担证据与论证，**不产出动作**。
_Avoid_: 报告、分析文档

**入口**:
工作区根目录 `README.md`。全系统唯一能产出动作与判断的地方，倒金字塔：标题即断言 → 一句话 → 三个数 → 动作 → 理由。
_Avoid_: 首页、索引、index

**档案**:
`relationship-file.md`。跨会话记忆，只存"说过什么、学到什么、卡在哪"，**不存判断**。
_Avoid_: 记忆文件、日志

**动作**:
一个具体行为，必须带时间与场景，A 自己就能做。**全系统任何时刻只有一个当周动作**，位于入口 §1。
_Avoid_: 建议、行动项、练习、清单（这些是证据层的分层建议，不是动作）

**分层建议**:
卷宗里成组的建议（即时行动 / 长期元原则 / 边界约定 / 行为练习 / 行动清单）。保留作证据，**不构成多个动作**。
_Avoid_: 动作（混用会导致一次会话出现三个"本周动作"）

**事实 / 推理 / 推测**:
证据三级。事实=原文可查；推理=由原文推出、链条可复述；推测=单向线索或外部常识。凡未标级别的结论视为事实级，这是错误的默认。
_Avoid_: 置信度高/中/低（"中"曾分别指事实中、推理中、单方来源中）

**单方来源**:
仅有 A 的口述、线上无对应原文。可作事实（"A 说了这句话"是事实），不可作对 B 的判定。
_Avoid_: 口述、未经证实

**锚点**:
`消息 id` 或 `日期 + 短引`，用于把结论指回 `message.content` 原文。段落摘要不是锚点。
_Avoid_: 引用、出处、证据编号

**日常层 / 结构层**:
日常层=关系当下的温度（分享、返场、亲密、摩擦降级）；结构层=关系是否在往前动（知情权、风险能否被说出口、A 是否有第三人）。两层独立计分，不可互相抵消。
_Avoid_: 表层/深层（这两个词常指"事件表象/心理机制"，与去留无关，必须区分）

**档位**:
去留的四档之一：维持 / 观察 / 暂停 / 结束。由日常层与结构层共同决定，硬红线一票否决。
_Avoid_: 阶段、状态、评级（"修复期"是阶段，不是档位）

**观察档**:
日常 ≥3 且结构 ≤1。日常照旧、**不降承诺**，但设到期日。区别于暂停档（要降承诺）。
_Avoid_: 等待期、观望期

**硬红线**:
越界且隐瞒 / 蔑视常态化 / 系统性隐瞒需求 / 安全红线。任一触发直接进结束档，不看分数。
_Avoid_: 底线（"底线"常指 A 的期待清单，含义不同）

**正向条件**:
已被原文验证的、能让 B 打开的具体情境（如"他的事 + 你只提问"）。只由成长 agent 识别，未来 agent 只引用、不重新识别。
_Avoid_: 优点、好的地方、加分项
