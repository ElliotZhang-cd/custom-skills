# 双人报告工作流（D1–D4）

> 本文件是双人报告**流程与数据绑定的唯一出处**：七节结构、每节放什么数据、组件与占位符绑定。机制唯一出处 `references/couple-theory-spec.md`（下称 couple spec）；图形几何见 `references/couple-visual-spec.md`；token↔markup 契约见 `assets/report-couple-template.html` 头部注释。第 0 步模式判定见 `SKILL.md`；第 1–2 步（校验与判型）见 `references/workflow-single.md` 与 `references/typing-procedure.md`。

### 双人模式工作流（情侣双方；D1–D4 严格按序）

**理论地基**：`references/couple-theory-spec.md`（下称 couple spec）是双人机制的唯一来源。本节只绑定"何时、何地、用哪个组件、多少条 / 什么结构"，机制一律见 couple spec 对应节。

#### D1 输入校验（先于一切分析）

- 必选：两组八维分数。每人八项之和 = 406（容差 ±0.05）、单分 0–121.8，违反 → 停止并报告输入异常（Stop rules 双人条款）。
- 同源前提（couple spec §1.1）：输入两组分数一律视为出自同一测评工具及版本，不做不同源分支；若实际工具/版本确有不同，由生成方在对话层说明，报告内不设可比性保留句。
- 可选输入（类型标签 / 双方单人报告 / 年龄或人生阶段 / 测评工具与日期 / 称谓）按 couple spec §1.2 处理：仅用于交叉校验与去重，禁止据此重做单人画像；类型标签与分数推导冲突时以上游推导为准并暴露冲突。
- 称谓：有则用称谓，无则"甲方/乙方"（按输入顺序，全文一致；禁止类型代码当称谓）。

#### D2 单人推导与层级决定

- 双方各自执行第 1–2 步（校验与判定），得到各自的类型、八功能堆叠（毕比位置）与置信度。
- 层级决定（couple spec §3.2–3.3）：**功能层**内容无论置信度永远执行；**栈层**内容仅中/高置信完整执行。任一方低置信（含双方均低）→ 全文按该方首选类型展开栈层内容，不再附降级行、不做候选不变性检验；备选类型只由第 0 节配置卡「其余可能」一行注承载（不列备选类型完整堆叠），配置卡与边界声明标注"含低置信推定"。禁止为规避而强行单判。

#### D3 写栈校验 + 六透镜（couple spec §3.1 Step 3.5、§4）

- 任何集合运算/命中判定之前，**逐字写出双方八位堆叠**（位置·原型·功能-态度）；后续每条命中线、每个块归属标注可回查的位置号。禁止复用任何上下文或示例中已算过的集合。
- 功能块划分（双方意识面/甲意识面·乙阴影面/乙意识面·甲阴影面/双方阴影面）先行于 P 模式判定；四块并集必须恰为 8 个功能-态度且两两不交，不满足即停止并报告推导错误。
- 六透镜①→⑥依次执行；未命中的 P 模式与四类交叉不展开。
