# 文案与禁区规则（copy-rules）

生成报告时，本文件与 theory-spec（单人）/ couple-theory-spec（双人）同时生效。theory-spec 管"说什么是对的"，本文件管"怎么说"；**两处冲突时以 theory-spec（双人模式下为 couple-theory-spec）为准**。单人报告的术语白话以「六、术语白话表」为准，机制定义一律见 theory-spec 对应节，本文件不复述；双人报告的固定文案唯一出处是 couple-theory-spec §5（见「五、双人报告增补」）。

## 一、语气规则（persona 的可执行落地）

1. **结论先行**：每章第一句即**章级一句话结论**（本章唯一结论块，写法规则 1）——必须是判断句（如"你最可能是 INTJ，证据相当扎实。"），禁止铺垫和寒暄。
2. **直说不绕**：坏消息（区分度低、疑似 loop、grip 信号）照常写，但只陈述事实与含义，不渲染。禁用"很遗憾 / 不得不说 / 但别担心"这类缓冲话术。
3. **不说教**：禁止"你应该 / 你必须 / 你要学会"。建议统一用"可以试试 / 更值得做的方向是"。
4. **不奉承**：禁用"优秀 / 天赋异禀 / 人中龙凤"类词。描述优势用功能术语，如"主导功能分化良好"。
5. **外行翻译纪律（术语三档制）**：
   - **甲档：原样保留、不加注**——功能码（Ni / Te / Se / Si / Ne / Ti / Fe / Fi）、八位置原型名（英雄 / 父母 / 永恒少年 / 阿尼玛……）、类型码（INTJ 等）。可作任何句子成分，不跟白话注。
   - **乙档：保留、只作括号注、不得作句子主词**——分化、能量投注 / 力比多流向、补偿、投射、张力、对立转化、个体化、超越功能、偏向五层、意识面 / 阴影面、意识轴 / 阴影轴、主导 / 辅助 / 第三 / 劣势功能、loop、grip。句子主词一律用人话，术语作为括号注跟在人话之后，格式固定 `人话（术语）`。例："你最不熟练的那一面在压力下接管（劣势功能）"。同一术语全篇只在首次出现带此括号注；白话含义见「六、术语白话表」。
   - **丙档：术语不出现**——讲不清的机制直接用人话，术语一律不写。丙档只删展示性解释，类型判定与置信度推导不受影响。
   节标题、表格表头、卡片标签、图注等非句子成分不受本约束；结构位 (阴影) 标注、位置锚点、书名号引用等非句中术语注不受本条管辖（括号注细则见写法规则 9 R3）。
6. **第二人称，句子短**：每句只装一个因果（写法规则 9 R2），报告不设成段行文（写法规则 9 R1）。
7. 报告里不给读者看理论引用标记；但生成过程中每句实质论断必须能指回 theory-spec 的具体条目，交付前按 `references/qa-checklist.md` 逐项核对。
8. **图表优先**：能用表格/卡片/图/组件呈现的不写段落，**不得用成段文字承载本可图形化的关系**；凡属六类结构关系的内容，一律图形化（在准入判据允许的图位内），不得用成段文字承载（通则见写法规则第 11 条）。
9. **颜色三铁律**：①功能码与功能中文名一律染功能文本色——**全位置无例外**：章级结论块、要点行、三标签、失衡信号、置信度理由、卡片标题与正文，每次出现都要包裹（统一写法 `<span class="fn" style="color:var(--ni-text)">Ni</span>`；映射唯一出处 stacks.json `function_colors_text`，浅色功能色作小号文字的 WCAG AA 加深变体）；**图形形状**（条形、圆点、渐变轨道、描边）用 `function_colors` 原色；②章级结论块内关键词染赭红（`.hl`，每处 1–2 个）；③数值只加粗不上色。
10. **新术语首次出现的白话**：乙档术语的固定白话以「六、术语白话表」为唯一标准（超越功能 / 对立转化 / 偏向五层等逐条见该表；双人报告见 couple-theory-spec §5.2）——本规则不再复述，生成时照表取用。

## 二、写法规则（怎么写）

以下为建设性规则，与禁区章节共同生效。目标：结构化、结论为主、直观形象；理论内容按写法规则 3（单人：理论注 ≤1 句）与「五、双人报告增补」（双人：不设理论注与依据行）处理。

1. **结论块**：每章第一个组件是加粗结论块——**自包含的完整句**（1–2 句）：功能 + 分数证据 + 机制/含义一次说全，单独抽出来读不需要上下文也能懂；用 `.concl` 组件（`assets/report-template.html`）。它是本章唯一的结论块（语气规则 1 的章级一句话结论即此块）；02B 每条轴、03 章总结的加粗小结属组件内文字（规则 9 S3），不算第二个结论块。
2. **要点行**：结论块下的 bullet，每条**完整短句**（有主语，不写电报体）、绑定本章结论块中的分数/分差/位置；每条只装一个因果（规则 9 R2）；每章 ≤3 条，可为 0 条则省略。用 `.points` 组件。三个以上并列一律拆成要点行（规则 9 R4）。
3. **理论注**：理论白话与术语白话一律装进灰字小注（`.theory-note`，前缀 ▸；即 theory-spec 所称"灰字理论注"），随文放置，**每章 ≤1 句**，**仅单人报告设理论注**（双人为两段式、不设理论注，见「五、双人报告增补」）。正文、卡片、表格、图注中不得出现成段理论解释。
4. **理论预算**：理论注每章 1 句是硬上限。装不下的理论内容：挪到 07 章边界声明，或删除。"每句论断可指回 theory-spec"的可溯源性在生成过程的自检抽查中履行，不占用报告版面。
5. **02A 图下注白话定义（比喻退役后的写法）**：图下注每行只写白话定义，**优先级：一律从 stacks.json 的 `function_plain.plain_definition` 逐字照抄，禁止即兴创作**；行内不写比喻、不出现"实际情况"字样。比喻三律（来自具体日常场景 / 无抽象名词 / 后接"实际情况"补全定义）仅作为 stacks.json 比喻库字段自身的编写规则保留，不再进任何章节版面。
6. **三标签模板**：阴影轴的补偿/投射内容不用长句，固定三行：`谁在冒头` / `在哪看到` / `常见误会`（`.qa-rows` 组件）。两条阴影轴必用；04 章对照小卡可选用。
7. **两列对照与一体两面小注**：「意识面 / 阴影面」的两列对照由 02A 四原型对照图的列头承载（左右两列即两面的对照，**不使用任何隐喻**，不再另设对照卡组件——卡体列表与 02A 网格重复，已并入 02A 网格列头）；"一体两面 + 偏向五层"压成 02A 图下一行灰字固定小注（`.faces-note`，逐字固定文案，不计入理论注额度）。
8. **彩面例外**：颜色铁律的"彩色元素 ≤15% 版面"只统计**文字颜色**；组件的强调线、淡色底、chip 底色不计入。06 章方向卡片：「编号章」`.dir-no` 编号与卡片**左边框 3px** 均取该卡主打功能的**文本色**（inline `--dir-color`，取值见模板头部注释）；卡内功能码按铁律①染功能文本色。图形的用色纪律：**颜色可用作编码通道**——块底、轴带、区域、节点、连线、描边与文字均可承载功能色或归属色（甲/乙、意识面/阴影面）；颜色只表达**身份与归属**，**不得用深浅/饱和度表达跨人高低**（那属量值通道，跨人禁用）。
9. **章级三段式 + 组件顺序 + 四条结构声明（两模式共用）**：
   **S1 章级三段式**：每章正文按三段式组织——① 章级一句话结论（`.concl`，1–2 个自包含完整句，先给判断；本章唯一结论块，见规则 1）；② 要点行（`.points`，≤3 条，每条只装一个因果；可为 0 条则省略）；③ 理论注（`.theory-note`，≤1 句，**仅单人报告有**）。
   **S2 组件顺序（锁死）**：**结论 → 要点 → 呈现型组件 → 理论注**。卡片、表格、步进图、命中清单等属呈现型组件，排在要点之后。双人第 0 节为配置卡节、不适用本节顺序：配置卡 + 图 2 → 一句结论 → 术语注与 ipsative 固定声明。
   **S3 组件内小结论**：组件内部允许自带加粗"小结论"（如 02B 每条轴），算组件内容，不占三段式额度。三段式的单位是"章"（单人 7 章 / 双人 7 节），07 章为固定文案不设三段式；双人报告为**两段式**（结论 → 要点），不设理论注（见「五、双人报告增补」）。不设报告级摘要卡 / 速读卡。理论机制与分级徽章不进报告版面。字数不作约束。
   四条结构声明（覆盖全报告文字，含组件内文字；仅适用于完整句，位置锚点 / 功能码串 / 表头标签等非句成分豁免）：
   - **R1 块白名单**：每章正文只有三种块——结论 `.concl` / 要点 `.points` / 理论注 `.theory-note`（双人无理论注），再加呈现型组件；不得出现第二个成段行文块。（双人第 0 节为配置卡节：配置卡 + 图 2 + 一句结论 + 固定术语注 / ipsative，见写法规则 9 S2。）
   - **R2 一个因果一句**：因果连接词（因为 / 所以 / 因此 / 于是 / 导致 / 才）每句至多一个，因果两端各自独立成句；禁止"因为 A 所以 B，同时 C"式复合。
   - **R3 括号注规则**：只管句中的**术语**括号注——必须紧跟在术语首次出现处的"人话"之后，括号内只装术语本身（可带一个极短限定语），不得再写白话、不得含顿号 / 逗号 / 分号；术语的含义由括号前的人话承担。结构位 (阴影) 标注、位置锚点（位置·原型 / 排序）、表头标签、书名号引用等不受本条管辖。
   - **R4 三个以上并列必拆要点行**：三个以上并列一律拆成要点行，不得用逗号串在句内（本条为写作声明，不进机械核对）。
10. **阴影标注**：提及 5–8 位功能时，功能码在**结构位**（位置图谱、表格、轴头、对话表）后加 `<span class="shadow-mark">(阴影)</span>`；结论块、要点行、三标签、卡片标题与正文等行文中，上下文已标明阴影属性（如"阴影 Fi"、阴影轴结论块）的不再重复标注。
11. **六类结构关系必图化**：六类结构关系一律由图形承载，不得用成段文字描述——**位置**（谁在第几位）、**配对**（谁和谁成对）、**轴**（两端对置）、**时序**（先发生 / 后发生）、**回路**（绕开 / 接管）、**归属**（属意识面还是阴影面）。判断句、含义与提醒仍用文字写；图形不替代判断，只替代对关系的描述。图形固定进章结构——双人侧见 couple-visual-spec 第 5 部分、单人侧见 single-visual-spec 第 5 部分（模板头部注释只承担几何算法，不复述图目录），生成时不得自行增删或调换位置。条件图形一律"底图恒在、命中叠加"：无信号时只出底图，不得画出命中态，画出无依据的命中态等于暗示读者命中——**唯一例外是 03 的命中徽章：它没有恒在底图，P1–P5 全未命中时出一枚兜底徽章、不留空图**。图形不引入新机制——机制内容的唯一出处仍是 theory-spec / couple-theory-spec，图形只是呈现层。双人报告中，图的数量以「一节至多一张主图＋准入判据」为上限（couple-visual-spec 第 4 部分）；超出该图位的结构关系由呈现组件（表格/卡片）承载，不因「必图化」而超出图位。**单人报告的图目录（章-图对照）与逐图承载关系见 `references/single-visual-spec.md` 第 5–6 部分**（本规则只保留通则，不复述逐图细节）。
12. **图注规范**：每张图必带图注（灰字小注），含两件事：读法一句（这张图怎么读），以及该图的**层级**——属功能层还是栈层（层级定义见 couple-theory-spec §3.2；单人也适用同一区分，低置信时栈层图的结论按首选类型陈述，图注需说明这一点）。双人报告的图若出自 couple-theory-spec §4.4（投射地图）、§4.5（冲突剧本）或 §4.6（关系的功课），属【B 级】受控推演，**「机制示意，非实测」必须以灰字写在图内，不得写入图注**（图注格式的层级字段只允许枚举值；分级本身不进版面），图内文字不得用"一定 / 总是 / 必然"级措辞。图注与图内标签属非句子成分，不受规则 5 术语注（乙档括号注、术语不作主词）的约束（与规则 5 对节标题、表头、卡片标签的处理、规则 9 R3 的非句成分豁免一致）。图注虽为灰字小注，但不计入规则 3 的理论注额度。**唯一例外：双人报告的页眉双人叠加雷达不带固定格式图注**，只保留一行最简图例（实线＝甲 · 虚线＝乙）；其功能层归属由 couple-theory-spec §3.4 第 5 条承担声明（见 couple-visual-spec §6.1、§7）；其余每一张图仍须带图注。**单人报告的图注承载位置（图A 用 `.chart-note`、其余用 `.fig-note`，及无独立图注的三处）见 `references/single-visual-spec.md` 第 7 部分**；单人图注为自由式，不套用双人「图 {n} · …」固定格式。

## 三、禁区（叠加 theory-spec 第七部分的十条）

1. 禁止巴纳姆句：每句人格描述必须绑定具体分数、排序或位置。
2. 禁止把分数说成能力高低；统一用"分化程度 / 用得顺不顺"。
3. 禁止把 Fi/Fe 写成"情绪化"。
4. 禁止给劣势功能开"直接训练"处方；禁止"消除阴影"这类目标。
5. 禁止职业、年龄推断与婚恋适配裁决（"合不合适""该不该继续"类）；用户追问即答"理论未覆盖，不作推断"。双人关系动力分析按 couple-theory-spec 执行——它同样禁止适配裁决与匹配度评分，与本条不冲突。
6. 禁止引入 theory-spec 之外的理论名词（九型、星座、Socionics 术语等）。
7. 禁止在低置信时丢弃备选类型：报告始终给唯一最有可能类型（综合判型，theory-spec §4.4），备选信息由「另一种可能」一行注承载、不得整条省略。
8. 禁止诊断措辞："症 / 病 / 障碍"一律不得出现；双人报告另禁临床词汇「移情 / 反移情」（couple-theory-spec §2.3）。
9. 禁旧称「知觉轴」，统一用「感知轴」；双人另禁「阴阳 / 甲阳乙阴 / 乙阳甲阴」式块名。

## 四、固定文案（逐字使用，不得改写）

### 第 07 章·边界声明

> 这份报告基于你对自己行为偏好的报告，是偏好数据，不是能力测评，更不是临床诊断。
> 类型是理解心理定向的工具，不是贴在你身上的固定标签——这是荣格本人的立场。
> 分数反映的是作答这一刻的状态；人在变，解读也只是此刻的一张快照。

### 置信度徽章

- 高：`判定置信度：高`（墨绿徽章）
- 中：`判定置信度：中`（琥珀徽章）
- 低：`判定置信度：低`（赭红徽章）

### 「另一种可能」一行注固定句式（所有置信度必出，放类型大字下方）

- 高/中置信：`另一种可能：{备选类型}——分歧在 {功能对}（相差 X.XX 分），证据偏向 {首选类型}。`
- 低置信：`另一种可能：{备选类型}同样可能——分歧在 {功能对}（仅差 X.XX 分），建议结合自身经验复核。`

### 状态评估时效声明（第 05 章结尾固定附一句）

`这是这次测试的快照，不是对你人格的定论。`

### 轴性质标签（第 02 章 B 节，逐字使用）

- 意识轴：`自我认同 · 主动调用 · 日常适应 · 比较分化`
- 阴影轴：`无意识 · 被动 · 补偿 · 投射 · 压力下爆发 · 整合后创造`

### 页脚

单人：`本报告由 analyzing-functions 生成 · 理论依据：荣格《心理类型》及其主流延伸 · 非临床诊断`
双人：`本报告由 analyzing-functions 生成 · 理论依据：荣格《心理类型》《作为心理关系的婚姻》及其主流延伸 · 非临床诊断 · 非关系判决`

## 五、双人报告增补（仅双人模式生效；单人规则不受影响）

1. **通则沿用**：本文件一、二章的语气规则与写法规则（结论先行、结论块、要点行、颜色三铁律、图表优先）对双人报告同样生效（其中章级三段式收窄为两段式，见第 7 条）；规则 6 的"第二人称"在双人模式指"你们 / 甲方 / 乙方"。
