# 荣格八维分数解读 Theory-Spec

> 用途：供 LLM 在拿到一个人的八维（Se / Si / Ne / Ni / Te / Ti / Fe / Fi）测验分数后，依据本规范完成三件事：
> 1. 解读八维分数的含义；
> 2. 推断该人的 MBTI 类型（含置信度）；
> 3. 按照规定的分析框架产出人格分析结果。
>
> 理论边界：本规范**只**使用荣格分析心理学派及其公认延伸主流理论（Myers–Briggs、von Franz、Grant/Beebe 功能层级模型、Quenk 压力理论、Nardi 神经科学佐证）。不使用九型人格、星座、Socionics 独有概念或其他流派的臆造概念。凡超出这些理论可支持范围的内容，必须明确标注为"理论未覆盖，不作推断"。

## 第一部分：理论渊源与依据（本规范的一切规则必须能回溯到这里）

### 1.1 荣格《心理类型》（C. G. Jung, *Psychological Types*, 1921）—— 地基

- **两种态度类型（Attitudes）**：外倾（Extraversion, E）与内倾（Introversion, I）。态度指力比多（心理能量）的基本流向：外倾朝向客体，内倾朝向主体。荣格原文强调：这不是社交能力，而是心理定向。
- **四种功能（Functions）**：
  - **理性功能（判断功能）**：思维（Thinking, T）、情感（Feeling, F）。二者互斥地竞争主导地位。
  - **非理性功能（知觉功能）**：感觉（Sensation, S）、直觉（Intuition, N）。二者互斥地竞争主导地位。
- 注意：荣格的"情感（Feeling）"是**价值判断功能**（评估好/坏、值得/不值得），不是情绪（affect）。解读 Fi/Fe 分数时不得把它解释为"情绪化程度"。
- **功能与态度结合，共 8 种类型-功能**：Te、Ti、Fe、Fi、Se、Si、Ne、Ni。这就是"八维"的理论出处。
- **主导与劣势**：荣格的核心论断是——人的意识由**一个优势（主导）功能**定向，与其**同类的对立功能**（T 对 F、S 对 N）被压抑而成为**劣势功能（inferior function）**；劣势功能携带大量无意识内容，是人格不平衡与张力的主要来源。
- **辅助功能**：荣格提到主导功能通常由另一类的功能辅助（判断型由知觉功能辅助，知觉型由判断功能辅助），以维持人格的基本平衡。但荣格本人**没有**给出完整的四功能排序。
- **补偿原理**：意识态度越片面，无意识越以其对立面进行补偿。这是后面"阴影功能""被劣势功能俘获"等分析的理论根基。
- **分化（Differentiation）**：心理发展 = 功能的分化程度提升。未分化的功能以原始、混杂、与无意识粘连的方式运作。分数的高低差异首先要用"分化程度"来解读，而不是"能力强弱"。

### 1.2 玛丽-路易丝·冯·弗朗兹（M.-L. von Franz, *The Inferior Function*, 1971）—— 劣势功能

- 劣势功能是"通往无意识的门"，是个体化（individuation）进程的关键入口。
- 劣势功能**不能**像主导功能那样被直接、主动地"训练"；强行以意识态度抓取它往往引发失控、情绪化、原始化反应。
- 对劣势功能的整合是缓慢、间接的（通过象征、想象、关系、中年期心理转向），这是分析框架中"发展建议"部分的理论约束。

### 1.3 迈尔斯-布里格斯（Myers & Briggs, MBTI）—— 类型编码系统

- 在荣格八功能之上建立了 16 类型编码系统，并加入 **J/P 维度**（生活方式定向：对外世界主要使用判断功能还是知觉功能）。
- 确立了**功能堆叠（function stack）** 的类型学：每个类型 = 主导 + 辅助 + 第三 + 劣势 的四功能序列，且态度（E/I）沿序列交替。

### 1.4 Grant 功能层级模型 & Harold Grant 等（*From Image to Likeness*, 1983）—— 四功能堆叠的标准形式

- 确立了现代主流的类型动力学公式：**主导(Dom) → 辅助(Aux) → 第三(Tert) → 劣势(Inf)**，态度严格交替（如 Ni-Te-Fi-Se）。
- 第三功能是辅助功能的对立功能（同类、反向态度）；劣势功能是主导功能的同类对立功能、反向态度。

### 1.5 约翰·毕比（John Beebe, *Energies and Patterns in Psychological Type*, 2016）—— 八功能-原型模型

- 将 8 个位置各赋予原型角色，使八维分数全部有理论位置可安放：
  1. **主导 = 英雄/女英雄（Hero）**：自我认同的核心，最可靠、最省力；
  2. **辅助 = 父母（Good Parent）**：用于帮助他人、与他人建立关系的功能；
  3. **第三 = 永恒少年/少女（Puer/Puella）**：玩乐、脆弱、不稳定，时灵时不灵；
  4. **劣势 = 阿尼玛/阿尼姆斯（Anima/Animus）**：灵魂功能，羞耻与渴望的交汇点，通往无意识；
  5. **第五 = 对立人格（Opposing Personality）**：主导功能的阴影态度，用于防御、对抗、抬杠；
  6. **第六 = 长老/女巫（Senex/Witch）**：辅助的阴影，以消极权威、批判、设限的方式出现；
  7. **第七 = 小丑/恶作剧者（Trickster）**：第三的阴影，盲区功能，容易在此处被愚弄或愚弄人、感到"双重束缚"；
  8. **第八 = 恶魔（Demonic Personality）**：劣势的阴影，最深、最具破坏性的无意识位置，也与最深的转化潜能相连。
- 规则：第 5–8 功能 = 第 1–4 功能保持功能不变、态度翻转（Ni→Ne，Te→Ti，Fi→Fe，Se→Si）。
- 别名对照：第六位"长老/女巫"在部分文献中称"批判父母"（Witch/Senex 的批判面向）；第七位"小丑/恶作剧者"亦称"欺骗者/愚者"（Trickster）。报告与图表统一使用固定名。
- 重要：毕比模型是**动力-原型模型**，不是说阴影位置分数必然低。分数高而位置为阴影，恰恰是有临床/发展意义的信号（见第三部分解读规则）。

### 1.6 内奥米·昆克（Naomi Quenk, *In the Grip*, 1993/2000）—— 压力与"被劣势功能俘获"

- **Loop（主导-第三循环）**：回避辅助功能时，主导与第三（同态度的两个功能）形成封闭循环，人格变得片面。
- **Grip（被劣势功能俘获）**：长期/重度压力下，劣势功能以原始的、失控的方式爆发（如 ISTJ 的 Ne 劣势表现为灾难化幻想）。每个类型的 grip 表现由劣势功能决定，有文献可循。
- 分析框架中的"状态评估"部分必须依据此理论。

### 1.7 达里奥·纳迪（Dario Nardi, *Neuroscience of Personality*, 2011）—— 谨慎使用的佐证

- EEG 研究显示不同功能偏好对应不同的脑区激活模式，可作为功能分化的间接佐证。
- 使用约束：仅作辅助印证，不作为任何推论的独立依据。

### 1.8 轴理论（意识轴与阴影轴）

- **框架**：意识面（毕比 1–4 位）与阴影面（毕比 5–8 位）是**一体两面**——不是两个人格，而是同一心灵中同一批功能的两个极：意识面负责"我是谁、我怎么适应"，阴影面负责"我缺了什么、我压抑了什么"。呈现层以「意识面 / 阴影面」两列对照呈现总体结构——两列对照由 02A 四原型对照图的列头承载（不另设对照卡组件），不使用任何比喻性总起（正式术语是下述四条轴）。呈现组件规格（结论块、要点行、理论注、三标签）以 copy-rules「写法规则」章与 `assets/report-template.html` 为准。
- 出处：毕比模型的轴线结构——意识轴两条：主导–劣势轴（spine，英雄—阿尼玛轴，承载自我认同）与辅助–第三轴（arm，父母—永恒少年轴，承担对外适应与照顾）；阴影轴两条：其一是 5&8 位配对、其二是 6&7 位配对。
- 配对规则（可执行规则）：意识轴 = 毕比 1–4 位中同类功能两两配对（N/S 两功能构成感知轴，T/F 两功能构成判断轴）；阴影轴 = 毕比 5–8 位中同类功能配对（5&8 与 6&7 各成一轴，其一为感知轴、另一为判断轴，由功能类别决定）。
- **偏向的五个层次**：说一个人"偏向某功能"，至少包含五个可区分的层次——
  1. **分化程度**：该功能有多成熟、多独立（荣格分化概念，§1.1）；
  2. **意识位置**：它在堆叠里排第几（毕比堆叠，§1.5）；
  3. **自我认同**："这是不是我"（英雄位承载 ego，§1.5）；
  4. **能量投注**：心理能量优先流向哪里（力比多投注，§1.1）；
  5. **可调用性**：能否被意志主动使用，还是只能被动爆发（荣格：分化后的功能服从意志，§1.1）。

  测验分数只直接反映分化程度与能量投注两层；分数与意识位置可以分歧（§3.1 交叉引用），分歧本身有解读价值。
- **两种偏向剖面**：意识轴的偏向 = 自我认同、主动调用、日常优先；阴影轴的偏向 = 补偿优先通道、压力下接管顺序、接近意识的程度。后者是阴影轴**内部的排序维度**（哪条阴影轴更先被激活、哪端更接近意识），非性质标签。
- 性质标签与文献映射表：

**意识轴标签**

| 标签 | 文献映射 |
|---|---|
| 自我认同 | 毕比：英雄位是自我认同的核心（§1.5） |
| 主动调用 | 荣格：分化后的功能服从意志、可被随意使用（§1.1） |
| 日常适应 | 荣格：辅助功能维持内外平衡与日常适应（§1.1） |
| 比较分化 | 荣格：1–4 位分化程度整体高于 5–8 位（§1.1） |

**阴影轴标签**

| 标签 | 文献映射 |
|---|---|
| 无意识 | 毕比：5–8 位内容不被自我认同（§1.5） |
| 被动 | 非自主浮现、不受意志调用 |
| 补偿 | 荣格补偿原理（§1.1） |
| 投射 | 毕比：阴影功能最易投射到他人身上（§1.5） |
| 压力下爆发 | 昆克 loop/grip（§1.6） |
| 整合后创造 | 冯·弗朗兹（§1.2）与荣格个体化：整合阴影释放被束缚的能量 |

标签为呈现层短语，含义以上述文献映射为准，不得脱离映射使用。

- **阴影轴的四种作用机制**：
  1. **补偿**：意识越片面，阴影越要求平衡（§1.1 补偿原理）；
  2. **防御与压力反应**：疲劳、压力、创伤、醉酒、亲密关系冲突时容易退行到阴影轴（"醉酒"一条仅限本 spec 记载，报告不写）；
  3. **投射**：阴影功能最常经由"别人"被看见——强烈讨厌或迷恋某人，常是自己的阴影在该功能上投出（毕比，§1.5）；
  4. **创造与整合的潜能**：整合后转化为创造力、幽默、灵活性与完整性（§1.2 冯·弗朗兹）。
- **互动原理**：意识越偏一极，阴影越要求另一极——X 使用过度，其阴影态度（同一功能类别、相反态度）就可能以原始形式反扑。报告可按此为每条意识轴写一行"失衡信号"（意识端过度 → 阴影端反扑的倾向）。
- **超越功能与对立转化**：荣格的**超越功能**（《超越功能》，CW 8）——意识与无意识的对立被容纳时，不是一方消灭另一方，而是产生**第三物**；**对立转化**（enantiodromia）——固守一极到极端会转向对立面。应用示例（合法的呈现层推演）：意识第 k 位与阴影第 9−k 位（1↔5、2↔6、3↔7、4↔8，恰为态度翻转对）两两对话，各自生成"第三条路"。
- **阴影位压力表现目录（示例性标注口径）**：各阴影位在压力下的表现由该位功能的性质推演——对立人格=防御性多疑与发散焦虑、长老/女巫=消极批判（道德愤怒或逻辑挑剔）、小丑/恶作剧者=冷酷控制或盲区缺席、恶魔=躯体化、经验失联、强迫例行。**标注：此目录由功能性质推演，非毕比/昆克文献逐条记载；报告措辞须用"可能倾向"级，不得写成确定性症状。**
- **个体化定位**：个体化不是让阴影轴夺权，也不是抛弃意识轴，而是让阴影轴被看见、被纳入意识，最终为自性（Self）服务（荣格个体化；§1.2）。

## 第二部分：八维构念定义（解读分数时使用的唯一标准定义）

| 功能 | 荣格式定义 | 高分时的典型表现 | 低分（未分化/被压抑）的典型表现 |
|---|---|---|---|
| **Te** 外倾思维 | 以客观标准、效率、可验证的程序组织外部世界 | 重逻辑结构与可执行性，以客观事实和结果为判据 | 难以依赖客观标准，或把主观逻辑误认为普遍有效 |
| **Ti** 内倾思维 | 以内在逻辑一致性为准绳，构建概念体系本身 | 追求精确、自洽，质疑未经验证的框架 | 逻辑松散，或对一切体系抱不信任而缺乏自己的体系 |
| **Fe** 外倾情感 | 以客体情境中的价值、氛围、共同体的情感标准作判断 | 敏感于他人情绪与群体规范，主动营造和谐 | 难以读取或回应群体情感氛围，或完全盲从外界评价 |
| **Fi** 内倾情感 | 以主体内在的价值与真实性为准绳作判断 | 价值坚定、重真诚与个人一致，共情基于自我投射 | 价值感模糊，或价值防御性地僵化、易受伤而不自知 |
| **Se** 外倾感觉 | 直接、当下、无中介地感知客体的现实 | 活在当下，感官敏锐，行动果断，把握即时机 | 与身体/当下脱节，或冲动地、强迫性地追逐刺激 |
| **Si** 内倾感觉 | 以主观印象与既往经验的沉淀来感知现实 | 重视可靠经验、细节、身体感受的稳定性，有历史感 | 经验库薄弱、细节涣散，或僵化地固守个人经验 |
| **Ne** 外倾直觉 | 在客体中看到可能性、潜在关联与演化方向 | 联想发散，热衷可能性与新事物，多角度跳跃 | 可能性贫乏、只看到一条路径，或漫无边际而失焦 |
| **Ni** 内倾直觉 | 向无意识意象收束，感知事物背后的内在意象与趋势 | 洞察纵深、预见走向、依赖"顿悟"式确定性 | 缺乏纵深洞察，或陷入偏执的、不可检验的宿命式预感 |

使用约束：
- 上表高分/低分两栏描述的是**功能分化程度**的表现，不是道德评价，也不是能力测评结论。报告中禁止使用"强/弱""好/坏"作定性措辞，须使用"分化程度高/低""占主导/处于劣势/处于阴影位置"等类型学术语。
- 八维分数是**自陈式偏好测量**，测的是"个体报告自己倾向于如何使用该功能"，不等于认知能力实测。任何解读必须带此限定。

## 第三部分：分数解读规则（第一层：分数本身意味着什么）

### 3.1 分数性质的判定（先做这一步）

1. 八维分数是**个体内（ipsative 倾向）**数据：解读以**个体内部的相对排序与差距**为主，绝对分数只作参考。必须先计算排序（第 1 高 → 第 8 低）再开始任何解读。
2. 必须检查量表上限：若多个功能并列封顶或分数整体挤在高分段（如全部 > 80%），说明区分效度低，此时只能做**低置信度**解读。可执行判据：最高分 − 最低分 < 32.5 视为区分度低（与并列封顶/整体挤高分段任一满足即触发；区分度问题在对话层向用户说明缘由，报告内以置信度体现，不另设声明）。
3. 计算四个同类功能对的**态度内对比**：T 对内 Ti vs Te、F 对内 Fi vs Fe、S 对内 Si vs Se、N 对内 Ni vs Ne。每对中更高者记为该功能类别的"优势态度"。这一步是类型判定的中间量。
4. 解读"偏向"须区分五个层次——分化程度、意识位置、自我认同、能量投注、可调用性（见 §1.8）：测验分数只直接反映其中两层，与意识位置的分歧本身有解读价值（如阴影位高分）。

### 3.2 单个分数的解读规则

- **最高分（Top 1）**：默认解读为"意识上最倚重、分化程度最高的功能"，是主导功能的第一候选。
- **次高分（Top 2、Top 3）**：辅助功能的候选区；也是"发展良好的非主导功能"的位置——在成熟人格中，第二、第三高分常常不是理论堆叠里的辅助/第三，而是个体后天发展的功能，解读时按第四部分算法判定归属。
- **最低分（Bottom 1）**：默认解读为"最少被意识使用、分化程度最低的功能"。注意：它**不一定**等于类型的劣势功能——很可能是第 7 位（Trickster，盲区）功能。两者含义不同：劣势功能是"渴望而笨拙"，Trickster 是"盲区而防御"。判定归属见第四部分。
- **同功能双态度同高**（如 Ti、Te 都高）：解读为该功能类别整体分化良好，态度的内外切换自如；类型判定以更"省力、认同更深"的那个态度为准（若分数无法区分，按 4.4 节处理模糊情形）。
- **同功能双态度同低**：解读为该功能类别整体处于未分化或被回避状态，在分析中须作为发展议题提出。

### 3.3 解读的语言规范

- 所有分数解读必须挂到原型位置（毕比模型）或发展状态（分化/未分化）上，禁止孤立的"你 Se 高所以你爱运动"式的行为学直译——荣格理论中功能是**心理定向**而非行为清单。
- 禁止巴纳姆语句（适用于所有人的模糊描述）。每句解读必须能指回：具体分数排序 + 具体理论条目（注明出自第一部分的哪一节）。

## 第四部分：MBTI 类型判定算法（第二层：从分数到类型）

### 4.1 判定依据的优先级（从高到低）

1. 最高分功能（主导候选；受 §4.4「主导的有界改判」约束）；
2. 该主导候选能否与分数结构中的其余功能组成**理论合法的堆叠**（4.2 节的合法性约束）；
3. 各功能类别内的态度优势对比（3.1 第 3 步）；
4. 最低分是否与推断类型的第 7/8 位功能吻合（反向验证）。

### 4.2 堆叠合法性约束（Grant 模型，不得违反）

- 主导与辅助**不同类**（判断/知觉各一）、**态度相反**；
- 第三 = 辅助的对立功能（同类反向态度）；劣势 = 主导的对立功能（同类反向态度）；
- 态度沿 1–4 位严格交替。
- 由此得到 16 个合法堆叠（判定时的唯一类型空间）：

| 类型 | Dom | Aux | Tert | Inf | 阴影 5–8（毕比，态度翻转） |
|---|---|---|---|---|---|
| ISTJ | Si | Te | Fi | Ne | Se-Ti-Fe-Ni |
| ISFJ | Si | Fe | Ti | Ne | Se-Fi-Te-Ni |
| INFJ | Ni | Fe | Ti | Se | Ne-Fi-Te-Si |
| INTJ | Ni | Te | Fi | Se | Ne-Ti-Fe-Si |
| ISTP | Ti | Se | Ni | Fe | Te-Si-Ne-Fi |
| ISFP | Fi | Se | Ni | Te | Fe-Si-Ne-Ti |
| INFP | Fi | Ne | Si | Te | Fe-Ni-Se-Ti |
| INTP | Ti | Ne | Si | Fe | Te-Ni-Se-Fi |
| ESTP | Se | Ti | Fe | Ni | Si-Te-Fi-Ne |
| ESFP | Se | Fi | Te | Ni | Si-Fe-Ti-Ne |
| ENFP | Ne | Fi | Te | Si | Ni-Fe-Ti-Se |
| ENTP | Ne | Ti | Fe | Si | Ni-Te-Fi-Se |
| ESTJ | Te | Si | Ne | Fi | Ti-Se-Ni-Fe |
| ESFJ | Fe | Si | Ne | Ti | Fi-Se-Ni-Te |
| ENFJ | Fe | Ni | Se | Ti | Fi-Ne-Si-Te |
| ENTJ | Te | Ni | Se | Fi | Ti-Ne-Si-Fe |

### 4.3 判定步骤（严格按序执行）

1. **取 Top 1 为首要主导候选。** 查 4.2 表，列出以它为主导的两个类型（如 Ni 最高 → INFJ / INTJ）。Top 1 与同档竞争者（分差 ≤ 3 分，见 §4.4 同档判据）并存时，不机械取最高分——对该档每个功能各自可成的合法候选综合评估后定主导。若满足 §4.4「主导的有界改判」触发条件，按该条扩展主导候选后重走本步。
2. **用辅助功能分流。** 在 Top 2–4 中寻找该候选类型的合法辅助功能：两个合法辅助分差 > 3 分时，取分更高者判给该类型（Ni 最高，Te > Fe → INTJ）；分差 ≤ 3 分属同档，不机械取分高者，按 §4.4 证据优先序综合评估。
3. **反向验证。** 检查推断类型的劣势功能与第 7、8 位阴影功能在实测分数中是否处于低分区（或劣势功能出现"低分但高唤起/高敏感"的叙述性矛盾——若用户附了质性描述才可用此条，纯分数时跳过）。名次判读按 §4.4 同档规则：待验证功能与其相邻名次功能分差 ≤ 3 时，名次不作独立证据、按「证据中性」处理。
4. **交叉验证态度优势。** 用 3.1 第 3 步的四对态度对比检验：判定类型的主导功能态度应与该类别内优势态度一致。若矛盾（如判 INTJ 但 Ne > Ni）（在 §4.4 同档比较中，此矛盾构成对该候选的否决），降级置信度并在报告中暴露此矛盾，不得掩盖。
5. **记录备选类型。** 始终输出第二候选类型及其与首选的分差来源，格式：`首选 INTJ（Ni 主导、Te 辅助）；备选 INFJ（差异来自 Te/Fe 分差仅 X 分）`（内部记录，不进报告正文；报告用「另一种可能」一行注承载，句式见 copy-rules）。

### 4.4 同档判据、证据优先序与模糊情形的处理（必须遵守）

- **同档判据**：类型推断中任意两功能分差 ≤ 3 分视为**同一档**；同档内名次先后不构成判型证据。
- **奥卡姆剃刀原则（本节总纲）**：候选类型之间的比较不得引入本规范之外的新假设；硬证据不足以区分候选时，取与实测剖面冲突更少（意识面异常更少，见下文第 3 层）的候选；判型过程中禁止临时发明本规范未载明的特例规则（见第七部分禁区 10）。
- **证据优先序**：同档 / 模糊情形下，候选类型按以下四层顺序比较；每层内部是启发式判断，**层级次序不得调换**：
  1. **态度否决**：候选与 §3.1 第 3 步同类态度对比矛盾者直接出局；两候选均矛盾时不作否决、继续以下各层，置信度按 §4.5 锁为"低"。
  2. **独有位置证据**：列出两候选堆叠中互不相同的位置（通常为辅助位与第三位；视候选对而定还可能含劣势位与阴影 5–8 位中的互异位），逐一检查该位置功能在实测中的分数与名次：独有位置功能落入实测低分区（与相邻名次分差 > 3 的后段名次）构成对该候选的不利证据，处于高分区构成支持证据；分差 ≤ 3 按同档处理为证据中性。
  3. **意识面最小异常（奥卡姆剃刀的操作化）**：数"候选堆叠意识面 1–4 位功能落入实测后四名"的个数，少者胜；阴影位（5–8 位）高分**不计**为异常（§1.5：分数高而位置为阴影是有临床/发展意义的信号，不是错误）；本层平局进入第 4 层。
  4. **分差兜底**：以上各层仍无法区分时，取分差更优者，并按第六部分要求在"另一种可能"一行注中写明分歧点。
- **主导的有界改判**：触发条件——Top 1 的两个合法辅助功能**都**明确低于某候选所需的辅助功能（与该辅助分差 > 3，非同档）。执行——把主导候选扩展为**实测前四名中每个能组出合法堆叠且其辅助功能受上述支持的功能**，候选全体按证据优先序比较后选唯一首选；改判结果置信度上限锁"低"（§4.5），改判原因（Top 1 辅助不受支持、改判依据）须在报告第 01 章暴露。仅一个辅助不受支持时不触发本条，按原路径执行并适用既有"辅助疑似被绕开"的降档处理。
- 触发条件（满足任一）：Top 1 与 Top 2 分差过小（相对差 = 两分数之差除以两者中较高者，< 5%；或绝对差在量表误差范围内）；主导候选的合法辅助功能分数接近持平；4.3 第 4 步出现态度矛盾。（"接近持平"的可执行判据与 Top 1/Top 2 同口径：两分数相对差 < 5%；"绝对差在量表误差范围内"按绝对差 ≤ 3 分（即同档）理解。两者满足其一即触发。）
- 处理方式：
  1. **综合判型**：同档 / 模糊情形下，两个候选都必须进入综合评估；综合评估按上述证据优先序执行；评估后给出**唯一首选**，不再并列呈现两套完整堆叠；
  2. 明确指出分歧点在哪一对功能上（如"Te 与 Fe 几乎持平，导致 INTJ/INFJ 需综合判读"）；
  3. 报告置信度按 4.5 阈值链输出（关键分流分差 < 3 仍标"低"）；备选类型以"另一种可能"一行注呈现（句式唯一出处：copy-rules「固定文案」章），并保留质性复核建议（自我认同、行为样本、发展史的叙述）。
- 荣格本人的立场作为兜底原则：类型是理解人格定向的启发式工具，不是把人装进抽屉的标签（《心理类型》前言中的明确告诫）。报告中应体现此立场。

### 4.5 判定置信度分级（输出必须携带）

- **高**：主导明确、辅助明确分流、反向验证通过、无态度矛盾；
- **中**：主导明确，辅助分流分差小但通过；或一项反向验证不通过但其余支持；
- **低**：触发 4.4 任一条件（含主导的有界改判），或分数整体区分度差（3.1 第 2 步）。

## 第五部分：分析框架（第三层：类型 + 分数 → 人格分析）

分析按以下五个层次依次展开，每层须同时引用**分数证据**与**理论条目**。最终输出的分析结果 = 这五个层次的结构化内容。

### 层次 A：类型结构分析（心理定向的骨架）

- 内容：主导功能如何定向意识（结合 1.1 的定义与第二部分表格）；辅助功能如何承担"对外关系与平衡"的角色（1.1 辅助功能条、毕比"父母"位）；第三与劣势功能的结构性张力（1.2）。
- 须回答：此人的意识世界主要由什么功能组织？判断/知觉的偏好方向？能量流向（E/I）？
- 须包含意识轴与阴影轴的定位描述（用 §1.8）。
- 分数证据：Top 1–2 的分数与排序；态度交替是否与理论堆叠吻合（吻合度高 → 结构典型；不吻合 → 进入层次 C 重点讨论）。

### 层次 B：功能分化与发展水平分析（类型学的时间维度）

- 理论依据：1.1"分化"概念；荣格关于**前半生发展主导与辅助、后半生（中年期）转向劣势与第三功能**以走向个体化的论述（《心理类型》及《论心理的性质》相关章节）；1.2 冯·弗朗兹对劣势功能不可直接训练的论断。
- 内容：将 8 个分数映射到毕比 8 位置后，区分三种分数模式：
  - **位置与分数匹配**（如主导位功能分数最高）：分化沿理论轴线进行，结构典型；
  - **非位置功能高分**（如第 5–8 位阴影功能分数高）：不解释为"阴影发达"，而解释为以下之一——(a) 后天情境（职业/环境）要求下的功能使用，能量消耗大；(b) 防御性使用（阴影原型被频繁激活，如 Opposing Personality 高分表现为好辩、防御姿态）；(c) 测量噪声。三者如何取舍取决于分数全貌，须在报告中说明选择了哪种解释及理由；
  - **位置功能低分**（如辅助位功能分数很低）：提示 1.6 的 **loop** 风险——主导-第三封闭循环、辅助功能被绕开。这是类型动力学中最有行动价值的信号之一，必须明确指出。
- 须回答：哪些功能分化良好？哪些处于原始/粘连状态？发展议题集中在哪些功能类别？

### 层次 C：人格动力学分析（张力、补偿与阴影）

- 理论依据：1.1 补偿原理；1.2 劣势功能；1.5 毕比原型模型。
- 内容：
  - **主导–劣势轴张力**：指出此类型特有的主导/劣势对（如 INTJ 的 Ni–Se 轴），描述其典型冲突形式（意识越固守主导，无意识越以劣势功能的原始形式反扑）；
  - **阴影位置的具体激活方式**：对照实测分数，指出 5–8 位中哪些分数偏高，按毕比原型描述其最可能的出现场景（第 5 位高 → 防御与对立；第 6 位高 → 挑剔与消极批判；第 7 位高 → 盲区领域反复受挫；第 8 位高 → 须提示而非断言，用"可能体验到与自我价值深度纠缠的破坏性时刻"之类的谨慎表述）；
  - **补偿信号**：若最低分落在劣势功能或第 7 位；**若最低分落在其他位置但与二者之一相差 ≤3 分，视同该位为最低（同档）**，结合 3.2 的规则区分"渴望型低分"与"盲区型低分"，二者给出的动力学结论不同，必须分开表述。
  - **化解方向**：主导–劣势轴张力的出路不是消灭一方，而是荣格的超越功能（§1.8）——对立被容纳后产生第三物。
- 禁止：不得做临床诊断；不得使用"病症""病理"措辞；"阴影"一律按荣格定义（被意识人格排斥/未分化的内容）使用，不得引申为道德负面。

### 层次 D：状态评估（压力与失衡的模式）

- 理论依据：1.6 昆克。
- 内容：
  - **Loop 信号**：若辅助位功能实测分数的排序低于第三位功能，且两者分差 ≥ 5 分（量表 0–121.8），提示此人当前可能处于主导-第三 loop 中，描述该类型 loop 的典型表现（昆克及类型学文献中的标准描述）；
  - **Grip 信号**：若劣势功能分数异常高（与"低分化"假设相反）且辅助功能低，提示可能正处于或反复进入"被劣势功能俘获"状态；描述该类型 grip 的标准表现（由劣势功能决定：劣势 Ne → 灾难化想象；劣势 Se → 强迫性感官沉溺；劣势 Fe → 情感爆发与被害式敏感；劣势 Ti → 强迫性挑剔与钻牛角尖；等等，按昆克原书逐型对照）。
- 状态评估必须声明时效性：分数快照反映的是**测量时点**的状态，loop/grip 结论是对"当前状态"的假设而非人格定论。

### 层次 E：个体化方向（发展议题，而非建议清单）

- 理论依据：1.1 分化与个体化；1.2 冯·弗朗兹（劣势功能须间接整合）；1.5 毕比（各原型位置的整合任务）。
- 内容约束：
  - 发展方向的表述一律采用荣格式目标——**扩大意识对未分化内容的容纳**，而非"提升某项技能"；
  - 劣势功能：只提"创造与它安全相遇的条件"（通过兴趣、艺术、关系、身体实践等间接途径），**禁止**给出"直接训练劣势功能"的建议（违反 1.2）；
  - 辅助功能：若层次 B 判定辅助发展不足，优先建议恢复辅助的使用——这是类型动力学中代价最小、收益最直接的一步；
  - 中年期议题（若用户年龄 ≥ 35 或自陈处于人生转折）：引入前半生/后半生转向的论述，说明后半生的发展任务就是接触第三与劣势功能；
  - 阴影功能：只按毕比模型指出"觉察其激活场景"这一目标，不给消灭阴影的建议（荣格理论中阴影不可被消灭，只能被整合）；
  - 个体化的定位：让阴影轴被看见、被纳入，为自性服务（§1.8）——不是阴影夺权，也不是抛弃意识轴；可为每组"意识位 × 阴影位"对话（1↔5、2↔6、3↔7、4↔8）各给一条整合方向。

## 第七部分：硬性禁区（违反任何一条即视为输出不合格）

1. 禁止把功能解释为技能、能力或行为清单（功能是心理定向）。
2. 禁止把 Feeling 功能解释为情绪化程度。
3. 禁止把类型判定说成确定性结论；置信度必须始终携带。
4. 禁止在 4.4 同档 / 模糊情形下跳过综合评估、机械按名次或高分单判、或调换 §4.4 证据优先序的层级次序；两个候选都必须进入综合评估，备选类型由"另一种可能"一行注承载，不得整条丢弃。
5. 禁止给"直接训练劣势功能""消除阴影"的建议（违反冯·弗朗兹与荣格的基本立场）。
6. 禁止引入本规范第一部分之外的理论概念（九型、星座、Socionics 独有术语、自行发明的功能组合规则等）。
7. 禁止临床诊断措辞；禁止对低分功能做病理化描述。
8. 禁止巴纳姆式描述：每句人格论断必须能指回具体分数位置 + 具体理论条目，二者缺一则删除该句。
9. 禁止根据八维分数推断年龄、职业适配、伴侣适配等荣格理论不支持的内容；此类需求一律回应"理论未覆盖，不作推断"。
10. 禁止在判定过程中临时发明本规范未载明的特例规则或例外条款；判型只能使用本规范已载明的规则（奥卡姆剃刀的治理含义：不为解释单个剖面新增假设）。
