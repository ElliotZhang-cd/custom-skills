# 荣格八维单人认知报告 视觉规范（Visual-Spec）

> 本文件是单人报告**全部视觉语言与图形几何的唯一出处**：设计代币、版式、逐图几何公式、图形状态、图注与禁区都在本文件，生成方按本文件可逐值复现每张图。

## 位阶

- **机制**（是什么、为什么）→ `references/theory-spec.md`；本文件只呈现，不复述机制。
- **写法**（语气、术语三档、固定文案逐字文本、禁区）→ `references/copy-rules.md`；本文件只指向。
- **数据绑定与流程**（章节结构、每章放什么数据）→ `references/workflow-single.md`。
- **token↔markup 契约**（占位符清单、填充规则）→ `assets/report-template.html` 头部注释；几何数值一律以**本文件第 6 部分**为准。
- **本文件**：单人报告视觉的唯一权威——版式、逐图几何公式、图形状态、图注、视觉禁区。

单人报告与双人报告的差异红线（防止误用双人规则）：

1. 单人设理论注层（`.theory-note` ≤1 句/章）；双人为两段式、无理论注。
2. 单人允许分数进版面（个体内）；双人零指标（分数不进版面）。
3. 单人量值通道个体内解禁（条长、倾侧、重心位置可编码本人分数）；颜色在任何模式下都不作量值。
4. 单人图注自由式（读法一句 + 层级）；双人为固定格式「图 {n} · …」。
5. 雷达轴序两卷统一为 **Se Si Ne Ni Te Ti Fe Fi**（自正上方顺时针，即输入规范顺序）。

## 第 2 部分：三条总原则

- **P1 结构关系必图化**：位置 / 配对 / 轴 / 时序 / 回路 / 归属六类关系一律图形承载（copy-rules 规则 11）；一种关系只给一种几何。
- **P2 量值通道个体内可用、颜色永不作量值**：条长、倾侧、重心位置可编码**本人**分数；颜色深浅/饱和度/面积在任何模式下不表达分数高低。
- **P3 图必须自解释**：图内文字与图注一律白话；图能脱开正文独立读懂。图注含「读法一句 + 层级（功能层/栈层）」。

## 第 3 部分：编码通道

| 通道 | 用法 |
|---|---|
| 位置/槽位 | 毕比位置号、排序位、格子行列 |
| 拓扑/相等/对置/方向 | 配对、同档、轴两端、有向箭头 |
| 归属 | 意识面/阴影面（实底 vs `--soft` 底 + (阴影) 标注）；面板强调底 |
| 颜色 | 只作身份与归属（功能色、面归属）；**不作量值** |
| 量值（个体内） | 图 A 条长 = min(分数,100)%；天平倾侧；张力条重心位置 |

## 第 4 部分：图与文字的边界

1. 每章正文三段式：`.concl`（1–2 句）→ `.points`（≤3 条）→ 呈现型组件 → `.theory-note`（≤1 句，单人专属）。
2. 图位由第 5 部分锁定，不得增删调换；条件图形一律「底图恒在、命中叠加」；**唯一例外**：无恒在底图的条件图见第 5 部分单列（单人情形单人卷无——05 回路图有恒在底图）。
3. 图注随图放置、属非句成分，不计入三段式与理论注额度。
4. 低置信：栈层图按首选类型画，图注加「（含低置信推定，按首选类型陈述）」；功能层图（页眉雷达、图 A）永不加限。

## 第 6 部分：逐图几何（唯一几何出处；生成方按公式逐值复现、静态直出）

### 6.0 雷达通用公式（页眉雷达）

- viewBox `0 0 250 200`；中心 `(cx,cy) = (150,100)`（左留 50px 给均值标签）、半径 `R = 70`。
- 轴序自正上方顺时针 **Se, Si, Ne, Ni, Te, Ti, Fe, Fi**；第 i 轴角度 `φ_i = −90° + 45°·i`（屏幕坐标 y 向下）。
- 顶点 = `(150 + r·cos φ, 100 + r·sin φ)`；`r = 70 × min(分数,100)/100`（>100 截断于满半径）。
- 网格：同心圆 `r = 17.5 / 35 / 52.5 / 70`（1px `#e6ddca`）+ 8 条径线（同色）+ **均值虚线圆 `r = 35.5`**（50.75 刻度，`#8d8271`，dasharray `4 3`）。
- 数据多边形：fill `rgba(74,66,56,.10)`、stroke `#4a4238` 2px；8 顶点圆点 r=2.5 fill 各功能原色。
- 轴标签在 `r = 84` 处，字体 11px/600，色取 `function_colors_text`；锚点：cos>0.7 → start，<−0.7 → end，其余 middle。
- 均值标签「均值 50.75」：位于 `(71.5,136)`、anchor=end、9.5px `#8d8271`。
- 无独立图注（容器带 `role="img"` + `aria-label="八维雷达"`）。

### 6.1 图 A（01 横向条形图）

- 8 行按分数**降序**排列（同档并列 ≤3 分差者按输入顺序 Se Si Ne Ni Te Ti Fe Fi 稳定排序）。
- 行结构：`[118px 功能名] [1fr 轨道] [52px 数值]`；轨道高 15px、底 `rgba(41,36,29,.05)`；条高 15px、圆角 4px、宽 = `min(分数,100)%`、fill = 功能原色；数值列加粗不上色。
- 均值竖虚线：绝对定位 `left:50.75%`，1.5px dashed `#8d8271`，顶部标签「均值 50.75」9.5px。
- 图注 = 固定 `.chart-note` 一行（无独立 fig-note、无 aria，A 组豁免）：「条长即分数（量表上限 121.8，超 100 封顶）；竖虚线为八项均值 50.75。八维高低只在你的剖面内部比较才有意义。」

### 6.2 02A 四原型 × 两面对照图（`.pos-grid`）

- 结构：CSS grid **2 列 ×（1 列头行 + 4 行）**；列宽 `1fr 1fr` 等长（不编码任何量）。
- 列头：左「意识面 · 第 1–4 位（日常优先、随时调用）」、右「阴影面 · 第 5–8 位（平时不用、常在别人身上看到）」。
- 第 k 行（k=1..4）：左格 = 毕比位置 k（意识），右格 = 位置 k+4（阴影）。**行即配对**（同一功能两种态度：功能不变、态度翻转）。
- 格内：位号（衬线 700 muted）→ 原型全名 → 功能码（染文本色，15px 700）→ 分数（右对齐 tabular）；阴影格加 `(阴影)` 标注。
- 格样式：意识格 = `--card` 底 + 1px `--border` 实线；阴影格 = `--soft` 底 + 同描边。圆角 9px，格距 10px。
- 容器 `role="img"` + aria；图注 `.fig-note`（读法一句 + 「本图属栈层」+ 低置信加限）置于图后、`{{POSITION_NOTES}}` 前。
- 图下固定小注 `.faces-note`（静态、逐字）：一体两面 + 偏向五层白话——置于图注之后、`{{POSITION_NOTES}}` 之前。
- `{{POSITION_NOTES}}`（呈现组件）：8 行「位号 · 原型全名 · 功能码 + plain_definition（逐字照抄 stacks.json）」；5–8 位各加一行激活场景（"可能倾向"级，按 theory-spec §1.8 目录推演；第 8 位用最谨慎级表述）。

### 6.3 02B 天平组（4 条轴）

- 每轴一个 `.axis` 卡；**阴影轴两卡整卡 `opacity:.55`**（成组弱化即阴影归属）。
- 轴头 `.axis-head`：轴名 + 「· 功能对」（双码染文本色）+ 轴类徽注（意识轴·判断 / 意识轴·感知 / 阴影轴·判断 / 阴影轴·感知）。轴名按 stacks.json `axis_rule` 推导：主导–劣势轴 / 辅助–第三轴 / 阴影轴一（第 5&8 位）/ 阴影轴二（第 6&7 位）。
- 天平 SVG `viewBox="0 0 300 120"`：
  - 梁：`<g transform="translate(150,70) rotate(θ)">` 内画 `line x1=-102 x2=102`（`#3d362c` 2.5px）+ 两端圆 r=7（fill 功能原色）。
  - **倾角公式**：`θ = clamp(−(s左 − s右) × 0.22, −14, +14)`；**同档态**：`|s左 − s右| ≤ 3` 时 `θ = 0` 且两端标签尾部加「· 同档」。分高一端更低（θ 已按此定义）。
  - 支点：三角 `(150,73) (138,100) (162,100)` fill `#3d362c`；地线 `y=106`（`--hairline` 1.5px）。
  - 端点标签（`y=24`，12px）：左 `x=6` anchor=start、右 `x=294` anchor=end；内容「功能码 · {分数}」（码染文本色 700、余 muted；多段混排时按段拆分独立 `<text>`、估宽拼接——校验器只认 `<text>` 级 fill）；**不写排序位**（排序由 03 主表与轴内结论文本承载，防双标签中轴碰撞）。
- 轴内容（组件内部、不占章级额度）：每轴 `.concl` 小结（1–2 句）；意识轴加 `.points` ×2 与 `.axis-signal` 失衡信号（"可能"级）；阴影轴用 `.qa-rows` 三标签（谁在冒头 / 在哪看到 / 常见误会）。性质标签 `.axis-tags` 固定两组、逐字（copy-rules 固定文案）：意识轴「自我认同 · 主动调用 · 日常适应 · 比较分化」；阴影轴「无意识 · 被动 · 补偿 · 投射 · 压力下爆发 · 整合后创造」。
- 02B 以 `.axis-tags` 性质标签开场（**无对照卡**——「意识面/阴影面」两列对照由 02A 网格列头承载，一体两面+偏向五层固定小注随 02A 图下 `.faces-note` 给出）；02B 无独立图注（层级由本规范声明）。

### 6.5 04 张力条（`.tension-bar`）与对照小卡

- `.tension-bar` 结构：`.tn-labels`（左「{主导码} {分} · 意识一极」右「{劣势码} {分} · 后台一极」，码染文本色）→ `.tn-bar`（高 16px、圆角 5px、`linear-gradient(90deg, var(--主导色) 0%, var(--主导色) 30%, var(--劣势色) 100%)`）→ `.tn-caption` 白话一句。

## 第 7 部分：图注格式

- 图注 = **读法一句（白话、无机制术语）+ 层级（功能层/栈层）**；低置信时栈层图加「（含低置信推定，按首选类型陈述）」。
- 承载位置：图 A 用 `.chart-note`（固定行）；05 / 02A / 06 用 `.fig-note`；02B 与 04 张力条**无独立图注**（豁免）；页眉雷达**无图注**（豁免）。
- 图注不出现 A/B 级徽章、不计入三段式与理论注额度；图内不写分级。
- 技术惯例：除豁免外每图带 `role="img"` + `aria-label`；`break-inside:avoid`；成对区分同时用形状差（实心/描边、实线/虚线）。
