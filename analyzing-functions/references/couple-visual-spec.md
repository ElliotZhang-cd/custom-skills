双人红线（couple-theory-spec §3.4，逐条继续生效）：

1. 双人层面零指标：全文禁跨人聚合数字；唯一数字 = 配置卡「其余可能」一行注的同人候选分差。
2. 双人报告不印功能绝对分数；**页眉雷达是全文唯一两人分数同图处**（只呈形状、图内不印分数、固定 0–100 刻度、>100 截断于满半径）。
3. 位置编码为主；禁用长度/面积/角度/粗细/色深表达**跨人**差异；颜色只作身份/归属。
4. 证据一律位置锚点（甲 n 位 · 乙 n 位 / 排序位）。
5. 03/04/05 三张 B 级构造物图必须在**图内**以灰字带「机制示意，非实测」（模板 `.fig-inmark` span，置于 SVG 之后、图注之前）；图注层级字段只允许枚举值。

## 第 2 部分：三条总原则

- **P1 同构优先**：图是"两份八位堆叠之间的关系"的空间同构，不是数据美化；一种关系只给一种几何。
- **P2 通道分层**：量值通道跨人禁用；个体内（页眉雷达的各自形状）可用但不印分数、不作跨人读数。
- **P3 图必须自解释**：图内文字一律白话（§5.2 为唯一译法源）；每图可脱正文读懂。

| 通道 | 用法 |

| 位置/槽位 | 毕比位置号、矩阵行列、8 槽条列位 |
