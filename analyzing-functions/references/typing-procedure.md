# 判型可执行编码（两模式共用）

> 第 2 步（单人）/ D2（双人）调用的判型流程。机制唯一出处 `references/theory-spec.md` 第四部分；本文件是其可执行编码，与源头冲突时以源头为准。调用处：`references/workflow-single.md` 第 2 步、`references/workflow-couple.md` D2。

### 第 2 步：类型判定

照 theory-spec §4 执行；下述伪代码为 §4.2–§4.5 的可执行编码，与源头冲突时以源头为准。

```
同档 = 类型推断中任意两功能分差 ≤3；同档内名次先后不构成判型证据
候选 = 以 Top1 为主导的两个类型
首选：
  合法辅助分差 >3 → 取合法辅助分数更高者；
  分差 ≤3（同档）→ 按证据优先序综合评估（层级次序不得调换，theory-spec §4.4）：
    ① 态度否决：与 §3.1 第 3 步同类态度对比矛盾的候选出局；两候选均矛盾则都不否决、置信锁低
    ② 独有位置证据：比较两候选互异位置（通常为辅助位与第三位；视候选对含劣势位与互异阴影位）
       功能与实测分数的对位（落入低分区=不利、高分区=支持；分差≤3=证据中性）
    ③ 奥卡姆剃刀·意识面最小异常：数候选意识面 1–4 位落入实测后四名的个数，少者胜；
       阴影位（5–8 位）高分不计异常（§1.5：阴影高分是信号不是错误）
    ④ 分差兜底：仍平局取分高者，分歧点写「另一种可能」一行注
  Top1 与同档竞争者（分差≤3）并存时，对该档每个功能各自可成的合法候选走同一优先序定主导
有界改判（theory-spec §4.4）：Top1 的两个合法辅助都明确低于某候选所需辅助（分差>3，非同档）时，
  主导候选扩展为前四名中每个能组出合法堆叠且辅助受支持的功能，按上述优先序重选唯一首选；
  改判结果置信度上限锁「低」，改判原因在第 01 章暴露；
  仅一个辅助不受支持 → 不触发，按原路径执行但置信度降一档，并在第 03/05 章点明"辅助功能疑似被绕开"
反向验证1 = 首选劣势功能是否处于后三名（与相邻名次分差≤3 时按「证据中性」处理，名次不作独立证据）
反向验证2 = 首选第7位(小丑)功能是否处于后两名（同上按同档判读）
态度一致性 = Top1 态度与类别内态度对比是否一致

置信度：高 = 分差≥10 且两项反向验证通过且态度一致
        中 = 分差∈[3,10) 且无矛盾；或分差≥10 但恰一项验证不过
        低 = 分差<3；或态度矛盾；或区分度低；或有界改判

输出口径：同档/模糊情形一律综合判型，输出唯一最有可能类型（不并列呈现两套完整堆叠）；
          置信度阈值链不变（关键分流分差<3 仍标「低」）。
禁止在判定中临时发明本规范未载明的特例规则（theory-spec 第七部分禁区 10，奥卡姆剃刀治理层）。
```

判定后生成**"另一种可能"一行注**（所有置信度都输出；逐字句式唯一出处：copy-rules「四、固定文案」章，不在此照录）。任何置信度都不做双候选并列呈现。
