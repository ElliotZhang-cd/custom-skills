# analyzing-functions

荣格八维分数 → 自包含 HTML 报告的生成框架（单人 7 章 / 双人 7 节）。本词汇表统一框架各文件（SKILL.md / workflow-single / workflow-couple / theory-spec / couple-theory-spec / copy-rules / 模板 / stacks.json）的共用语言。本文件同为转述层：机制性内容只写"见 §x.x"，不复述。

## Language

### 测量与判定

**八维分数**:
Se Si Ne Ni Te Ti Fe Fi 八项自陈式偏好分数，测"倾向于怎么用这个功能"，不是能力实测。
_Avoid_: 能力分、强弱分

**功能堆叠**:
每个类型 1–8 位的功能序列：Grant 前四位（主导/辅助/第三/劣势）+ 毕比阴影四位（5–8）。

**判定置信度**:
高/中/低三档，由分差、反向验证、态度一致性、区分度四项规则算出，必须始终随类型结论出现。有界改判触发时置信度上限锁低（theory-spec §4.4）。

**同档**:
类型推断中任意两功能分差 ≤3 分视为同一档；同档内名次先后不构成判型证据，须按证据优先序（态度否决→独有位置证据→意识面最小异常→分差兜底）综合评估后给出唯一最有可能类型（theory-spec §4.4）。
_Avoid_: 名次判读、机械取高分

**最小异常**:
奥卡姆剃刀在判型中的操作化——同档候选硬证据打平时，数「候选堆叠意识面 1–4 位功能落入实测后四名」的个数，少者胜；阴影位（5–8 位）高分不计为异常（§1.5：阴影高分是有临床/发展意义的信号，不是错误）。
_Avoid_: 全 8 位错位计数、剖面打分

**有界改判**:
Top1 的两个合法辅助都明确低于某候选所需辅助（分差 >3，非同档）时，主导候选扩展为前四名中能组出合法堆叠且辅助受支持者重选；结果置信度锁低、改判原因在第 01 章暴露（theory-spec §4.4）。
_Avoid_: 机械锚定 Top1、全空间重推

**另一种可能一行注**:
类型大字下方承载备选类型的一句话，句式随置信度变化；低置信时不做双候选并列呈现。
_Avoid_: 双塔并列、判读路径三段

### 轴与位置

**意识面 / 阴影面**:
毕比 1–4 位为意识面（日常优先、随时能调用）；5–8 位为阴影面（平时不用、常在别人身上看到）。一体两面，不是两个人格。
_Avoid_: 影子人格、第二人格、一切比喻式别称

**意识轴 / 阴影轴**:
四条配对轴：意识轴 = 毕比 1–4 位中同类功能两两配对（哪条是感知轴、哪条是判断轴由功能类别决定）；阴影轴 = 5–8 位中 5&8、6&7 各成一轴。配对规则唯一出处：theory-spec §1.8。

**偏向五层**:
说"偏向某功能"实际混了五层：分化程度、意识位置、自我认同、能量投注、可调用性；分数只直接反映其中"分化程度"与"能量投注"两层。

**对位**:
单人报告第 03 章主表的一列——结构位置与实测分数排名的对齐判定（✓ 匹配 / ≈ 接近 / 偏离），证据是位置与分数的关系，不是功能之间的配对。
_Avoid_: 功能配对、1↔5 对位

### 呈现组件

**视觉语法**:
报告里「哪类内容必须以图形承载、图与文字如何分工」的规则总称（六类结构关系必图化；图形固定进章结构）。单人报告的现行图目录、逐图几何与图注格式唯一出处为 `references/single-visual-spec.md`；双人见 `references/couple-visual-spec.md`。
_Avoid_: 图表风格、视觉方案

**结论块**:
每章第一个组件，也是本章唯一的结论块：1–2 句自包含的加粗结论——功能 + 分数证据 + 机制/含义一次说全，单独抽出来读不需要上下文也能懂。合并原"章级引句"与"节级结论块"两个槽位；组件内加粗"小结论"（如 02B 每条轴）不算第二个结论块。
_Avoid_: 铺垫式导语段落、电报式短句

**要点行**:
一句话结论下的 bullet，每条一个完整短句、只装一个因果，必须绑定分数或排序依据，每章至多 3 条（可为 0 条则省略）。

**理论预算**:
每章理论注 ≤1 句的硬上限；装不下的理论内容挪到 07 章边界声明或删除。

**比喻库**:
stacks.json 内每功能的三个固定字段（白话定义 / 比喻 / 日常例子），生成时照抄取用，用户可直接改库（版面只用白话定义；比喻 / 日常例子两字段仅作库数据保留）。
_Avoid_: 即兴比喻、现场创作比喻

**比喻三律**:
一切比喻（含库外新增）（现仅约束 stacks.json 比喻库字段自身的编写；报告版面已无比喻）的硬规则：来自具体日常场景；无抽象名词；后面必须跟"实际情况："补全功能定义。

**三标签**:
阴影轴补偿/投射内容的固定三行模板：谁在冒头 / 在哪看到 / 常见误会。
_Avoid_: 投射长句、回声句

**彩面例外**:
"彩色元素 ≤15% 版面"铁律只统计文字颜色；组件的强调线、淡色底、chip 不计入。

**四原型两面对照图**:
单人 02A 的图形——4 行（英雄/父母/少年/劣势）× 2 列（意识面＝原态度、阴影面＝态度翻转），格宽不编码任何量（轴不画入本图，轴图见 02B）。

**回路图**:
单人 05 章的图形——四节点（主导/辅助/第三/劣势）与正常通路底图，loop 命中时叠加绕过辅助的弧线，grip 命中时劣势节点接管。
_Avoid_: 状态图、循环图

**双向对话图**:
单人 06 章的图形——1↔5、2↔6、3↔7、4↔8 四组双向对话，每行两段对称箭头指向中轴；四行汇入一条自下而上的空腔主干，即两极被同时容下时长出的第三条路（产物，不是第三个功能）；4↔8 一线为虚线并标间接途径。
_Avoid_: 回流图、单向箭头图

**图形层级**:
每张图属于功能层还是栈层（双人报告的依据是 couple-theory-spec §3.2），决定低置信时该图的解释是否降级；必须写进图注。

### 报告结构与语言

**倒金字塔**:
报告文字的排布原则——越往上越短、越可单独抽走：先一句话结论，次要点，细节进呈现型组件与理论注；只读最上层也能拿到本章要义。
_Avoid_: 摘要卡、速读卡、先铺垫后结论

**三段式**:
报告每章固定的文字次序——① 一句话结论 → ② 要点行（≤3 条，每条只装一个因果；可为 0 条则省略）→ ③ 呈现型组件 → ④ 理论注（≤1 句，单人专属）。三段式的单位是"章"（单人 7 章），07 章为固定文案不设三段式；双人为两段式（结论 → 要点），不设理论注。
_Avoid_: 三层结构、四层结构、段落结构、展开层

**一句话结论**:
每章第一块，也是本章唯一的结论块——1–2 句自包含的完整句，先给判断；合并原"章级引句"与"节级结论块"两个槽位。
_Avoid_: 章级引句、节级结论块、铺垫式导语

**理论注**:
每章末尾的灰字小注（≤1 句，CSS 类 `.theory-note`，前缀 ▸）：装理论白话或细节补充；仅单人报告有此层，双人两段式不设。
_Avoid_: 灰注、理论白话注、正文理论段落、成段理论注

**术语三档**:
报告术语按可讲清程度分档处置——甲档原样保留、不加注（功能码 / 八位置原型名 / 类型码）；乙档保留但只作括号注、不作句子主词，句子主词用人话；丙档讲不清的直接白话、术语不出现（只删展示性解释，类型判定与置信度不受影响）。
_Avoid_: 术语替换表、一刀切白话

**四条结构声明**:
覆盖全报告文字（含组件内文字）的四条硬规则——R1 块白名单（每章正文只有 结论 / 要点 / 理论注 三种块 + 呈现型组件，不得出现第二个成段行文块）；R2 一个因果一句（因果连接词每句至多一个）；R3 括号注规则（只管句中术语白话注：紧跟术语首现、括号内只装术语本身（可带一个极短限定语）、不含顿号逗号分号）；R4 三个以上并列拆要点行。R1–R3 由脚本机械校验，R4 为写作声明。
_Avoid_: 文案细则、写法清单

### 双人

**双人模式**:
同一请求出现两组八维分数时的工作模式，产出固定 7 节（00–06）双人关系 HTML 报告；一组分数 = 单人模式；形态或意图不明 → 停止确认。路由唯一出处：SKILL.md 第 0 步。

**同源前提**:
输入的两组分数一律视为出自同一测评工具及版本；不做不同源分支处理，报告内不设可比性保留句（couple-theory-spec §1.1）。

**couple-theory-spec**:
双人模式的唯一理论来源（references/couple-theory-spec.md），以上游契约引用 theory-spec，不重定义分数→类型/堆叠/置信度推导。
_Avoid_: 桌面绝对路径式引用（统一用 references/ 下相对路径）

**六透镜流水线**:
双人分析固定顺序：① 个体配置重建 → ② 态度与能量经济 → ③ 感知轴×判断轴 → ④ 投射地图（核心）→ ⑤ 冲突剧本 → ⑥ 关系的功课。唯一出处：couple-theory-spec §4。
_Avoid_: 分析步骤、六大模块

**功能层 / 栈层**:
双人分析的两层：功能层只依赖分数相对排序、态度内对比、剖面形状，无论置信度永远执行；栈层依赖毕比位置，仅中/高置信完整执行，任一方低置信时全文按该方首选类型陈述（couple-theory-spec §3.2–3.3）。

**功能块划分**:
透镜④第一步：把 8 个功能-态度划入双方意识面/甲意识面·乙阴影面/乙意识面·甲阴影面/双方阴影面四块，须通过穷尽性检查（并集=8、两两不交）；P2 命中从块划分导出。

**双方阴影面块**:
功能块之一：双方阴影区重合的功能-态度。只允许"双向共影"级措辞，禁止写成单向投射。
_Avoid_: 共享阴影块、甲阳乙阴块、乙阳甲阴块

**双人层面零指标**:
双人报告不构造任何聚合数字（分差、相似度、契合率、命中率、排名）；跨人陈述仅"同高/同低/一高一低"三种相对形式；绝对分数只允许出现在配置卡。
_Avoid_: 相似度、匹配率、契合分

**逐维度读数**:
总览位的关系地图（位置对应矩阵）之下的 8 行描述性读数（功能 ｜ 甲位置·原型 ｜ 乙位置·原型 ｜ 一句动力学）；**无排序位列、无分数、无汇总行**，不是匹配度评分。
_Avoid_: 逐维度相遇表、排序位表

**证据分级**:
双人论断标注制度：【A 级】文献直接支持；【B 级】A 级机制向双人场景的推演，措辞强制"可能倾向"级；分级不进报告版面，在生成过程自检中核对。

**写栈校验**:
集合运算/命中判定前逐字写出双方八位堆叠，一切命中与块归属以写出的栈为唯一依据；禁止复用上下文或示例中已算过的集合。

**反好消息校验**:
结构性/戏剧性结论必须独立重算并逐位写出中间集合，结论措辞强度不得高于计算精度。

**双人叠加雷达**:
页眉的双人同图雷达，全文唯一允许两人**分数**同图之处（位置／拓扑类同图不受此限，见「跨人量值禁令」与图 2／图 3／图 4／图 5）（视觉几何见 references/couple-visual-spec.md 第 5 部分 图 1）。
_Avoid_: 双人雷达对比图、匹配雷达

**剖面内分数排序位**:
某功能在本人八项分数中从高到低的位次（1–8）。§3.4 第 2 条的"同高 / 同低"前 3 位 / 后 2 位阈值以此为准，不得与毕比位置号混读。
_Avoid_: 排名、强弱位

**位置编码**:
双人图形只用七个通道表达关系——位置/槽位、拓扑、相等、对置、方向、归属、颜色；不用长度/面积/角度等量值通道表达跨人差异；颜色可作身份/归属区分，但不作跨人量值。剖面内排序位是结论与要点行的文字锚点（couple-theory-spec §3.4），不是图形编码通道（白名单通道见 couple-visual-spec 第 3 部分；视觉几何见 references/couple-visual-spec.md）。
_Avoid_: 比例编码、数值编码

**态度×节律坐标系**:
双人 01 节的图形（定位与视觉几何见 references/couple-visual-spec.md 第 5 部分 图 4）。
_Avoid_: 态度与节律坐标系、态度与节律双轴图、2×2 网格图

**感知轴×判断轴坐标系**:
双人 02 节的图形（定位与视觉几何见 references/couple-visual-spec.md 第 5 部分 图 5）。
_Avoid_: 轴对照图、轴位双点图

**因果链图**:
双人 04 节的图形（定位与视觉几何见 references/couple-visual-spec.md 第 5 部分 图 7）。
_Avoid_: 互锁回路

**位置锚点**:
结论与要点行举证时使用的双方位置表述（毕比位置号 / 剖面内排序位），取代分数。
_Avoid_: 分数锚点、数据锚点

**双人视觉 spec**:
双人**页眉与 00–05 节**图形呈现的唯一依据（references/couple-visual-spec.md）；谈图形语法、几何映射与用色策略，不涉字体/间距/版式，不复述机制。

**单人视觉 spec**:
单人**页眉与 01–06 章**图形呈现的唯一依据（references/single-visual-spec.md）；谈图形语法、几何映射与用色策略，不涉字体/间距/版式，不复述机制。与双人的差异：单人设理论注层、允许分数进版面、量值通道个体内可用、图注为自由式（`.chart-note`/`.fig-note`）。
_Avoid_: 单人图表风格、散落的模板注释

**关系图系统**:
双人图形的基本性质——每张图把"两份八位堆叠之间的关系"画成同构的空间关系，不是把数值画成图形。
_Avoid_: 数据可视化、图表美化

**同构优先**:
一条论断对应唯一一种空间形式（位置/拓扑/相等/对置/方向/归属/颜色），一种关系只给一种形式。

**通道白名单**:
双人图允许使用的七个通道：位置/槽位、拓扑、相等、对置、方向、归属、颜色。

**量值通道黑名单**:
长度、面积、角度、粗细、深浅等"可比较大小"的通道；仅在跨人比较时禁用，个体内解禁。颜色作为身份/归属区分不受禁，作为深浅量值时仍属量值通道。
_Avoid_: 全局禁长度

**跨人量值禁令**:
跨人方向不得使用任何量值通道；个体内唯一的形状图形是页眉双人叠加雷达。**位置／拓扑类通道的两人同图不受此限**（图 2／图 3／图 4／图 5 均是两人同图）。
_Avoid_: 比例编码、数值对比

**图 / 呈现组件**:
只有图形（chart）计为"图"并受"一节一主图"约束；卡片、清单、表格属呈现组件，不占图名额。

**准入判据**:
双人每节至多一张主图，且该图必须编码一个"用文字或表格会失真、或需长解释"的结构关系，否则退回文字/表格。

**固定图注**:
双人图注的统一格式——`图 {n} · {名} ｜ 图形层级：{功能层/栈层/双层}{· 含低置信推定} ｜ 读法：{一句白话}`；n 为 spec §5 固定的图号 1–8；层级声明是 couple-theory-spec §3.2 的硬要求。**唯一例外：页眉双人叠加雷达不带固定格式图注**，只保留一行最简图例（实线＝甲 · 虚线＝乙）。

**配置卡一句话简述**:
00 节配置卡内紧接类型行的一句自包含简述——替代原整段身份句，承载该方功能取向与最需知道的一点，每人各一句；备选信息的括注与 spine/arm 指认仍各自独立成句（视觉位置见 references/couple-visual-spec.md 第 5 部分）。
_Avoid_: 身份句、身份段

**配置卡横向对照**（图 2）:
00 节的图形——甲、乙两条八槽横条上下叠放、同号位竖直对齐，每槽＝位置号＋原型名＋功能-态度码，不印分数；上四位意识面、下四位阴影面。图位于甲、乙两张配置卡下方（视觉几何见 references/couple-visual-spec.md 第 5 部分 图 2）。
_Avoid_: 配置卡并排对照、配置卡堆叠带、单人堆叠带

**命中徽章**（图 6）:
03 节「吸引的无意识根源」的图形——不设统一底图，每个**实际命中**的机制一枚**纯几何徽章**（你们互为对方的镜像／{方}最深的一面，正是{对方}的日常／{方}平时不用的，正是{对方}天天在用的／你们占着同一个驾驶座／触动我的是哪个位置）＋一句白话；未命中的机制不出图，P1–P5 全未命中时出一枚兜底徽章（触动我的是哪个位置；几何由 `scripts/couple_figures.mjs` 填充器产出，见 references/couple-visual-spec.md 第 5 部分 图 6）。
_Avoid_: 功能块矩阵、双栈投射图、投射箭头、命中附属小图

**纵向汇流图**（图 8）:
双人 05 节的图形——甲乙两个立场节点在上（甲实线、乙虚线）、两条箭头向下汇入「第三条路」盒；轴只出现在标题行（定位与视觉几何见 references/couple-visual-spec.md 第 5 部分 图 8）。
